Lens exposes a same-origin HTTP API and MCP endpoints through the unified Python
FastAPI backend (`llm_d_lens`). Vite proxies browser `/api/...` calls directly to
it in development. In production, the same backend serves the built frontend,
REST API, `/api/mcp` (Agent Task MCP), and `/api/assistant/mcp` (Assistant Tool
Catalog), and owns validation, persistence, and task execution.

:::note
For direct namespace-scoped Kubernetes workflows without running the Lens server or database, use the standalone `llmd` CLI (`apps/lens`). See [CLI Reference](/cli-reference).
:::

Deploy is part of the Lens Python backend, not a separate llm-d-bench API.
Deployment routes run in the same process; no separate BFF upstream is required.
Use `hack/lens-local.sh start` for local development; see
[Installation](/installation) and [Environment variables](/environment-variables)
for current startup and storage settings rather than host-specific `/root/...`
paths. Requests require an authenticated Lens session (or a `lens-pat-*` bearer
token on `/api/mcp`) and the relevant permission; unsafe browser session methods
also require the matching `prism_csrf` cookie and `x-prism-csrf` header.
Unauthenticated smoke requests may return `401`, not a resource list.

## Surfaces

| Surface | Description |
| --- | --- |
| Python API | Same-origin FastAPI routes for deploy, simulation (`/api/simulation`), evaluation, model catalog (`/api/v1/model-catalog`), storage, monitoring, auth, and Playground; also serves the production frontend. |
| Agent Task MCP (`/api/mcp`) | Stateless Streamable HTTP MCP server exposing 46 task-oriented tools for external coding/operations agents (see [MCP integration](/mcp)). |
| Assistant Tool Catalog (`/api/assistant/mcp`) | Assistant-callable operations generated from backend routes into the internal MCP catalog (see [Lens Assistant](/api-reference/modules/lens-assistant)). |
| Kubernetes backend | Server-side Kubernetes access over the official Python client, with CLI rollback. |

OpenAPI schema. Regenerate it after backend route changes:

```bash
source .venv/bin/activate
npm run docs:api
```

## Conventions

Every new or modified externally callable API (FastAPI routes, HTTP handlers,
RPC/MCP tools and their request/response contracts) must keep its description
consistent with the implemented behavior, validation, authorization, defaults,
status codes and schemas. See the repository API description requirements in
`.github/instructions/api-documentation.instructions.md`.
