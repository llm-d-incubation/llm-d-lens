Lens exposes a same-origin HTTP API through the Python FastAPI backend
(`llm_d_lens`). Vite proxies browser `/api/...` calls directly to it in development.
In production, the same backend serves the built frontend, API and MCP endpoint,
and owns validation, persistence and task execution.

```mermaid
flowchart LR
    UI["Lens UI"] --> PY["Python API (llm_d_lens) :3000"]
    PY -->|/api/remote-deploy| SSH["Remote host over SSH"]
    PY --> DB["Database"]
    PY --> K8s["Kubernetes"]
```

Deploy is part of the Lens Python backend, not a separate llm-d-bench API.
Deployment routes run in the same process; no separate BFF upstream is required.
Use `hack/lens-local.sh start` for local development; see
[Installation](/installation) and [Environment variables](/environment-variables)
for current startup and storage settings rather than host-specific `/root/...`
paths. Requests require an authenticated Lens session and the relevant permission;
unsafe methods also require the matching `prism_csrf` cookie and `x-prism-csrf`
header. Unauthenticated smoke requests may return `401`, not a resource list.

## Surfaces

| Surface | Description |
| --- | --- |
| Python API | Same-origin FastAPI routes for deploy, simulation, evaluation, storage, monitoring, auth and Playground; also serves the production frontend. |
| MCP tools | Assistant-callable operations generated from backend routes into the MCP catalog. |
| Kubernetes backend | Server-side Kubernetes access over the official Python client, with CLI rollback. |

Every Python backend endpoint is also documented in the generated FastAPI
OpenAPI schema. Regenerate it after backend route changes:

```bash
source .venv/bin/activate
npm run docs:api
```

## Conventions

Every new or modified externally callable API (FastAPI routes, HTTP handlers,
RPC/MCP tools and their request/response contracts) must keep its description
consistent with the implemented behavior, validation, authorization, defaults,
status codes and schemas. See the repository API description requirements in
`.github/instructions/api-documentation.instructions.md`.
