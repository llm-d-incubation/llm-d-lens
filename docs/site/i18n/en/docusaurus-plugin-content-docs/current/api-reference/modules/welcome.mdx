## What this module is

Welcome is a read-only issue feed for the landing page. Use it to build an alert
view or dashboard that combines current findings across clusters. It returns issue
snapshots only; cluster capacity, model-service tables, deployment history, and
usage remain on their owning APIs.

Both endpoints require an authenticated session with `cluster:cluster:read`.
Results are filtered to the clusters and domain permissions available to the
caller.

## Quick start

### Get the overview

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/welcome/overview?clusterId=cluster-a"
```

The response contains `generatedAt`, `scope`, and an `issues` envelope with the
current issue array.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        overview = await lens.dashboard.overview(cluster_id="cluster-a")
        for issue in overview.issues.data or []:
            print(issue.severity, issue.code, issue.title)


asyncio.run(main())
```

## Common tasks

### Filter and paginate current issues

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/welcome/issues?severity=critical&category=model-service&limit=10"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        page = await lens.dashboard.alerts(
            severity="critical", category="model-service", limit=10
        )
        print(page.total, page.next_cursor)
        for issue in page.items:
            print(issue.cluster_name, issue.title)


asyncio.run(main())
```

  </TabItem>
</Tabs>

- Optional filters: `clusterId`, `severity`, `category`, and `search`.
- Pass `nextCursor` back as `cursor`. If the snapshot changed or expired, the
  response sets `restarted: true` and starts from the first page.
- `category` values are `cluster`, `model-service`, `deployment`, `storage`,
  `model-cache`, `monitoring`, `ai-provider`, and `access`.

### Refresh the snapshot

Set `refresh=true` on the overview request to schedule a background refresh. The
call returns the current snapshot immediately and does not wait for remote
sources. Check the `issues.stale` flag before treating values as current.

## Endpoints

| Method | Path | Use |
| --- | --- | --- |
| `GET` | `/api/v1/welcome/overview` | Scoped issue envelope for the landing page. |
| `GET` | `/api/v1/welcome/issues` | Flat, filtered issue list with cursor pagination. |

## Errors / limits

- Missing or invalid authentication returns `401`; missing `cluster:cluster:read`
  returns `403`.
- An inaccessible explicit `clusterId` returns `403` without resource details.
- `limit` must be between `1` and `100`.
- Snapshots are refreshed in the background about every 60 seconds. `refresh=true`
  only queues a refresh.
