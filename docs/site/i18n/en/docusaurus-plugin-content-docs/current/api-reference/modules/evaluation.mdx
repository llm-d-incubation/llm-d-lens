Lens Evaluate measures a ready deployment execution or a published Model Service, or deploys a configuration and benchmarks it in one workflow. Use this module to run throughput and latency tests, compare configurations, inspect saved results, and clean up runs. A benchmark requires a ready execution with an endpoint and an active cluster session.

## Quick start

Benchmark an existing ready deployment.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -sX POST http://127.0.0.1:3000/api/v1/evaluate/runs \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "deployment_execution_id": "<execution-id>",
    "cluster_session_id": "<cluster-session-id>",
    "workload": "sanity_random.yaml"
  }'
```

```json
{
  "kind": "benchmark",
  "id": "<run-id>",
  "status": "queued"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.evaluation.models import EvaluateRunRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        run = await lens.evaluation.create_run(
            EvaluateRunRequest(
                deployment_execution_id="<execution-id>",
                cluster_session_id="<cluster-session-id>",
                workload="sanity_random.yaml",
            )
        )
        print(run.id, run.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## Common tasks

### Estimate benchmark time

Preview the runtime and automatic timeout for a workload. This does not read or launch cluster resources.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/evaluate/timing-estimate`**

```json
{
  "parallelism": 1,
  "matrix": [{"isl": 1024, "osl": 128}],
  "concurrency_stages": [{"concurrency": 8, "num_requests": 96}]
}
```

Response fields: `lower_seconds`, `upper_seconds`, `timeout_seconds`, `timeout_mode`, `assumptions`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.evaluation.models import BenchmarkSpec
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        timing = await lens.evaluation.estimate_timing(
            BenchmarkSpec(
                parallelism=1,
                matrix=[{"isl": 1024, "osl": 128}],
                concurrency_stages=[{"concurrency": 8, "num_requests": 96}],
            )
        )
        print(timing.lower_seconds, timing.upper_seconds, timing.timeout_seconds)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### Benchmark with a matrix and SLA targets

Sweep input/output length points and attach optional targets. The run returns `202` when queued; poll it for progress.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/evaluate/runs`**

```json
{
  "deployment_execution_id": "<execution-id>",
  "cluster_session_id": "<cluster-session-id>",
  "harness": "inference-perf",
  "workload": "sanity_random.yaml",
  "parallelism": 2,
  "matrix": [{"isl": 1024, "osl": 128}],
  "concurrency_stages": [{"concurrency": 8, "num_requests": 96}],
  "sla_targets": {
    "ttft_ms": 500,
    "tpot_ms": 50,
    "throughput_min_tps": 1000
  }
}
```

Response fields: `id`, `status`, `deployment_execution_id`, `matrix`, `sla_targets`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.evaluation.models import BenchmarkSlaTargets, EvaluateRunRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        run = await lens.evaluation.create_run(
            EvaluateRunRequest(
                deployment_execution_id="<execution-id>",
                cluster_session_id="<cluster-session-id>",
                harness="inference-perf",
                workload="sanity_random.yaml",
                parallelism=2,
                matrix=[{"isl": 1024, "osl": 128}],
                concurrency_stages=[{"concurrency": 8, "num_requests": 96}],
                sla_targets=BenchmarkSlaTargets(
                    ttft_ms=500,
                    tpot_ms=50,
                    throughput_min_tps=1000,
                ),
            )
        )
        print(run.id, run.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### Benchmark a published Model Service

Set `model_service_group_id` instead of `deployment_execution_id`. The harness resolves the group's active member and calls it through the shared Gateway. `api_key` is required and must be a model access token beginning with `lens-mk-`; it is never persisted.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/evaluate/runs`**

```json
{
  "model_service_group_id": "<model-service-group-id>",
  "api_key": "<token>",
  "harness": "inference-perf",
  "workload": "sanity_random.yaml"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.evaluation.models import EvaluateRunRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:

            EvaluateRunRequest(

            )

        print(run.id, run.status)

    asyncio.run(main())
```

### Compare saved configurations

Deploy one or more saved configuration artifacts, benchmark them, and compare the results with optional baselines.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/evaluate/evaluations`**

```json
{
  "name": "Qwen comparison",
  "cluster_session_id": "<cluster-session-id>",
  "benchmark_plans": [
    {
      "id": "candidate",
      "configuration_artifact_id": "<configuration-artifact-id>",
      "include_baseline": true,
      "baseline_type": "direct-vllm",
      "benchmark": {
        "workload": "sanity_random.yaml",
        "matrix": [{"isl": 1024, "osl": 128}]
      }
    }
  ],
  "compare_configurations": true
}
```

Response fields: `kind`, `id`, `status`, `cases[]`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.evaluation.models import EvaluationCreateRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        workflow = await lens.evaluation.create_evaluation(
            EvaluationCreateRequest(
                name="Qwen comparison",
                cluster_session_id="<cluster-session-id>",
                benchmark_plans=[
                    {
                        "id": "candidate",
                        "configuration_artifact_id": "<configuration-artifact-id>",
                        "include_baseline": True,
                        "baseline_type": "direct-vllm",
                        "benchmark": {
                            "workload": "sanity_random.yaml",
                            "matrix": [{"isl": 1024, "osl": 128}],
                        },
                    }
                ],
            )
        )
        print(workflow.id, workflow.status, len(workflow.cases or []))

    asyncio.run(main())
```

</Tabs>

### Inspect results and manage a run

Read a benchmark result or expanded workflow details, then cancel, retry, or delete it when it reaches the required state.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/evaluate/runs/<run-id>`**

**`GET /api/v1/evaluate/workflow-runs/<workflow-id>/details`**

```json
{
  "workflow": {"id": "<workflow-id>", "status": "succeeded"},
  "report": {
    "comparison_version": 2,
    "comparisons": []
  }
}
```

Use `POST /api/v1/evaluate/workflow-runs/<workflow-id>/retry` for a failed or cancelled workflow, `POST /api/v1/evaluate/workflow-runs/<workflow-id>/cancel` to stop it, and `DELETE /api/v1/evaluate/workflow-runs/<workflow-id>` after it is terminal.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        detail = await lens.evaluation.get_workflow_run_details("<workflow-id>")
        print(detail["workflow"]["id"], detail["report"]["comparison_version"])

        await lens.evaluation.cancel_workflow_run("<workflow-id>")
        await lens.evaluation.delete_workflow_run("<workflow-id>")

    asyncio.run(main())
```

## Endpoints

| Method | Path | Permission | Purpose |
| --- | --- | --- | --- |
| `GET` | `/api/v1/evaluate/benchmark-defaults` | `evaluate:run:read` | Show the default benchmark source and runtime |
| `POST` | `/api/v1/evaluate/timing-estimate` | `evaluate:run:read` | Estimate duration and timeout |
| `POST` | `/api/v1/evaluate/runs` | `evaluate:run:create` | Benchmark a ready execution or Model Service |
| `GET` | `/api/v1/evaluate/runs` | `evaluate:run:read` | List benchmark runs |
| `GET` | `/api/v1/evaluate/runs/{run_id}` | `evaluate:run:read` | Get benchmark results and evidence |
| `POST` | `/api/v1/evaluate/runs/{run_id}/cancel` | `evaluate:run:cancel` | Cancel an active benchmark |
| `DELETE` | `/api/v1/evaluate/runs/{run_id}` | `evaluate:run:delete` | Delete a terminal benchmark |
| `POST` | `/api/v1/evaluate/workflow-runs` | `evaluate:workflow:create` | Deploy and benchmark in one workflow |
| `POST` | `/api/v1/evaluate/evaluations` | `evaluate:workflow:create` | Run a multi-configuration evaluation |
| `GET` | `/api/v1/evaluate/workflow-runs` | `evaluate:run:read` | List evaluation workflows |
| `GET` | `/api/v1/evaluate/workflow-runs/{workflow_id}` | `evaluate:run:read` | Get a workflow record |
| `GET` | `/api/v1/evaluate/workflow-runs/{workflow_id}/details` | `evaluate:run:read` | Get cases, results, and report |
| `POST` | `/api/v1/evaluate/workflow-runs/{workflow_id}/retry` | `evaluate:run:retry` | Retry a failed or cancelled workflow |
| `POST` | `/api/v1/evaluate/workflow-runs/{workflow_id}/cancel` | `evaluate:run:cancel` | Cancel a workflow |
| `POST` | `/api/v1/evaluate/workflow-runs/{workflow_id}/cases/{case_id}/cancel` | `evaluate:run:cancel` | Cancel one evaluation case |
| `DELETE` | `/api/v1/evaluate/workflow-runs/{workflow_id}` | `evaluate:run:delete` | Delete a terminal workflow |

## Errors and limits

| Code | Meaning | What to do |
| --- | --- | --- |
| `401` / `403` | Not authenticated or missing permission | Check the token and the permission column above |
| `404` | Execution, run, workflow, or Model Service not found | Re-list resources and confirm the id |
| `409` | Not ready, lifecycle conflict, no healthy member, or owned by another backend | Check status and send the request to the owning backend |
| `422` | Invalid request or malformed identifier | Fix the request fields |
| `503` | Evaluation could not be queued | Check cluster access and retry |

- A benchmark target must be a `ready` execution with an endpoint and an active cluster session. Otherwise creation returns `409`; a missing execution returns `404`.
- Set exactly one of `deployment_execution_id` or `model_service_group_id`. Model Service benchmarks also require `api_key` beginning with `lens-mk-`.
- HTTP `202` means the run is queued. Monitoring preparation must pass before traffic starts; setup failure stops the run before the benchmark.
- `wait_timeout_seconds: null` uses an automatic budget between 900 and 14400 seconds. Explicit values must be 1-14400. `parallelism` is 1-32 and `harness_memory_gib` is 1-512.
- Use at most one of `matrix`, `shared_prefix`, or `workload_yaml` as the workload generator.
- Only `succeeded`, `failed`, and `cancelled` are terminal. Delete a benchmark or workflow only after it is terminal; active runs and benchmarks owned by a workflow return `409`.
- Retry only failed or cancelled workflows. Cancel, retry, and delete requests for work owned by another backend return `409`; send them to that backend.
- For a PD configuration, an automatic baseline replica count must be an exact integer from 1 to 32. Otherwise creation returns `409` before queueing; set explicit baseline replicas to override.
- Missing historical telemetry, KV captures, or resource snapshots are not reconstructed from current live data. Rerun to collect newly enabled evidence.
