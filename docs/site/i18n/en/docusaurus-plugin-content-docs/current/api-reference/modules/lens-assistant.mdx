## What this module is

Lens Assistant is the built-in chat that uses Lens' MCP tool catalog. Use the same
endpoint when your own MCP client, IDE agent, or script should inspect and operate
Lens. It is a stateless JSON-RPC 2.0 endpoint over Streamable HTTP: every request is
independent and tool calls read the current Lens REST state.

## Quick start

`POST /api/v1/mcp` requires a signed-in session with `mcp:tool:invoke` or
`playground:chat:use`, sent as a bearer token or the `prism_session` cookie.

There is no Python SDK wrapper for the MCP transport. The SDK tab shows the typed
in-process equivalent of the same Lens operation.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -s "http://127.0.0.1:3000/api/v1/mcp" \
  -H "Authorization: Bearer $LENS_SESSION_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {"name": "list_clusters", "arguments": {}}
  }'
```

Successful tool calls return a JSON-RPC `result` with `content` blocks. The `text`
field contains the JSON-stringified REST result.

## Common tasks

### Discover available tools

Tool names change as Lens modules evolve. Ask the server for the current catalog:

```bash
curl -s "http://127.0.0.1:3000/api/v1/mcp" \
  -H "Authorization: Bearer $LENS_SESSION_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc": "2.0", "id": 2, "method": "tools/list"}'
```

Each tool reports input fields and a risk tier (`read`, `write`, or `approve`).

## Endpoints

| Method | Path | Use |
| --- | --- | --- |
| `POST` | `/api/v1/mcp` | One stateless MCP JSON-RPC request (`initialize`, `tools/list`, or `tools/call`). |
| `GET` | `/api/v1/mcp` | Returns `405`; there is no server-to-client stream in stateless mode. |
| `DELETE` | `/api/v1/mcp` | Returns `405`; there is no server-side session to end. |

## Errors / limits

- Missing or invalid authentication returns `401`. A session without
  `mcp:tool:invoke` or `playground:chat:use` returns `403`.
- Unknown tool names or invalid arguments return a tool error result. Use
  `tools/list` to confirm the current name and fields.
- `GET` and `DELETE` return `405` with a JSON-RPC error payload.
- Requests do not share a session. Send credentials on every request.
- In Lens Assistant, destructive `approve` tools require explicit human
  confirmation; agents should not auto-approve them.
