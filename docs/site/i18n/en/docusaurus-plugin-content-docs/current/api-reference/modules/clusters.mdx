## Backend API

Cluster management routes come from `llm_d_lens/cluster/router.py`, `llm_d_lens/cluster/bootstrap/router.py`, and `llm_d_lens/cluster/sdk_discovery.py`.

### List clusters

List Lens-managed clusters and optionally include draft records that have not been finalized yet. The route also computes a `ready` flag per cluster by probing its Kubernetes API reachability.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/cluster/clusters`**

    Request: no request body.

    - `includeDrafts` (`boolean`, query, default `false`): include draft cluster records.

    Response: `ClustersResponse` with one `ClusterRecord` per visible cluster.

`hfTokenSecret` reports the namespace and name of the cluster's HF_TOKEN Secret, or `null` when the cluster has none. Only the location is returned; the token value stays on the target cluster and is never served by the API.

    ```json
    {
      "items": [
        {
          "id": "cluster-a",
          "name": "Primary cluster",
          "description": "Shared production GPU cluster",
          "createdAt": "2026-09-20T10:15:00Z",
          "ready": true,
          "proxy": {
            "mode": "custom",
            "httpProxy": "http://proxy.example:3128",
            "httpsProxy": "http://proxy.example:3128",
            "noProxy": "127.0.0.1,localhost,.svc"
          },
          "llmDRef": "v0.3.0",
          "llmDBenchmarkRef": "main",
          "llmDRepoPath": "/cache/llm-d/v0.3.0",
          "llmDBenchmarkRepoPath": "/cache/llm-d-benchmark/main",
          "hfTokenSecret": {
            "namespace": "llm-d-bench-storage-44395349",
            "name": "hf-token-c758ced0"
          },
          "draft": false
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import service

    async def main() -> None:
        clusters = service.list_clusters(include_drafts=True)
        ready_flags = await asyncio.gather(*(service.cluster_is_ready(cluster) for cluster in clusters))
        for cluster, ready in zip(clusters, ready_flags):
            print(cluster.id, cluster.name, ready)

    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### Register a cluster

Register a cluster from an uploaded kubeconfig file. The route accepts multipart form data, stores the cluster record, and returns the new cluster plus any created Lens session id.

llm-d component versions are fixed by the Lens stack profile (see [Get supported llm-d versions](#get-supported-llm-d-versions)); `llmDRef`, `llmDBenchmarkRef`, `routerVersion`, `gieVersion` and `ippVersion` are accepted for compatibility but ignored.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters`**

    Request: multipart form-data, not JSON.

    - `name` (`string`, form): cluster display name.
    - `description` (`string`, form, optional): free-form description.
    - `file` (`file`, form): UTF-8 kubeconfig upload.
    - `proxy` (`string`, form, optional): JSON string matching `ProxyConfigDTO`.
    - `llmDRef` (`string`, form, optional): ignored — the `llm-d` version comes from the stack profile.
    - `llmDBenchmarkRef` (`string`, form, optional): ignored — the `llm-d-benchmark` version comes from the stack profile.
    - `gatewayProvider` (`string`, form, optional): shared Gateway provider (`envoy-ai-gateway` | `istio` | `agentgateway` | `gke`).
    - `gatewayPublicUrl` (`string`, form, optional): externally reachable host/IP clients use for the Gateway — Lens adds `http://` + the exposed port + `/v1`. Empty derives it from the exposed port and the cluster node.
    - `gatewayPort` (`integer`, form, optional): NodePort the shared Gateway is exposed on (30000–32767).
    - `gatewayAuthzHost` (`string`, form): the host/IP this cluster uses to reach Lens (required for providers with a Lens address hook: `envoy-ai-gateway`/`istio`/`agentgateway`). Pick from `GET /api/cluster/lens-hosts`; Lens adds its own serving port, and when empty Lens fills in this host's address.
    - `inotifyMaxUserInstances` (`integer`, form, default `8192`): per-uid inotify instance limit Lens applies to every node (`fs.inotify.max_user_instances`). Lift it above kind's 128 default on nodes running many pods.
    - `draft` (`boolean`, form, default `false`): create as draft.

    Example field values:

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "file": "<uploaded kubeconfig.yaml UTF-8 file>",
      "proxy": "{"mode":"custom","httpProxy":"http://proxy.example:3128","httpsProxy":"http://proxy.example:3128","noProxy":"127.0.0.1,localhost,.svc"}",
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": true
    }
    ```

    Response: `CreateClusterResponse`.

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": false,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",
          "noProxy": "127.0.0.1,localhost,.svc"
        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": true
      },
      "sessionId": "f4c15c0a-8c1f-4eb7-b4d7-ef83f22c2e9b"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster import service

    kubeconfig_text = """
    apiVersion: v1
    kind: Config
    clusters: []
    contexts: []
    current-context: ""
    users: []
    """.strip()

    cluster, session = service.create_cluster(
        "Primary cluster",
        "Shared production GPU cluster",
        kubeconfig_text,
        proxy_mode="custom",
        http_proxy="http://proxy.example:3128",
        https_proxy="http://proxy.example:3128",
        no_proxy="127.0.0.1,localhost,.svc",
        llm_d_ref="v0.3.0",
        llm_d_lensmark_ref="main",
        draft=True,
    )

    print(cluster.id, session.id)
    ```
  </TabItem>
</Tabs>

### Update a cluster

Patch a cluster's editable settings, including name, description, proxy settings, and draft status. The kubeconfig itself is not part of this patch contract. Version fields (`llmDRef`, `llmDBenchmarkRef`, `routerVersion`, `gieVersion`, `ippVersion`) are server-managed from the stack profile and ignored on input.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`PATCH /api/cluster/clusters/{cluster_id}`**

    Request body (`ClusterSettingsUpdateRequest`):

    - `name` (`string`, optional)
    - `description` (`string`, optional)
    - `proxy` (`ProxyConfigDTO`, optional)
    - `llmDRef` (`string`, optional)
    - `llmDBenchmarkRef` (`string`, optional)
    - `gatewayProvider` (`string`, optional)
    - `gatewayPort` (`integer`, optional)
    - `gatewayPublicUrl` (`string`, optional): externally reachable Gateway host/IP — Lens adds the exposed port; empty derives it.
    - `gatewayAuthzHost` (`string`): the host/IP this cluster uses to reach Lens (required for providers with a Lens address hook; Lens adds its own serving port; empty fills in this host's address).
    - `inotifyMaxUserInstances` (`integer`, optional): per-uid inotify instance limit applied to every node (default `8192`).
    - `draft` (`boolean`, optional)

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "proxy": {
        "mode": "custom",
        "httpProxy": "http://proxy.example:3128",
        "httpsProxy": "http://proxy.example:3128",
        "noProxy": "127.0.0.1,localhost,.svc"
      },
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": false
    }
    ```

    Response: `CreateClusterResponse` with the updated record.

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": true,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",

        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": false
      },
      "sessionId": null
    }
    ```
  </TabItem>

### Create the cluster HF_TOKEN secret

Create a standalone Kubernetes Secret holding a Hugging Face token on the target cluster, and record its coordinates on the Lens cluster record so Deployments and Model Cache downloads default to it. This is the Create cluster wizard's Model cache step. The token value is written to the cluster only; Lens stores just the namespace and name. The request fails with `409 secret_already_exists` when the Secret is already present — use the rotation endpoint below to replace an existing token.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/hf-token-secrets`**

    Request body (`HfTokenSecretCreateRequest`):

    - `namespace` (`string`, required): namespace to create the Secret in; created when missing.
    - `name` (`string`, required): Secret name.
    - `token` (`string`, required): Hugging Face token stored under the `HF_TOKEN` key.

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0",
      "token": "hf_exampleTokenValue"
    }
    ```

    Response: `HfTokenSecretRef`.

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import registry, service

    cluster = registry.get_cluster("cluster-a")
    ref = asyncio.run(
        service.create_hf_token_secret(
            cluster,
            "llm-d-bench-storage-44395349",
            "hf-token-c758ced0",
            "hf_exampleTokenValue",
        )
    )
    print(ref["namespace"], ref["name"])
    ```
  </TabItem>
</Tabs>

### Rotate the cluster HF_TOKEN secret

Replace the Hugging Face token stored in the cluster's `HF_TOKEN` Secret, from the Edit cluster drawer. Unlike creation this applies the Secret, so an existing one is overwritten rather than rejected. `namespace` and `name` default to the coordinates already recorded on the cluster (`hfTokenSecret`), so rotating a token needs only the token; supplying different coordinates repoints the cluster at that Secret and creates it when absent.

Rotation rewrites only this cluster-level Secret. The namespace-local `llm-d-hf-token` copies that Deployments and Model Cache downloads derive at run time are re-derived on the next deployment or download, so workloads that are already running keep the previous token until they are recreated.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`PUT /api/cluster/clusters/{cluster_id}/hf-token-secret`**

    Request body (`HfTokenSecretUpdateRequest`):

    - `namespace` (`string`, optional): defaults to the cluster's recorded secret namespace.
    - `name` (`string`, optional): defaults to the cluster's recorded secret name.
    - `token` (`string`, required): new Hugging Face token; a blank value is rejected with `422 invalid_secret_token`.

    ```json
    {
      "token": "hf_rotatedTokenValue"
    }
    ```

    Response: `HfTokenSecretRef` with the coordinates that were written.

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import registry, service

    cluster = registry.get_cluster("cluster-a")
    # Rotate in place, reusing the coordinates recorded on the cluster.
    ref = asyncio.run(service.update_hf_token_secret(cluster, "hf_rotatedTokenValue"))
    print(ref["namespace"], ref["name"])

    # Or repoint the cluster at a different Secret.
    ref = asyncio.run(
        service.update_hf_token_secret(
            cluster,
            "hf_rotatedTokenValue",
            namespace="llm-d-bench-storage-44395349",
            name="hf-token-rotated",
        )
    )
    ```
  </TabItem>
</Tabs>

### Start cluster software downloads

Start downloading the `llm-d` and `llm-d-benchmark` revisions pinned by the Lens stack profile for a cluster. The handler schedules background downloads and immediately returns the current status snapshot; the request body is ignored.

Source checkouts are isolated by repository URL and resolved commit. Branch downloads refresh the remote ref; previously cached full commit SHAs can be reused offline. A per-source lock and atomic publication prevent concurrent requests from exposing incomplete checkouts or replacing an earlier snapshot.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/software-downloads`**

    Request body (`SoftwareDownloadRequest`): optional and ignored — the profile-pinned revisions are downloaded.

    ```json
    {}
    ```

    Response: `SoftwareDownloadStatusResponse`.

    ```json
    {
      "llmD": {
        "ref": "v0.2.0",
        "state": "downloading",
        "path": null,
        "error": null
      },
      "llmDBenchmark": {
        "ref": "main",
        "state": "downloading",
        "path": null,
        "error": null
      }
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster.router import _download_and_record
    from llm_d_lens.cluster import repo_downloads

    async def main() -> None:
        await _download_and_record("cluster-a", "llm-d", "v0.2.0")
        await _download_and_record("cluster-a", "llm-d-benchmark", "main")
        print(repo_downloads.get_status("cluster-a", "llm-d"))
        print(repo_downloads.get_status("cluster-a", "llm-d-benchmark"))

    asyncio.run(main())
    ```

### Start cluster image pre-pull

Pre-pull the pinned llm-d images for the selected accelerators onto every cluster node. The images are the llm-d-router EPP and P/D sidecar plus the model-server image(s) for the accelerators; versions come from the Lens stack profile, not the request. A privileged DaemonSet runs the host's `crictl` per node; poll the GET below for per-node readiness.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/images/prepull`**

    Request body:

    - `accelerators` (`string[]`): accelerator ids whose model-server image should be pulled (e.g. `["nvidia","intel"]`).

    ```json
    {
      "accelerators": ["nvidia", "intel"]
    }
    ```

    Response: overall state, `ready`/`desired` node counts, the image list and per-node readiness.

    ```json
    {
      "state": "pulling",
      "desired": 2,
      "ready": 1,
      "images": [
        { "name": "ghcr.io/llm-d/llm-d-router-endpoint-picker:v0.11.0", "ready": 2, "desired": 2, "state": "ready" },
        { "name": "ghcr.io/llm-d/llm-d-router-disagg-sidecar:v0.11.0", "ready": 2, "desired": 2, "state": "ready" },
        { "name": "ghcr.io/llm-d/llm-d-cuda:v0.9.0", "ready": 1, "desired": 2, "state": "pulling" }
      ],
      "nodes": [{ "node": "worker-1", "phase": "Running", "ready": true, "restarts": 0 }]
    }
    ```

    `images[].state` is `ready` when every node pulled that image, `pulling` while in progress and `failed` if a node's pull crash-loops.
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster import images

    status = await images.start_image_prepull("cluster-a", ["nvidia", "intel"])
    print(status["state"], status["ready"], status["desired"])
    ```
  </TabItem>
</Tabs>

### Delete a cluster

Delete a Lens-managed cluster record and clean up related state. This should only be used when the cluster should be removed from Lens entirely.

Remote cleanup performed by this endpoint:

- The cluster's `HF_TOKEN` secret recorded in `hfTokenSecret` is deleted, and its namespace is deleted with it when the namespace has no reason to outlive the cluster. That is the case for the Lens-owned `llm-d-bench-storage-{cluster_id}` namespace, for any namespace Lens created for the secret (labelled `app.kubernetes.io/managed-by: llm-d-lens`), and for a namespace that, once the secret is gone, holds nothing but the objects Kubernetes and cluster add-ons inject into every namespace (the `default` service account, its token secret, and CA-bundle config maps such as `kube-root-ca.crt`). A namespace that still holds any other object -- including a custom resource -- is kept, and `default`, `kube-system`, `kube-public` and `kube-node-lease` are never deleted. If the namespace contents cannot be listed, the namespace is kept.
- For a draft cluster, every Storage volume still attached to it is removed together with its `PersistentVolumeClaim` and `PersistentVolume` objects. Model files on the underlying NFS or host-path storage are kept, because the `PersistentVolume` uses the `Retain` reclaim policy.

All remote cleanup is best-effort: a failure is logged and the Lens record is still deleted, so an unreachable cluster never becomes permanently undeletable. A non-draft cluster that still has Storage volumes is rejected instead; delete its volumes first.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`DELETE /api/cluster/clusters/{cluster_id}`**

    Request: no request body.

    - `cluster_id` (`string`, path): target cluster id.

    Response: `204 No Content`. This endpoint does not return a JSON body.
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python

    from llm_d_lens.cluster import service

    async def main() -> None:
        await service.delete_cluster("cluster-a")

    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### Start a bootstrap job

Start a long-running Kubespray-based cluster bootstrap job after preflight succeeds. The response returns the bootstrap job id immediately while the real provisioning continues in the background.

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/bootstrap`**

    Request body (`BootstrapCreateRequest`):

    - `nodes` (`BootstrapNodeInput[]`): the nodes to provision.
    - `hostKeys` (`BootstrapHostKeyPin[]`): the exact confirmed fingerprint for every expanded `host:port`.
    - `proxy` (`BootstrapProxyConfig`, optional): target-node proxy configuration.

    ```json
    {
      "nodes": [
        {
          "host": "10.0.0.1",
          "port": 22,
          "roles": [
            "control-plane"
          ],
          "username": "root"
        },
        {
          "host": "10.0.0.2",
          "port": 22,
          "roles": [
            "worker"
          ],
          "username": "root"
        }
      ],
      "hostKeys": [
        { "host": "10.0.0.1", "port": 22, "fingerprint": "SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA" },
        { "host": "10.0.0.2", "port": 22, "fingerprint": "SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB" }
      ],
      "proxy": {
        "mode": "custom",
        "httpProxy": "http://proxy.example:3128",
        "httpsProxy": "http://proxy.example:3128",
        "noProxy": "127.0.0.1,localhost,.svc"
      }
    }
    ```

    Response: `BootstrapCreateResponse`.

    ```json
    {
      "bootstrapId": "bootstrap-5b7fd3a81290"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster.bootstrap.dto import BootstrapHostKeyPin, BootstrapNodeInput, BootstrapProxyConfig
    from llm_d_lens.cluster.bootstrap import service

    async def main() -> None:
      pins = [
        BootstrapHostKeyPin(host="10.0.0.1", port=22, fingerprint="SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"),
        BootstrapHostKeyPin(host="10.0.0.2", port=22, fingerprint="SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB"),
      ]
        job = service.create_job(
            [
                BootstrapNodeInput(host="10.0.0.1", roles=["control-plane"]),

                httpsProxy="http://proxy.example:3128",
                noProxy="127.0.0.1,localhost,.svc",
            ),
        )
        await service.run_bootstrap_job(job.id)
        print(job.id)

    asyncio.run(main())
    ```
