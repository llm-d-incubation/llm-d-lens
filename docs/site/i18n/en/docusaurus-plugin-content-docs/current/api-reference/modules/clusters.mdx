## Overview

Clusters connects Lens to the Kubernetes clusters you deploy and benchmark on.
Register a cluster before caching models, starting deployments, or reading cluster
health. Use this module to upload a kubeconfig, finish draft registrations, prepare
Gateway, LeaderWorkerSet, CRD, and image dependencies, bootstrap new machines,
rotate Hugging Face access, and inspect capacity, nodes, and versions.

## Quick start

List the clusters visible to you and confirm which are reachable.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        clusters = await lens.clusters.list_clusters()
        for cluster in clusters.items:
            print(cluster.id, cluster.name, cluster.ready)


asyncio.run(main())
```

  </TabItem>
</Tabs>

Draft clusters are hidden by default. Pass `includeDrafts=true` in REST or
`include_drafts=True` in the SDK to include them.

## Common tasks

### Register a cluster from a kubeconfig

`POST /api/v1/cluster/clusters` uses multipart form data, not JSON. It returns `201`
with the new cluster and, when a session is created, its `sessionId`.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -F "name=<cluster-name>" \
  -F "file=@<kubeconfig-path>" \
  "$LENS_URL/api/v1/cluster/clusters"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio
from io import BytesIO
from pathlib import Path

from starlette.datastructures import UploadFile

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        response = await lens.clusters.create_cluster(
            file=UploadFile(
                filename="kubeconfig.yaml",
                file=BytesIO(Path("<kubeconfig-path>").read_bytes()),
            ),
            name="<cluster-name>",
        )
        print(response.cluster.id, response.session_id)


asyncio.run(main())
```

  </TabItem>
</Tabs>

The kubeconfig must be a UTF-8 file. llm-d component versions come from the Lens
release, not from the request, so `llmDRef` and `llmDBenchmarkRef` are ignored.
Add `draft=true` to register the cluster before it is ready to use.

### Complete or edit a registration

Use `PATCH` to rename a cluster, change its description or proxy, or flip a draft
to a finalized cluster. Only supplied fields change.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X PATCH -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"<cluster-name>","draft":false}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import ClusterSettingsUpdateRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        response = await lens.clusters.update_cluster(
            "<cluster-id>",
            ClusterSettingsUpdateRequest(name="<cluster-name>", draft=False),
        )
        print(response.cluster.id, response.cluster.ready)


asyncio.run(main())
```

  </TabItem>
</Tabs>

A Gateway provider can be assigned once. After that, changing it returns
`422 gateway_provider_immutable`. The Gateway port must be in `30000`-`32767`.

### Prepare Gateway and image dependencies

Apply the pinned Gateway API CRDs and LeaderWorkerSet controller, then pre-pull
the router and accelerator images. These operations are idempotent. Poll the
matching `GET` endpoints for progress.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# Apply the pinned Gateway API / GIE CRDs.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/crds"

# Install or upgrade LeaderWorkerSet.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/lws"

# Pre-pull router and model-server images for the selected accelerators.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"accelerators":["nvidia"]}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/images/prepull"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import ImagePrepullRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        await lens.clusters.create_cluster_crds("<cluster-id>")
        await lens.clusters.install_cluster_lws("<cluster-id>")

        status = await lens.clusters.create_cluster_image_prepull(
            "<cluster-id>",
            ImagePrepullRequest(accelerators=["nvidia"]),
        )
        print(status.state, status.ready, status.desired)


asyncio.run(main())
```

  </TabItem>
</Tabs>

Image pre-pull uses a privileged DaemonSet and can take several minutes per node.
A failed image state means at least one node is crash-looping its puller.

### Set or rotate the Hugging Face token

Store a Hugging Face token on the cluster so Model Cache downloads and private
model deployments can use it. `PUT` rotates the token in place; omit `namespace`
and `name` to reuse the Secret already recorded on the cluster.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X PUT -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"token":"<hf-token>"}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/hf-token-secret"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import HfTokenSecretUpdateRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        ref = await lens.clusters.update_hf_token_secret(
            "<cluster-id>",
            HfTokenSecretUpdateRequest(token="<hf-token>"),
        )
        print(ref.namespace, ref.name)


asyncio.run(main())
```

  </TabItem>
</Tabs>

If the cluster has no Secret yet, create one with
`POST /api/v1/cluster/clusters/{cluster_id}/hf-token-secrets`. Creating an existing
Secret returns `409 secret_already_exists`; use `PUT` to rotate it instead. A
blank token returns `422 invalid_secret_token`. Running workloads keep the old
token until they are recreated.

### Bootstrap bare-metal machines

Discover and pin SSH host keys, run preflight, then start the Kubespray job.
Preflight must pass before bootstrap starts. The job returns a `bootstrapId`
immediately while provisioning continues in the background.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# 1. Discover host keys without authenticating.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap/host-keys"

# 2. Pin the returned fingerprints and run preflight.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22,"roles":["worker"],"username":"root","password":"<ssh-password>"}],"hostKeys":[{"host":"<ip>","port":22,"fingerprint":"SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap/preflight"

# 3. After allPassed is true, start the job.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22,"roles":["worker"],"username":"root","password":"<ssh-password>"}],"hostKeys":[{"host":"<ip>","port":22,"fingerprint":"SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap"

# 4. Poll until phase is succeeded; the response then carries the kubeconfig.
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/bootstrap/<bootstrap-id>"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.bootstrap.dto import (
    BootstrapCreateRequest,
    BootstrapHostKeyPin,
    BootstrapHostKeyRequest,
    BootstrapHostAddress,
    BootstrapNodeInput,
    BootstrapPreflightRequest,
)
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        keys = await lens.cluster_bootstrap.discover_host_keys(
            BootstrapHostKeyRequest(nodes=[BootstrapHostAddress(host="<ip>", port=22)])
        )
        print([(item.host, item.fingerprint) for item in keys.items])

        node = BootstrapNodeInput(
            host="<ip>",
            roles=["worker"],
            username="root",
            password="<ssh-password>",
        )
        pin = BootstrapHostKeyPin(
            host="<ip>",
            port=22,
            fingerprint="SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA",
        )
        preflight = await lens.cluster_bootstrap.preflight(
            BootstrapPreflightRequest(nodes=[node], host_keys=[pin])
        )
        if preflight.all_passed:
            job = await lens.cluster_bootstrap.start_bootstrap(
                BootstrapCreateRequest(nodes=[node], host_keys=[pin])
            )
            print(job.bootstrap_id)


asyncio.run(main())
```

  </TabItem>
</Tabs>

SSH credentials are used only for preflight and bootstrap. Compare host-key
fingerprints with a trusted source before pinning them. Cancel a job with
`POST /api/v1/cluster/bootstrap/{bootstrap_id}/cancel`.

### Check cluster health

Read the live node, accelerator, capacity, and component summary, plus the
Kubernetes version check against the Lens minimum.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/overview?clusterId=<cluster-id>"

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/kubernetes-version"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        overview = await lens.clusters.overview(cluster_id="<cluster-id>")
        version = await lens.clusters.read_cluster_kubernetes_version("<cluster-id>")

        print(overview.kubernetes.hardware.accelerators)
        print(version.version, version.supported)


asyncio.run(main())
```

  </TabItem>
</Tabs>

Capacity fields can be `null` when a reading is unavailable; `null` means unknown,
not zero. `ready` is a reachability probe and does not guarantee free GPUs.

### Bootstrap

| Method | Path | Permission | Purpose |
| --- | --- | --- | --- |
| POST | `/api/v1/cluster/bootstrap/host-keys` | `cluster:bootstrap:execute` | Discover SSH host keys for target machines. |
| POST | `/api/v1/cluster/bootstrap/preflight` | `cluster:bootstrap:execute` | Validate SSH, sudo, and node prerequisites. |
| POST | `/api/v1/cluster/bootstrap` | `cluster:bootstrap:execute` | Start a Kubespray bootstrap job. |
| GET | `/api/v1/cluster/bootstrap/{bootstrap_id}` | `cluster:bootstrap:read` | Read job status and the kubeconfig handoff. |

Most reads return `200`. Registration and HF Secret creation return `201`;
software-download and bootstrap creation return `202`; cluster deletion and
bootstrap cancellation return `204`.

## Errors and limits

- **`401` / `403`** — missing authentication or no access to the cluster.
  Administrators can manage every cluster; maintainers only assigned clusters.
- **`404`** — unknown cluster, missing bootstrap job, or an inactive session.
- **`409 cluster_has_available_deployments`** or
  **`cluster_has_storage_volumes`** — the cluster still has resources. Delete
  those first.
- **`422 invalid_kubeconfig`** — the uploaded file is not UTF-8 text.
- **`422 invalid_proxy_config`** — `proxy` is not valid JSON.
- **`422 invalid_gateway_port`** or **`gateway_port_in_use`** — choose a free
  NodePort in `30000`-`32767`.
- **`422 gateway_provider_immutable`** — a Gateway provider can only be assigned
  once.
- **`422 invalid_secret_token`** — the Hugging Face token is blank.
- **`409 secret_already_exists`** — the Secret exists; rotate it with `PUT`.
- **`502 cluster_gateway_cleanup_failed`** — Gateway cleanup failed and the
  registration was kept. Retry deletion.
- **`503 kubectl_unavailable`** or **`504 kubectl_timeout`** — Lens cannot reach
  the cluster API. Check the kubeconfig, network, and proxy.
- Component versions are fixed by the Lens release. Request version fields do
  not override them.
- Cordon only blocks new pods. It does not evict or stop running pods.
