Use Simulation to replay a registered trace dataset against a deployment, a published Model Service, or an endpoint URL. Reach for it when you need measured throughput, latency, and per-request errors for a realistic workload; use Evaluation for benchmark suites.

## Quick start

List the backends Lens can use in the current environment, then choose one whose `available` value is `true`.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/simulation/backends
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        response = await lens.simulation.backends_catalog()
        for backend in response.backends:
            print(backend.name, backend.available, backend.scenarios)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## Common tasks

### 1. Find a trace dataset and its replay shape

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/simulation/trace-datasets

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/simulation/trace-datasets/mooncake-arxiv/timeline?bins=200"
```

Use `data_dir`, `datasets[].downloaded`, and `datasets[].supported_backends` to pick a dataset. The timeline returns `request_count`, `duration_seconds`, and `bins`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        datasets = await lens.simulation.trace_datasets_catalog()
        for dataset in datasets.datasets:
            print(dataset.name, dataset.downloaded, dataset.supported_backends)

        timeline = await lens.simulation.trace_dataset_timeline("mooncake-arxiv", bins=200)
        print(timeline.request_count, timeline.duration_seconds)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 2. Download a trace dataset

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/simulation/trace-datasets/download \
  -d '{"dataset":"mooncake-arxiv","force":false}'
```

The response returns `path`, `artifact_uri`, `trace_format`, `size_bytes`, and `sha256`. Set `force` to `true` only when you want to replace an existing download.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal
from llm_d_lens.simulation.models import TraceDatasetDownloadRequest

with LensLocal("<username>") as lens:
    async def main() -> None:
        result = await lens.simulation.download_trace_dataset(
            TraceDatasetDownloadRequest(dataset="mooncake-arxiv", force=False)
        )
        print(result.path, result.sha256, result.size_bytes)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 3. Discover models at an endpoint

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/simulation/models/discover \
  -d '{"endpoint_url":"http://<host>:<port>/v1","api_key":"<token>"}'
```

The response contains `endpoint` and `models`. The optional `api_key` is sent as a Bearer token and is not returned.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal
from llm_d_lens.simulation.models import ModelDiscoveryRequest

with LensLocal("<username>") as lens:
    async def main() -> None:
        models = await lens.simulation.endpoint_models(
            ModelDiscoveryRequest(endpoint_url="http://<host>:<port>/v1", api_key="<token>")
        )
        print(models.endpoint, models.models)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 4. Create a replay task

Create a task against a ready deployment execution:

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/simulation/tasks \
  -d '{
    "name": "Chat replay",
    "scenario": "chat",
    "backend": "trace-replayer",
    "endpoint_mode": "deployment",
    "endpoint_deployment_execution_id": "<execution-id>",
    "endpoint_cluster_id": "<cluster-id>",
    "endpoint_url": "http://<host>:<port>/v1",
    "model_name": "Qwen/Qwen3-8B",
    "trace_dataset": "mooncake-arxiv",
    "trace_path": "<dataset-path>",
    "duration_seconds": 60
  }'
```

This returns `202 Accepted` with `task_id`, `status`, and `task`. To target a published Model Service instead, send `model_service_group_id` and `api_key`; the backend resolves the active member and published model name. Endpoint URL tasks are validated through `/v1/models` before the task is queued.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal
from llm_d_lens.simulation.models import SimulationTaskCreateRequest

with LensLocal("<username>") as lens:
    async def main() -> None:
        response = await lens.simulation.create_simulation_task(
            SimulationTaskCreateRequest(
                name="Chat replay",
                scenario="chat",
                backend="trace-replayer",
                endpoint_mode="deployment",
                endpoint_deployment_execution_id="<execution-id>",
                endpoint_cluster_id="<cluster-id>",
                endpoint_url="http://<host>:<port>/v1",
                model_name="Qwen/Qwen3-8B",
                trace_dataset="mooncake-arxiv",
                trace_path="<dataset-path>",
                duration_seconds=60,
            )
        )
        print(response.task_id, response.status, response.task.id)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 5. Watch progress and read results

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>/response-code-issues?status_code=500&limit=20"

curl -H "Authorization: Bearer $LENS_TOKEN" \
  -OJ http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>/artifacts/summary-json
```

Read `status`, `progress_percent`, `result.summary`, and `result.artifacts`. Use `status_code=unknown` for requests with no HTTP status. The response-code endpoint returns `issues`; the SDK exposes the same list as `.items`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        task = await lens.simulation.simulation_task("<task-id>")
        print(task.status, task.progress_percent, task.result.summary)

        issues = await lens.simulation.simulation_response_code_issues(
            "<task-id>", status_code="500", limit=20
        )
        print(issues.total, len(issues.items))

        artifact = await lens.simulation.download_simulation_artifact("<task-id>", "summary-json")
        print(artifact.media_type)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 6. Stop, rerun, or delete a task

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>/stop

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>/rerun \
  -d '{"endpoint_deployment_execution_id":"<new-execution-id>"}'

curl -X DELETE -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/simulation/tasks/<task-id>
```

Stop returns `status: "cancelling"`. Rerun returns `202 Accepted` with a new task id. Delete returns `status: "deleted"` and only succeeds after the task has stopped.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal
from llm_d_lens.simulation.models import SimulationTaskRerunRequest

with LensLocal("<username>") as lens:
    async def main() -> None:
        await lens.simulation.stop_simulation_task("<task-id>")

        rerun = await lens.simulation.rerun_simulation_task(
            "<task-id>",
            SimulationTaskRerunRequest(endpoint_deployment_execution_id="<new-execution-id>"),
        )
        print(rerun.task_id, rerun.status)

        await lens.simulation.delete_simulation_task("<task-id>")

    asyncio.run(main())
```

</Tabs>

## Endpoints

| Method | Path | Permission | Purpose |
| --- | --- | --- | --- |
| GET | `/api/v1/simulation/backends` | `simulation:task:read` | List usable backends and scenarios. |
| POST | `/api/v1/simulation/models/discover` | `simulation:task:create` | Probe `/v1/models` at an endpoint. |
| GET | `/api/v1/simulation/scenarios` | `simulation:task:read` | List replay scenarios. |
| GET | `/api/v1/simulation/trace-datasets` | `simulation:task:read` | List trace datasets. |
| POST | `/api/v1/simulation/trace-datasets/download` | `simulation:dataset:download` | Download a dataset. |
| GET | `/api/v1/simulation/trace-datasets/{dataset_name}/timeline` | `simulation:task:read` | Read a dataset timeline. |
| GET | `/api/v1/simulation/tasks` | `simulation:task:read` | List tasks. REST uses `status`; SDK uses `task_status`. |
| POST | `/api/v1/simulation/tasks` | `simulation:task:create` | Create a task (`202`). |
| GET | `/api/v1/simulation/tasks/{task_id}` | `simulation:task:read` | Get one task and its result. |
| GET | `/api/v1/simulation/tasks/{task_id}/artifacts/{kind}` | `simulation:artifact:download` | Download an artifact. |
| GET | `/api/v1/simulation/tasks/{task_id}/response-code-issues` | `simulation:task:read` | List requests by status code. |
| POST | `/api/v1/simulation/tasks/{task_id}/stop` | `simulation:task:stop` | Stop a running task. |
| POST | `/api/v1/simulation/tasks/{task_id}/rerun` | `simulation:task:rerun` | Queue a rerun (`202`). |
| DELETE | `/api/v1/simulation/tasks/{task_id}` | `simulation:task:delete` | Delete a stopped task. |

## Errors / limits

- **400**: invalid endpoint URL, failed endpoint discovery or authentication, unknown backend, missing trace file, or invalid trace range.
- **401 / 403**: missing or expired authentication, missing permission, or no access to the task's cluster.
- **404**: unknown task, dataset, or artifact; **409**: the dataset timeline is not ready, or you tried to delete an active task.
- **429**: the concurrent trace download limit is reached (default 1; set `SIMULATION_MAX_CONCURRENT_DOWNLOADS` on the backend).
- **422**: invalid query values. Task list `limit` is 1-100, timeline `bins` is 50-2000, and response-code `limit` is at most 500.
- Endpoint URL tasks must pass `/v1/models`; entering a model name manually does not bypass that check. A Model Service target also requires `api_key`.
- Create and rerun return `202`; poll the task until it is `completed`, `failed`, or `cancelled` before downloading artifacts.
