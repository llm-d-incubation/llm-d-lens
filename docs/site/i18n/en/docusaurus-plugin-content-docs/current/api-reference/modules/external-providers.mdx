## What this module is

External providers are saved outbound AI connections that Lens uses as a client — for example OpenAI, Anthropic, or a self-hosted OpenAI-compatible server. Use this module to test a connection, save and update provider settings, send a chat completion through a saved provider, and remove connections you no longer need. Stored API keys are never returned; responses expose only `hasApiKey` and `apiKeyPreview`.

## Quick start

Test a draft configuration first, then save it. Provider calls go from the Lens backend to the provider, so the URL must be reachable and public.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST "$LENS_URL/api/v1/ai-providers/test" \
  -H "Content-Type: application/json" \
  -d '{"baseUrl":"https://api.openai.com/","model":"gpt-4o-mini","apiKey":"<token>","providerType":"openai"}'

curl -X POST "$LENS_URL/api/v1/ai-providers" \
  -H "Content-Type: application/json" \
  -d '{"name":"OpenAI","baseUrl":"https://api.openai.com/","model":"gpt-4o-mini","apiKey":"<token>","providerType":"openai","timeoutSeconds":30}'
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderCreateRequest, AIProviderTestRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        result = await lens.external_providers.test_draft_provider(
            AIProviderTestRequest(
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
            )
        )
        print(result.success, result.message)

        provider = await lens.external_providers.create_provider(
            AIProviderCreateRequest(
                name="OpenAI",
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
                timeoutSeconds=30,
            )
        )
        print(provider.id, provider.has_api_key)

    asyncio.run(main())
```

</Tabs>

## Common tasks

### Test a configuration before saving

The test probes the provider's model list and reports whether the configured model was found. An unreachable provider returns `200` with `success: false`; check the result rather than relying only on the HTTP status.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers/test`**

```json
{
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "apiKey": "<token>",
  "providerType": "openai",
  "timeoutSeconds": 15
}
```

```json
{
  "success": true,
  "message": "Connected successfully.",
  "modelFound": true,
  "availableModels": ["gpt-4o-mini"],
  "latencyMs": 182.4
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderTestRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        result = await lens.external_providers.test_draft_provider(
            AIProviderTestRequest(
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
            )
        )
        print(result.success, result.model_found, result.latency_ms)

    asyncio.run(main())
```

### Save a provider connection

Save a durable connection for Lens Assistant and other agentic features. Provider names are unique, ignoring case; a duplicate returns `409 ai_provider_name_conflict`.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers`**

```json
{
  "name": "OpenAI",
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "apiKey": "<token>",
  "providerType": "openai",
  "timeoutSeconds": 30
}
```

Response (`201`):

```json
{
  "id": "ai-provider-7f3a2c1d",
  "name": "OpenAI",
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "providerType": "openai",
  "timeoutSeconds": 30,
  "hasApiKey": true,
  "apiKeyPreview": "...cdef"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderCreateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        provider = await lens.external_providers.create_provider(
            AIProviderCreateRequest(
                name="OpenAI",
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
                timeoutSeconds=30,
            )
        )
        print(provider.id, provider.model, provider.has_api_key)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### Update a provider or rotate its key

All fields are optional. Omit `apiKey` to keep the stored key, or send an empty string to clear it.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`PUT /api/v1/ai-providers/{provider_id}`**

```json
{
  "model": "gpt-4.1-mini",
  "timeoutSeconds": 45,
  "apiKey": "<token>"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderUpdateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        provider = await lens.external_providers.update_provider(
            "<provider-id>",
            AIProviderUpdateRequest(
                model="gpt-4.1-mini",
                timeoutSeconds=45,
                apiKey="<token>",
            ),
        )
        print(provider.id, provider.model)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### Send a chat completion through a saved provider

The server forwards an OpenAI-style body with the saved key attached and fills in the saved model when `model` is omitted. Only `openai`-type providers support this route.

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers/{provider_id}/chat/completions`**

```json
{
  "messages": [
    {
      "role": "user",
      "content": "Give me a one-line health summary."
    }
  ]
}
```

The response is the upstream provider's JSON.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        response = await lens.external_providers.proxy_chat_completions(
            "<provider-id>",
            {"messages": [{"role": "user", "content": "Say hello in one sentence."}]},
        )
        print(response)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### Test a saved provider

This reuses the stored URL, model, key and timeout. Use it after editing a provider or when diagnosing a connection problem.

  <TabItem value="rest-api" label="REST API">

```bash

```

The response has the same shape as a draft test.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

    import asyncio

    async def main() -> None:
        result = await lens.external_providers.test_saved_provider("<provider-id>")

    asyncio.run(main())

### Delete a provider

Deleting removes the saved configuration and its stored key. It does not affect the external provider itself.

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X DELETE "$LENS_URL/api/v1/ai-providers/<provider-id>"
```

Response: `204 No Content`.

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        await lens.external_providers.delete_provider("<provider-id>")

    asyncio.run(main())
```

</Tabs>

## Endpoints

| Method | Path | Permission | Purpose |
| --- | --- | --- | --- |
| GET | `/api/v1/ai-providers` | `ai-provider:provider:read` | List saved providers with masked keys. |
| GET | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:read` | Get one saved provider. |
| POST | `/api/v1/ai-providers` | `ai-provider:provider:create` | Save a new provider connection. |
| PUT | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:update` | Update a provider; rotate or clear its key. |
| DELETE | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:delete` | Delete a saved provider. |
| POST | `/api/v1/ai-providers/test` | `ai-provider:provider:test` | Test an unsaved configuration. |
| POST | `/api/v1/ai-providers/{provider_id}/test` | `ai-provider:provider:test` | Test a saved provider. |
| POST | `/api/v1/ai-providers/{provider_id}/chat/completions` | `ai-provider:provider:chat` | Proxy an OpenAI chat completion. |

## Errors / limits

- **API keys are never returned.** List, get, create and update responses expose `hasApiKey` and `apiKeyPreview` only.
- **Updating without `apiKey` keeps the old key.** Send `"apiKey": ""` to clear it, or a new value to rotate it.
- **Provider names are unique, ignoring case.** A duplicate returns `409 ai_provider_name_conflict`.
- **Outbound URLs must use public HTTPS.** Do not embed credentials, query parameters or fragments. Versioned base paths such as `/openai/v1.0` are supported. Redirects are not followed. Only configure an egress proxy you trust; set `LENS_TRUSTED_AI_PROVIDER_PROXY` to pin a specific verified proxy.
- **A failed connectivity test is not an HTTP error.** The test endpoint returns `200` with `success: false` and a message for an unreachable or rejected probe. Invalid request fields return `422`.
- **Chat proxying is OpenAI-only.** Other provider types return `400`. A missing provider returns `404`; upstream error statuses are passed through; network or timeout failures return `502`.
- **Field limits.** `name` and `model` allow up to 200 characters; `timeoutSeconds` must be greater than `0` and at most `120`; `providerType` is `openai` or `anthropic`. Chat proxy calls use a separate, longer fixed timeout.
- **Supported provider types.** Use `openai` for OpenAI-compatible APIs and `anthropic` for Anthropic-compatible APIs. Chat proxying currently supports `openai` only.
