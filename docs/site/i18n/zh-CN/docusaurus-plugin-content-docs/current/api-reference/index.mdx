Lens 通过统一的 Python FastAPI 后端（`llm_d_lens`）暴露同源 HTTP API 和 MCP 端点。
开发环境中，Vite 将浏览器的 `/api/...` 请求直接代理到该后端。
生产环境中，同一后端提供构建后的前端、REST API、`/api/mcp`（Agent Task MCP）和
`/api/assistant/mcp`（助手工具目录），并负责校验、持久化和任务执行。

Deploy 属于 Lens Python 后端，并非独立的 llm-d-bench API。
部署路由在同一进程内执行，不再需要单独的 BFF 上游。
本地开发使用 `hack/lens-local.sh start`；当前启动与存储设置参见
[安装](/installation)和[环境变量](/environment-variables)，不要沿用主机专属的 `/root/...` 路径。
请求需要已认证的 Lens 会话（或在 `/api/mcp` 上使用 `lens-pat-*` Bearer 令牌）及相应权限；
浏览器会话的非安全方法还需要匹配的 `prism_csrf` Cookie 和 `x-prism-csrf` 请求头。
未登录的冒烟请求可能返回 `401`，而不是资源列表。

## 接口

| 接口 | 说明 |
| --- | --- |
| Python API | 用于部署、模拟（`/api/simulation`）、评估、模型目录（`/api/v1/model-catalog`）、存储、监控、认证和 Playground 的同源 FastAPI 路由；同时提供生产环境前端。 |
| Agent Task MCP（`/api/mcp`） | 无状态 Streamable HTTP MCP 服务端，向外部编码/运维代理暴露 46 个面向任务的工具（参见 [MCP 集成](/mcp)）。 |
| 助手工具目录（`/api/assistant/mcp`） | 从后端路由生成的助手可调用操作，纳入内部 MCP 目录（参见 [Lens Assistant](/api-reference/modules/lens-assistant)）。 |
| Kubernetes 后端 | 通过官方 Python 客户端进行的服务端 Kubernetes 访问，支持 CLI 回滚。 |

每个 Python 后端端点也都记录在生成的 FastAPI OpenAPI schema 中。
在后端路由发生变化后，重新生成它：

```bash
source .venv/bin/activate
npm run docs:api
```

## 约定

每一个新增或修改的、可供外部调用的 API（FastAPI 路由、HTTP 处理器、
RPC/MCP 工具及其请求/响应契约）都必须使其描述与实际实现的行为、
校验逻辑、授权、默认值、状态码和 schema 保持一致。参见
`.github/instructions/api-documentation.instructions.md` 中仓库对
API 描述的要求。
