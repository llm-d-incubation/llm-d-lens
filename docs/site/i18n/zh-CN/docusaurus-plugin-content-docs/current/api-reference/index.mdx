Lens 提供两种方式执行同一组操作：

- **REST API**：供远程客户端、脚本和浏览器使用。
- **进程内 Python SDK**：供 Lens 主机上的可信自动化使用。

两者共享同一套请求/响应模型、权限和审计规则。

## 快速开始

### REST API

使用 Bearer Access Token 或已认证的浏览器会话：

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/deployments/executions
```

使用 Cookie 的非安全请求还需要在 `x-prism-csrf` 请求头中携带 `prism_csrf`
Cookie。参见[认证](/user-guide/administration)。

### 进程内 Python SDK

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    executions = lens.deployments.list_executions()
    for execution in executions:
        print(execution.execution_id, execution.status)
```

SDK 只用于运行在 Lens 主机上的代码。调用方在远程主机，或本机用户不可信时，
请使用 REST。

## 选择接口

| 调用方 | 使用 |
| --- | --- |
| 远程服务、CI Runner 或其他机器 | 带 Bearer Token 的 REST API |
| 浏览器 UI | 带 Session Cookie 的 REST API |
| Lens 主机上的可信脚本或 CI 任务 | 进程内 Python SDK |
| Lens Assistant | MCP 工具 |

## 约定

- 除文件下载和事件流外，响应均为 JSON。
- 错误使用 `application/problem+json`，包含稳定的 `code`、`message` 和可选
  `details`。
- 请求需要认证；使用 Cookie 的非安全请求还需要 CSRF。
- 资源级权限和集群范围由服务层检查，不仅由路由检查。
- HTTP 字段使用 camelCase；Python 模型使用 snake_case 属性，并在定义了别名时
  同时接受两种写法。

## 已弃用路径

旧的 `/api/...` 路径，例如 `/api/cluster`、`/api/simulation` 和 `/api/mcp`，
在客户端迁移期间仍作为 `/api/v1/...` 的临时别名保留。`/healthz` 继续用于进程探针。

## 完整 schema

生成的 OpenAPI schema 是请求/响应字段的最终来源：

- Swagger UI：`/api/v1/simulation/docs`
- OpenAPI JSON：`/api/v1/simulation/openapi.json`

模块页面用于常见任务，完整字段定义请查 OpenAPI schema。
