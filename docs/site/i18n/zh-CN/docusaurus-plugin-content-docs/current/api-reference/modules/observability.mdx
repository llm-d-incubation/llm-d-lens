使用可观测性（Observability）检查或安装集群 Prometheus/Grafana 技术栈、查看加速器和 GPU 驱动健康状态、管理单个部署的监控，并读取性能剖析指标。仪表盘缺失、驱动或 exporter 需要处理，或需要确认哪些部署执行已启用监控时使用本模块。

## 快速开始

列出 Lens 支持的加速器系列和访问模式。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/monitoring/accelerators
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    response = lens.accelerator.list_accelerators()
    for item in response.accelerators:
        print(item.type, item.access_modes, item.default_namespace)
```

  </TabItem>
</Tabs>

## 常见任务

### 1. 检查集群监控技术栈和仪表盘链接

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/cluster-stack/status?namespace=llm-d-monitoring&cluster_id=<cluster-id>"

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/cluster-stack/links?namespace=llm-d-monitoring&cluster_id=<cluster-id>"
```

读取 `status`、`message`、`release` 和 `components[]`。链接响应返回 Prometheus 和 Grafana 条目，包含 `available` 和 `url`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        status = await lens.cluster_stack.status(
            namespace="llm-d-monitoring", cluster_id="<cluster-id>"
        )
        print(status.status, status.message)

        links = await lens.cluster_stack.links(
            namespace="llm-d-monitoring", cluster_id="<cluster-id>"
        )
        for link in links.links:
            print(link.kind, link.available, link.url)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 2. 预检并安装或重新安装集群技术栈

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  "http://127.0.0.1:3000/api/v1/monitoring/cluster-stack/installations/preflight?cluster_id=<cluster-id>" \
  -d '{"namespace":"llm-d-monitoring","mode":"central","enable_tls":false,"reinstall":false}'

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: <request-id>" \
  "http://127.0.0.1:3000/api/v1/monitoring/cluster-stack/installations?cluster_id=<cluster-id>" \
  -d '{"namespace":"llm-d-monitoring","mode":"central","enable_tls":false,"reinstall":false}'
```

预检返回 `allowed`、阻断性 `checks` 和 `warnings`。安装返回 `202 Accepted` 和 `operation_id`；请轮询操作直到 `status` 为 `succeeded` 或 `failed`。重新安装会删除已存储的指标。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.monitoring.cluster_stack.models import ClusterStackInstallRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        request = ClusterStackInstallRequest(
            namespace="llm-d-monitoring",
            mode="central",
            enable_tls=False,
            reinstall=False,
        )
        preflight = await lens.cluster_stack.installation_preflight(
            request, cluster_id="<cluster-id>"
        )
        print(preflight.allowed, preflight.warnings)

        operation = await lens.cluster_stack.create_installation(
            request, idempotency_key="<request-id>", cluster_id="<cluster-id>"
        )
        print(operation.operation_id, operation.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 3. 检查加速器能力和状态

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/accelerators/nvidia_gpu/status?namespace=dcgm-exporter&access_mode=dra&cluster_id=<cluster-id>"
```

读取 `status`、`message`、`release`、`access_modes[]` 和 `components[]`。请显式传入 `dcgm-exporter` 或你的 NVIDIA release 命名空间；查询默认使用 `intel-xpumd`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        status = await lens.accelerator.status(
            "nvidia_gpu",
            namespace="dcgm-exporter",
            access_mode="dra",
            cluster_id="<cluster-id>",
        )
        print(status.status, status.message)
        for mode in status.access_modes:
            print(mode.mode, mode.available, mode.detected)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 5. 管理部署监控

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/deployments?cluster_id=<cluster-id>"

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/deployments/<execution-id>?cluster_id=<cluster-id>"

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/deployments/<execution-id>/enable?cluster_id=<cluster-id>"
```

有效操作包括 `install`、`enable`、`disable` 和 `uninstall`。从响应中读取 `status`、`enabled`、`servicemonitors` 和 `podmonitors`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        listing = await lens.observability.list_deployment_monitoring("<cluster-id>")
        print(listing.cluster_id, listing.stack_ready, len(listing.items))

        status = await lens.observability.get_deployment_monitoring(
            "<execution-id>", "<cluster-id>"
        )
        print(status.status, status.enabled)

        result = await lens.observability.manage_deployment_monitoring(
            "<execution-id>", "enable", "<cluster-id>"
        )
        print(result.status, result.message)

    asyncio.run(main())
```

### 6. 检查 GPU 驱动和性能剖析流量图

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/gpu-driver/status?access_mode=dra&cluster_id=<cluster-id>&hardware=intel-xpu"

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  "http://127.0.0.1:3000/api/v1/monitoring/gpu-driver/install?cluster_id=<cluster-id>&hardware=intel-xpu" \
  -d '{"access_mode":"dra"}'

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/monitoring/profiling/flow-map?execution_id=<execution-id>&cluster_id=<cluster-id>"
```

驱动状态返回 `installed`、`ready` 和 `message`。驱动安装为异步操作（`202`）。流量图返回 `prometheus_reachable`、`components` 和 `edges`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.monitoring.gpu_driver.models import GpuDriverInstallRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        status = await lens.gpu_driver.read_status(
            "dra", cluster_id="<cluster-id>", hardware="intel-xpu"
        )
        print(status.installed, status.ready, status.message)

        installed = await lens.gpu_driver.create_install(
            GpuDriverInstallRequest(access_mode="dra"),
            cluster_id="<cluster-id>",
            hardware="intel-xpu",
        )
        print(installed.applied, installed.message)

        flow = await lens.profiling.flow_map("<execution-id>", "<cluster-id>")
        print(flow.prometheus_reachable, len(flow.components), len(flow.edges))

    asyncio.run(main())
```

## 错误与限制

- **401 / 403**：认证缺失或过期、缺少监控权限，或无权访问目标集群。
- **404 `CLUSTER_NOT_FOUND`**：集群 ID 未知。部署操作不在 `install`、`enable`、`disable` 或 `uninstall` 中时也会返回 `404`。
- **422**：命名空间、访问模式或安装请求无效；请求体中的加速器必须与路径一致。
- **502** 且带有 `CLUSTER_QUERY_FAILED`、`ACCELERATOR_QUERY_FAILED` 或 `FLOW_MAP_FAILED`：集群或 Prometheus 查询失败，可重试。
- 安装操作返回 `202`；请轮询操作端点直到 `status` 为 `succeeded` 或 `failed`。预检不会更改集群。
- **重新安装会删除已存储的指标。** 仅在确定要替换监控技术栈时使用。
- `POST /api/v1/monitoring/deployments/{execution_id}/install` 和 `enable` 要求部署已就绪。`GET /api/v1/monitoring/deployments` 需要 `cluster_id`；流量图需要 `execution_id`。
- 命名空间最长 63 个字符，且必须是有效的 DNS 标签。加速器 ID 来自已登记的硬件配置，例如 `intel_gpu` 和 `nvidia_gpu`。
- 加速器状态查询对所有系列默认使用 `intel-xpumd`；查询 NVIDIA 时始终传入其 release 命名空间，通常是 `dcgm-exporter`。
