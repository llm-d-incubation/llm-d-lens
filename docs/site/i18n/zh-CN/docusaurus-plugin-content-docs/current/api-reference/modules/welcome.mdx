## 模块用途

欢迎页提供落地页使用的只读问题数据。你可以用它构建跨集群的告警视图或仪表盘。
该接口只返回问题快照；集群容量、模型服务列表、部署历史和用量仍由各自模块的接口负责。

两个端点都需要已登录会话和 `cluster:cluster:read`。返回结果会按调用者可访问的
集群和领域权限过滤。

## 快速开始

### 获取概览

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/welcome/overview?clusterId=cluster-a"
```

响应包含 `generatedAt`、`scope`，以及带有当前问题数组的 `issues` 信封。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        overview = await lens.dashboard.overview(cluster_id="cluster-a")
        for issue in overview.issues.data or []:
            print(issue.severity, issue.code, issue.title)


asyncio.run(main())
```

  </TabItem>
</Tabs>

## 常见任务

### 筛选和分页获取当前问题

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/welcome/issues?severity=critical&category=model-service&limit=10"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        page = await lens.dashboard.alerts(
            severity="critical", category="model-service", limit=10
        )
        print(page.total, page.next_cursor)
        for issue in page.items:
            print(issue.cluster_name, issue.title)


asyncio.run(main())
```

  </TabItem>
</Tabs>

- 可选筛选项：`clusterId`、`severity`、`category` 和 `search`。
- 将 `nextCursor` 作为 `cursor` 传回。如果快照发生变化或已过期，响应会设置
  `restarted: true`，并从第一页重新开始。
- `category` 的取值为 `cluster`、`model-service`、`deployment`、`storage`、
  `model-cache`、`monitoring`、`ai-provider` 和 `access`。

### 刷新快照

在概览请求中设置 `refresh=true` 可安排一次后台刷新。调用会立即返回当前快照，
不会等待远程数据源。将值作为最新数据使用前，请检查 `issues.stale` 标志。

## 端点

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/welcome/overview` | 落地页当前范围内的问题信封。 |
| `GET` | `/api/v1/welcome/issues` | 支持筛选和游标分页的扁平问题列表。 |

## 错误与限制

- 缺少或无效的认证返回 `401`；缺少 `cluster:cluster:read` 返回 `403`。
- 显式传入无权访问的 `clusterId` 返回 `403`，且不包含资源详情。
- `limit` 必须在 `1` 到 `100` 之间。
- 快照大约每 60 秒在后台刷新一次。`refresh=true` 只会排队一次刷新。
