## 这个模块是什么

外部提供方是 Lens 作为客户端使用的、已保存的出站 AI 连接，例如 OpenAI、Anthropic 或自托管的兼容 OpenAI 服务器。你可以用它测试连接、保存和更新提供方设置、通过已保存的提供方发送聊天补全，以及移除不再需要的连接。存储的 API 密钥永远不会返回；响应只暴露 `hasApiKey` 和 `apiKeyPreview`。

## 快速开始

先测试草稿配置，再保存它。提供方请求由 Lens 后端发出，因此 URL 必须可访问且为公网地址。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST "$LENS_URL/api/v1/ai-providers/test" \
  -H "Content-Type: application/json" \
  -d '{"baseUrl":"https://api.openai.com/","model":"gpt-4o-mini","apiKey":"<token>","providerType":"openai"}'

curl -X POST "$LENS_URL/api/v1/ai-providers" \
  -H "Content-Type: application/json" \
  -d '{"name":"OpenAI","baseUrl":"https://api.openai.com/","model":"gpt-4o-mini","apiKey":"<token>","providerType":"openai","timeoutSeconds":30}'
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderCreateRequest, AIProviderTestRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        result = await lens.external_providers.test_draft_provider(
            AIProviderTestRequest(
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
            )
        )
        print(result.success, result.message)

        provider = await lens.external_providers.create_provider(
            AIProviderCreateRequest(
                name="OpenAI",
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
                timeoutSeconds=30,
            )
        )
        print(provider.id, provider.has_api_key)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 常见任务

### 保存前测试配置

测试会探测提供方的模型列表，并报告是否找到了配置的模型。无法访问的提供方会返回 `200` 且 `success: false`；请检查结果，不要只看 HTTP 状态码。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers/test`**

```json
{
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "apiKey": "<token>",
  "providerType": "openai",
  "timeoutSeconds": 15
}
```

```json
{
  "success": true,
  "message": "Connected successfully.",
  "modelFound": true,
  "availableModels": ["gpt-4o-mini"],
  "latencyMs": 182.4
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderTestRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        result = await lens.external_providers.test_draft_provider(
            AIProviderTestRequest(
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
            )
        )
        print(result.success, result.model_found, result.latency_ms)

    asyncio.run(main())
```

### 保存提供方连接

为 Lens Assistant 和其他智能体功能保存持久连接。提供方名称唯一且忽略大小写；重复名称返回 `409 ai_provider_name_conflict`。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers`**

```json
{
  "name": "OpenAI",
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "apiKey": "<token>",
  "providerType": "openai",
  "timeoutSeconds": 30
}
```

响应（`201`）：

```json
{
  "id": "ai-provider-7f3a2c1d",
  "name": "OpenAI",
  "baseUrl": "https://api.openai.com/",
  "model": "gpt-4o-mini",
  "providerType": "openai",
  "timeoutSeconds": 30,
  "hasApiKey": true,
  "apiKeyPreview": "...cdef"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderCreateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        provider = await lens.external_providers.create_provider(
            AIProviderCreateRequest(
                name="OpenAI",
                baseUrl="https://api.openai.com/",
                model="gpt-4o-mini",
                apiKey="<token>",
                providerType="openai",
                timeoutSeconds=30,
            )
        )
        print(provider.id, provider.model, provider.has_api_key)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 更新提供方或轮换密钥

所有字段都是可选的。省略 `apiKey` 会保留已存储的密钥，传入空字符串则会清除它。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`PUT /api/v1/ai-providers/{provider_id}`**

```json
{
  "model": "gpt-4.1-mini",
  "timeoutSeconds": 45,
  "apiKey": "<token>"
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.ai_providers.contracts import AIProviderUpdateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        provider = await lens.external_providers.update_provider(
            "<provider-id>",
            AIProviderUpdateRequest(
                model="gpt-4.1-mini",
                timeoutSeconds=45,
                apiKey="<token>",
            ),
        )
        print(provider.id, provider.model)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 通过已保存的提供方发送聊天补全

服务器会附带已保存的密钥转发 OpenAI 风格的请求体，并在省略 `model` 时填入已保存的模型。只有 `openai` 类型提供方支持此路由。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/ai-providers/{provider_id}/chat/completions`**

```json
{
  "messages": [
    {
      "role": "user",
      "content": "Give me a one-line health summary."
    }
  ]
}
```

响应是上游提供方返回的 JSON。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        response = await lens.external_providers.proxy_chat_completions(
            "<provider-id>",
            {"messages": [{"role": "user", "content": "Say hello in one sentence."}]},
        )
        print(response)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

此操作会复用已存储的 URL、模型、密钥和超时设置。在编辑提供方后或诊断连接问题时使用它。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST "$LENS_URL/api/v1/ai-providers/<provider-id>/test"
```

响应结构与草稿测试相同。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:

    asyncio.run(main())
```

### 删除提供方

删除会移除保存的配置及其存储的密钥。它不会影响外部提供方本身。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X DELETE "$LENS_URL/api/v1/ai-providers/<provider-id>"
```

响应：`204 No Content`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        await lens.external_providers.delete_provider("<provider-id>")

    asyncio.run(main())
```

## 端点

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/v1/ai-providers` | `ai-provider:provider:read` | 列出已保存的提供方，密钥已屏蔽。 |
| GET | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:read` | 获取一个已保存的提供方。 |
| POST | `/api/v1/ai-providers` | `ai-provider:provider:create` | 保存新的提供方连接。 |
| PUT | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:update` | 更新提供方；轮换或清除密钥。 |
| DELETE | `/api/v1/ai-providers/{provider_id}` | `ai-provider:provider:delete` | 删除已保存的提供方。 |
| POST | `/api/v1/ai-providers/test` | `ai-provider:provider:test` | 测试未保存的配置。 |
| POST | `/api/v1/ai-providers/{provider_id}/test` | `ai-provider:provider:test` | 测试已保存的提供方。 |
| POST | `/api/v1/ai-providers/{provider_id}/chat/completions` | `ai-provider:provider:chat` | 代理 OpenAI 聊天补全。 |

## 错误 / 限制

- **API 密钥永远不会返回。** 列表、获取、创建和更新响应只暴露 `hasApiKey` 和 `apiKeyPreview`。
- **更新时不传 `apiKey` 会保留旧密钥。** 传入 `"apiKey": ""` 可清除它，传入新值可轮换它。
- **提供方名称唯一且忽略大小写。** 重复名称返回 `409 ai_provider_name_conflict`。
- **出站 URL 必须使用公网 HTTPS。** 不要内嵌凭据、查询参数或片段标识符。支持带版本的基础路径，例如 `/openai/v1.0`。系统不会跟随重定向。只配置你信任的出口代理；设置 `LENS_TRUSTED_AI_PROVIDER_PROXY` 以固定某个经过验证的代理。
- **连接测试失败不是 HTTP 错误。** 对于无法访问或被拒绝的探测，测试端点返回 `200` 且 `success: false`，并附带说明信息。无效请求字段返回 `422`。
- **聊天代理仅支持 OpenAI 类型。** 其他提供方类型返回 `400`。提供方不存在返回 `404`；上游错误状态会原样返回；网络或超时失败返回 `502`。
- **字段限制。** `name` 和 `model` 最多 200 个字符；`timeoutSeconds` 必须大于 `0` 且不超过 `120`；`providerType` 为 `openai` 或 `anthropic`。聊天代理调用使用单独的、更长的固定超时。
- **支持的提供方类型。** 兼容 OpenAI 的 API 使用 `openai`，兼容 Anthropic 的 API 使用 `anthropic`。聊天代理目前仅支持 `openai`。
