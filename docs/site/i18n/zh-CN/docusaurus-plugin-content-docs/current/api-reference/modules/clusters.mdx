## Backend API

集群管理路由来自 `llm_d_lens/cluster/router.py`、`llm_d_lens/cluster/bootstrap/router.py` 和 `llm_d_lens/cluster/sdk_discovery.py`。

### 列出集群

列出由 Lens 管理的集群，并可选择包含尚未完成的草稿记录。该路由还会通过探测每个集群的 Kubernetes API 可达性来计算 `ready` 标志。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/cluster/clusters`**

    请求：无请求体。

    - `includeDrafts`（`boolean`，查询参数，默认 `false`）：是否包含草稿集群记录。

    响应：`ClustersResponse`，每个可见集群对应一个 `ClusterRecord`。

`hfTokenSecret` 返回该集群 HF_TOKEN Secret 的命名空间和名称；集群没有该 Secret 时为 `null`。接口只返回位置信息，令牌值保存在目标集群上，不会由 API 返回。

    ```json
    {
      "items": [
        {
          "id": "cluster-a",
          "name": "Primary cluster",
          "description": "Shared production GPU cluster",
          "createdAt": "2026-09-20T10:15:00Z",
          "ready": true,
          "proxy": {
            "mode": "custom",
            "httpProxy": "http://proxy.example:3128",
            "httpsProxy": "http://proxy.example:3128",
            "noProxy": "127.0.0.1,localhost,.svc"
          },
          "llmDRef": "v0.3.0",
          "llmDBenchmarkRef": "main",
          "llmDRepoPath": "/cache/llm-d/v0.3.0",
          "llmDBenchmarkRepoPath": "/cache/llm-d-benchmark/main",
          "hfTokenSecret": {
            "namespace": "llm-d-bench-storage-44395349",
            "name": "hf-token-c758ced0"
          },
          "draft": false
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import service

    async def main() -> None:
        clusters = service.list_clusters(include_drafts=True)
        ready_flags = await asyncio.gather(*(service.cluster_is_ready(cluster) for cluster in clusters))
        for cluster, ready in zip(clusters, ready_flags):
            print(cluster.id, cluster.name, ready)

    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### 注册集群

通过上传的 kubeconfig 文件注册集群。该路由接受 multipart 表单数据，存储集群记录，并返回新集群以及（如有）创建的 Lens 会话 id。

llm-d 组件版本由 Lens 技术栈配置文件固定（参见[获取支持的 llm-d 版本](#获取支持的-llm-d-版本)）；`llmDRef`、`llmDBenchmarkRef`、`routerVersion`、`gieVersion` 和 `ippVersion` 为兼容性保留字段，但会被忽略。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters`**

    请求：multipart 表单数据，不是 JSON。

    - `name`（`string`，表单字段）：集群显示名称。
    - `description`（`string`，表单字段，可选）：自由格式描述。
    - `file`（`file`，表单字段）：UTF-8 编码的 kubeconfig 上传文件。
    - `proxy`（`string`，表单字段，可选）：与 `ProxyConfigDTO` 匹配的 JSON 字符串。
    - `llmDRef`（`string`，表单字段，可选）：已忽略 —— `llm-d` 版本来自技术栈配置文件。
    - `llmDBenchmarkRef`（`string`，表单字段，可选）：已忽略 —— `llm-d-benchmark` 版本来自技术栈配置文件。
    - `gatewayProvider`（`string`，表单字段，可选）：共享网关供应商（`envoy-ai-gateway` | `istio` | `agentgateway` | `gke`）。
    - `gatewayPublicUrl`（`string`，表单字段，可选）：客户端用来访问网关的外部可达主机/IP —— Lens 会自动添加 `http://` 加暴露端口加 `/v1`。为空时将根据暴露端口和集群节点推导。
    - `gatewayPort`（`integer`，表单字段，可选）：共享网关暴露所使用的 NodePort（30000–32767）。
    - `gatewayAuthzHost`（`string`，表单字段）：该集群用来访问 Lens 的主机/IP（对于带有 Lens 地址钩子的供应商为必填：`envoy-ai-gateway`/`istio`/`agentgateway`）。可从 `GET /api/cluster/lens-hosts` 中选取；Lens 会自动添加自身的服务端口，为空时 Lens 会自动填入该主机地址。
    - `inotifyMaxUserInstances`（`integer`，表单字段，默认 `8192`）：Lens 应用于每个节点的每用户 inotify 实例数上限（`fs.inotify.max_user_instances`）。在运行大量 Pod 的节点上，应将其调高到 kind 默认值 128 之上。
    - `draft`（`boolean`，表单字段，默认 `false`）：是否以草稿形式创建。

    示例字段取值：

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "file": "<uploaded kubeconfig.yaml UTF-8 file>",
      "proxy": "{"mode":"custom","httpProxy":"http://proxy.example:3128","httpsProxy":"http://proxy.example:3128","noProxy":"127.0.0.1,localhost,.svc"}",
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": true
    }
    ```

    响应：`CreateClusterResponse`。

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": false,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",
          "noProxy": "127.0.0.1,localhost,.svc"
        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": true
      },
      "sessionId": "f4c15c0a-8c1f-4eb7-b4d7-ef83f22c2e9b"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster import service

    kubeconfig_text = """
    apiVersion: v1
    kind: Config
    clusters: []
    contexts: []
    current-context: ""
    users: []
    """.strip()

    cluster, session = service.create_cluster(
        "Primary cluster",
        "Shared production GPU cluster",
        kubeconfig_text,
        proxy_mode="custom",
        http_proxy="http://proxy.example:3128",
        https_proxy="http://proxy.example:3128",
        no_proxy="127.0.0.1,localhost,.svc",
        llm_d_ref="v0.3.0",
        llm_d_lensmark_ref="main",
        draft=True,
    )

    print(cluster.id, session.id)
    ```
  </TabItem>
</Tabs>

### 更新集群

修改集群的可编辑设置，包括名称、描述、代理设置和草稿状态。kubeconfig 本身不在此补丁契约范围内。版本字段（`llmDRef`、`llmDBenchmarkRef`、`routerVersion`、`gieVersion`、`ippVersion`）由服务端根据技术栈配置文件管理，输入时会被忽略。

Gateway 命名空间前缀会附加该 Lens 集群注册的稳定短 ID。注册 ID 为 `1234abcd` 时，
默认命名空间为 `lens-gateway-1234abcd`；`gatewayNamespace: "custom"` 会解析为
`custom-1234abcd`。再次传入带后缀的值不会重复添加。集群响应返回实际命名空间，
以前使用共享 `lens-gateway` 默认值的记录也遵循此规则。
`service.update_cluster_settings(..., gateway_namespace="custom")` 的行为相同。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`PATCH /api/cluster/clusters/{cluster_id}`**

    请求体（`ClusterSettingsUpdateRequest`）：

    - `name`（`string`，可选）
    - `description`（`string`，可选）
    - `proxy`（`ProxyConfigDTO`，可选）
    - `llmDRef`（`string`，可选）
    - `llmDBenchmarkRef`（`string`，可选）
    - `gatewayProvider`（`string`，可选）：当集群尚未设置供应商时可赋值一次；设置后不可更改，传入不同值会返回 `422 gateway_provider_immutable`。
    - `gatewayNamespace`（`string`，可选）：最多 63 个字符的命名空间前缀，会附加注册的稳定短 ID。
    - `gatewayPort`（`integer`，可选）
    - `gatewayPublicUrl`（`string`，可选）：外部可达的网关主机/IP —— Lens 会自动添加暴露端口；为空时将自动推导。
    - `gatewayAuthzHost`（`string`）：该集群用来访问 Lens 的主机/IP（对于带有 Lens 地址钩子的供应商为必填；Lens 会自动添加自身服务端口；为空时会自动填入该主机地址）。
    - `inotifyMaxUserInstances`（`integer`，可选）：应用于每个节点的每用户 inotify 实例数上限（默认 `8192`）。
    - `draft`（`boolean`，可选）

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "proxy": {
        "mode": "custom",
        "httpProxy": "http://proxy.example:3128",
        "httpsProxy": "http://proxy.example:3128",
        "noProxy": "127.0.0.1,localhost,.svc"
      },
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": false
    }
    ```

    响应：`CreateClusterResponse`，包含更新后的记录。

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": true,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",
          "noProxy": "127.0.0.1,localhost,.svc"
        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": false
      },
      "sessionId": null
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster import service

    cluster = service.update_cluster_settings(
        "cluster-a",
        name="Primary cluster",
        description="Shared production GPU cluster",
        proxy_mode="custom",
        http_proxy="http://proxy.example:3128",
        https_proxy="http://proxy.example:3128",
        no_proxy="127.0.0.1,localhost,.svc",
        llm_d_ref="v0.3.0",
        llm_d_lensmark_ref="main",
        gateway_authz_host="10.0.0.5",
        draft=False,
    )
    print(cluster.id, cluster.name)
    ```
  </TabItem>
</Tabs>

### 创建集群 HF_TOKEN secret

在目标集群上创建保存 Hugging Face 令牌的独立 Kubernetes Secret，并把它的坐标记录到 Lens 集群记录上，供部署和模型缓存下载默认使用。这是创建集群向导的模型缓存步骤。令牌值只写入集群；Lens 只保存命名空间和名称。Secret 已存在时返回 `409 secret_already_exists`，此时请使用下面的轮换接口替换令牌。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/hf-token-secrets`**

    请求体（`HfTokenSecretCreateRequest`）：

    - `namespace`（`string`，必填）：创建 Secret 的命名空间；不存在时自动创建。
    - `name`（`string`，必填）：Secret 名称。
    - `token`（`string`，必填）：保存在 `HF_TOKEN` 键下的 Hugging Face 令牌。

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0",
      "token": "hf_exampleTokenValue"
    }
    ```

    响应：`HfTokenSecretRef`。

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import registry, service

    cluster = registry.get_cluster("cluster-a")
    ref = asyncio.run(
        service.create_hf_token_secret(
            cluster,
            "llm-d-bench-storage-44395349",
            "hf-token-c758ced0",
            "hf_exampleTokenValue",
        )
    )
    print(ref["namespace"], ref["name"])
    ```
  </TabItem>
</Tabs>

### 轮换集群 HF_TOKEN secret

在编辑集群面板中替换集群 `HF_TOKEN` Secret 中保存的 Hugging Face 令牌。与创建接口不同，这里使用 apply，因此已存在的 Secret 会被覆盖而不是报错。`namespace` 和 `name` 默认使用集群上已记录的坐标（`hfTokenSecret`），所以轮换令牌只需提供令牌；提供不同坐标会把集群指向该 Secret，并在其不存在时创建它。

轮换只重写这个集群级 Secret。部署和模型缓存下载在运行时派生的命名空间内 `llm-d-hf-token` 副本会在下一次部署或下载时重新派生，因此已在运行的工作负载在重建之前仍使用旧令牌。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`PUT /api/cluster/clusters/{cluster_id}/hf-token-secret`**

    请求体（`HfTokenSecretUpdateRequest`）：

    - `namespace`（`string`，可选）：默认使用集群已记录的 Secret 命名空间。
    - `name`（`string`，可选）：默认使用集群已记录的 Secret 名称。
    - `token`（`string`，必填）：新的 Hugging Face 令牌；空值返回 `422 invalid_secret_token`。

    ```json
    {
      "token": "hf_rotatedTokenValue"
    }
    ```

    响应：`HfTokenSecretRef`，返回实际写入的坐标。

    ```json
    {
      "namespace": "llm-d-bench-storage-44395349",
      "name": "hf-token-c758ced0"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster import registry, service

    cluster = registry.get_cluster("cluster-a")
    # 使用集群上已记录的坐标原地轮换。
    ref = asyncio.run(service.update_hf_token_secret(cluster, "hf_rotatedTokenValue"))
    print(ref["namespace"], ref["name"])

    # 也可以把集群指向另一个 Secret。
    ref = asyncio.run(
        service.update_hf_token_secret(
            cluster,
            "hf_rotatedTokenValue",
            namespace="llm-d-bench-storage-44395349",
            name="hf-token-rotated",
        )
    )
    ```
  </TabItem>
</Tabs>

### 启动集群软件下载

为集群下载由 Lens 技术栈配置文件固定的 `llm-d` 和 `llm-d-benchmark` 版本。处理函数会调度后台下载任务并立即返回当前状态快照；请求体会被忽略。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/software-downloads`**

    请求体（`SoftwareDownloadRequest`）：可选且会被忽略 —— 系统会下载配置文件中固定的版本。

    ```json
    {}
    ```

    响应：`SoftwareDownloadStatusResponse`。

    ```json
    {
      "llmD": {
        "ref": "v0.2.0",
        "state": "downloading",
        "path": null,
        "error": null
      },
      "llmDBenchmark": {
        "ref": "main",
        "state": "downloading",
        "path": null,
        "error": null
      }
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_lens.cluster.router import _download_and_record
    from llm_d_lens.cluster import repo_downloads

    async def main() -> None:
        await _download_and_record("cluster-a", "llm-d", "v0.2.0")
        await _download_and_record("cluster-a", "llm-d-benchmark", "main")
    ```

  </TabItem>

### 启动集群镜像预拉取

为所选加速器在每个集群节点上预拉取 Lens 固定版本的 llm-d 镜像。这些镜像包括 llm-d-router EPP 和 P/D sidecar，以及各加速器对应的模型服务镜像；版本来自 Lens 技术栈配置文件，而非请求内容。一个特权 DaemonSet 会在每个节点上运行主机的 `crictl`；可通过下方的 GET 端点轮询每个节点的就绪状态。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/images/prepull`**

    请求体：

    - `accelerators`（`string[]`）：需要拉取模型服务镜像的加速器 id（例如 `["nvidia","intel"]`）。

    ```json
    {
      "accelerators": ["nvidia", "intel"]
    }
    ```

    响应：总体状态、`ready`/`desired` 节点数、镜像列表以及每个节点的就绪状态。

    ```json
    {
      "state": "pulling",
      "desired": 2,
      "ready": 1,
      "images": [
        { "name": "ghcr.io/llm-d/llm-d-router-endpoint-picker:v1.0.0", "ready": 2, "desired": 2, "state": "ready" },
        { "name": "ghcr.io/llm-d/llm-d-router-disagg-sidecar:v1.0.0", "ready": 2, "desired": 2, "state": "ready" },
        { "name": "ghcr.io/llm-d/llm-d-cuda:v0.9.0", "ready": 1, "desired": 2, "state": "pulling" }
      ],
      "nodes": [{ "node": "worker-1", "phase": "Running", "ready": true, "restarts": 0 }]
    }
    ```

    当所有节点都已拉取该镜像时 `images[].state` 为 `ready`；拉取进行中为 `pulling`；若某节点拉取不断崩溃重试则为 `failed`。
  </TabItem>

### 删除集群

删除由 Lens 管理的集群记录，并清理相关状态。仅当需要将集群从 Lens 中彻底移除时才应使用此操作。

该接口会执行以下远端清理：

- 删除注册独立的 Gateway 命名空间（通常为 `lens-gateway-<cluster-id>`），以及其中的 Gateway、IPP、鉴权资源和路由。命名空间不存在视为成功，不删除旧共享命名空间、其他注册的命名空间或共享 Gateway 控制器。
- 删除 `hfTokenSecret` 中记录的集群 `HF_TOKEN` Secret；当其所在命名空间没有理由在集群之后继续存在时，该命名空间也会一并删除。以下情况属于此类：Lens 自有的 `llm-d-bench-storage-{cluster_id}` 命名空间、Lens 为该 Secret 创建的任何命名空间（带有 `app.kubernetes.io/managed-by: llm-d-lens` 标签），以及删除该 Secret 后仅剩 Kubernetes 和集群插件注入到每个命名空间中的对象（`default` 服务账号及其令牌 Secret、`kube-root-ca.crt` 等 CA 证书包 ConfigMap）的命名空间。仍包含任何其他对象（包括自定义资源）的命名空间会被保留；`default`、`kube-system`、`kube-public` 和 `kube-node-lease` 永远不会被删除。如果无法列出命名空间内容，则保留该命名空间。
- 对于草稿集群，仍挂在其上的每个存储卷都会连同其 `PersistentVolumeClaim` 和 `PersistentVolume` 对象一起删除。底层 NFS 或主机路径存储上的模型文件会保留，因为 `PersistentVolume` 使用 `Retain` 回收策略。

Gateway 命名空间必须清理成功：失败或超时返回 `502 cluster_gateway_cleanup_failed`，
并保留集群记录和 kubeconfig 以便重试。HF-token 和草稿存储清理仍为尽力而为。
非草稿集群仍有可用部署或存储卷时返回 `409`，请先清理这些资源。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`DELETE /api/cluster/clusters/{cluster_id}`**

    请求：无请求体。

    - `cluster_id`（`string`，路径参数）：目标集群 id。

    响应：`204 No Content`。此端点不返回 JSON 响应体。

    失败：`502 cluster_gateway_cleanup_failed` 表示独立 Gateway 命名空间无法删除；
    `409 cluster_has_available_deployments` 或 `cluster_has_storage_volumes`
    表示已完成注册的集群仍有对应资源。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    必要清理失败时，`service.delete_cluster()` 抛出包含相同状态和错误码的 `ClusterOverviewError`。

    ```python

    ```

    ```python
                BootstrapNodeInput(host="10.0.0.2", roles=["worker"]),
            ],
            pins,
            proxy=BootstrapProxyConfig(
                mode="custom",
                httpProxy="http://proxy.example:3128",
                httpsProxy="http://proxy.example:3128",
                noProxy="127.0.0.1,localhost,.svc",
            ),
        )
        await service.run_bootstrap_job(job.id)
        print(job.id)

    asyncio.run(main())
    ```

### 获取引导状态

获取引导作业的当前状态。当作业首次达到 `succeeded` 状态时，该响应还可以携带一次性的 kubeconfig 交接数据。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/cluster/bootstrap/{bootstrap_id}`**

    请求：无请求体。

    - `bootstrap_id`（`string`，路径参数）：引导作业 id。

    响应：`BootstrapStatusResponse`。

    ```json
    {
      "id": "bootstrap-5b7fd3a81290",
      "phase": "succeeded",
      "logTail": "PLAY [all]
ok: [10-0-0-1]",
      "error": null,
      "kubeconfig": "apiVersion: v1
kind: Config
clusters: []
contexts: []
users: []
"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster.bootstrap import service

    job = service.get_job("bootstrap-5b7fd3a81290")
    kubeconfig = service.consume_kubeconfig(job.id) if job.phase == "succeeded" else None
    print(job.phase, kubeconfig)
    ```
  </TabItem>
</Tabs>

### 取消引导作业

取消一个正在运行的引导作业，使其停止配置并不再继续。一旦收到取消请求，此端点会立即返回。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/cluster/bootstrap/{bootstrap_id}/cancel`**

    请求：无请求体。

    - `bootstrap_id`（`string`，路径参数）：引导作业 id。

    响应：`204 No Content`。此端点不返回 JSON 响应体。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.cluster.bootstrap import service

    service.cancel_job("bootstrap-5b7fd3a81290")
    ```
  </TabItem>
</Tabs>

还有一些其他端点可用于网关端口可用性检查、HF token 密钥创建、模型密钥列表、节点 cordon/uncordon 以及旧版集群概览会话断开路由 —— 详见完整的 OpenAPI 参考文档。

完整的请求/响应模式请参见 FastAPI OpenAPI 模式（使用 `npm run docs:api` 重新生成）。
