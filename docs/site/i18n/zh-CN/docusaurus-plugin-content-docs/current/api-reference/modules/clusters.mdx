## 概述

集群模块把 Lens 连接到用于部署和基准测试的 Kubernetes 集群。在缓存模型、启动部署或读取集群健康状态之前，先注册集群。使用本模块上传 kubeconfig、完成草稿注册、准备 Gateway、LeaderWorkerSet、CRD 和镜像依赖、引导新机器、轮换 Hugging Face 访问凭据，并查看容量、节点和版本。

## 快速开始

列出你可见的集群，并确认哪些集群可达。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        clusters = await lens.clusters.list_clusters()
        for cluster in clusters.items:
            print(cluster.id, cluster.name, cluster.ready)


asyncio.run(main())
```

  </TabItem>
</Tabs>

默认不显示草稿集群。在 REST 中传入 `includeDrafts=true`，在 SDK 中传入 `include_drafts=True` 可包含草稿。

## 常见任务

### 从 kubeconfig 注册集群

`POST /api/v1/cluster/clusters` 使用 multipart 表单数据，而不是 JSON。成功时返回 `201`，包含新集群；如果创建了会话，还包含其 `sessionId`。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -F "name=<cluster-name>" \
  -F "file=@<kubeconfig-path>" \
  "$LENS_URL/api/v1/cluster/clusters"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio
from io import BytesIO
from pathlib import Path

from starlette.datastructures import UploadFile

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        response = await lens.clusters.create_cluster(
            file=UploadFile(
                filename="kubeconfig.yaml",
                file=BytesIO(Path("<kubeconfig-path>").read_bytes()),
            ),
            name="<cluster-name>",
        )
        print(response.cluster.id, response.session_id)


asyncio.run(main())
```

  </TabItem>
</Tabs>

kubeconfig 必须是 UTF-8 文件。llm-d 组件版本来自 Lens 发行版，而不是请求，因此 `llmDRef` 和 `llmDBenchmarkRef` 会被忽略。添加 `draft=true` 可在集群可用前先注册。

### 完成或编辑注册

使用 `PATCH` 重命名集群、修改描述或代理，或将草稿转为正式集群。只有传入的字段会改变。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X PATCH -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"<cluster-name>","draft":false}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import ClusterSettingsUpdateRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        response = await lens.clusters.update_cluster(
            "<cluster-id>",
            ClusterSettingsUpdateRequest(name="<cluster-name>", draft=False),
        )
        print(response.cluster.id, response.cluster.ready)


asyncio.run(main())
```

  </TabItem>
</Tabs>

Gateway 提供程序只能分配一次。之后修改会返回 `422 gateway_provider_immutable`。Gateway 端口必须在 `30000`-`32767` 之间。

### 准备 Gateway 和镜像依赖

应用固定版本的 Gateway API CRD 和 LeaderWorkerSet 控制器，然后预拉取路由器和加速器镜像。这些操作是幂等的。使用对应的 `GET` 端点轮询进度。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# Apply the pinned Gateway API / GIE CRDs.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/crds"

# Install or upgrade LeaderWorkerSet.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/lws"

# Pre-pull router and model-server images for the selected accelerators.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"accelerators":["nvidia"]}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/images/prepull"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import ImagePrepullRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        await lens.clusters.create_cluster_crds("<cluster-id>")
        await lens.clusters.install_cluster_lws("<cluster-id>")

        status = await lens.clusters.create_cluster_image_prepull(
            "<cluster-id>",
            ImagePrepullRequest(accelerators=["nvidia"]),
        )
        print(status.state, status.ready, status.desired)


asyncio.run(main())
```

  </TabItem>
</Tabs>

镜像预拉取使用特权 DaemonSet，每个节点可能需要数分钟。镜像状态为失败表示至少有一个节点的拉取 Pod 在崩溃循环。

### 设置或轮换 Hugging Face 令牌

在集群上保存 Hugging Face 令牌，以便模型缓存下载和私有模型部署使用。`PUT` 会原地轮换令牌；省略 `namespace` 和 `name` 可复用集群上已记录的 Secret。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X PUT -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"token":"<hf-token>"}' \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/hf-token-secret"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.models import HfTokenSecretUpdateRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        ref = await lens.clusters.update_hf_token_secret(
            "<cluster-id>",
            HfTokenSecretUpdateRequest(token="<hf-token>"),
        )
        print(ref.namespace, ref.name)


asyncio.run(main())
```

  </TabItem>
</Tabs>

如果集群还没有 Secret，请使用 `POST /api/v1/cluster/clusters/{cluster_id}/hf-token-secrets` 创建一个。创建已存在的 Secret 会返回 `409 secret_already_exists`；此时应使用 `PUT` 轮换。令牌为空会返回 `422 invalid_secret_token`。正在运行的工作负载会继续使用旧令牌，直到重新创建。

### 引导裸金属机器

发现并固定 SSH 主机密钥，运行预检，然后启动 Kubespray 任务。预检必须通过后才能开始引导。任务会立即返回 `bootstrapId`，实际配置在后台继续。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# 1. Discover host keys without authenticating.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap/host-keys"

# 2. Pin the returned fingerprints and run preflight.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22,"roles":["worker"],"username":"root","password":"<ssh-password>"}],"hostKeys":[{"host":"<ip>","port":22,"fingerprint":"SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap/preflight"

# 3. After allPassed is true, start the job.
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nodes":[{"host":"<ip>","port":22,"roles":["worker"],"username":"root","password":"<ssh-password>"}],"hostKeys":[{"host":"<ip>","port":22,"fingerprint":"SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"}]}' \
  "$LENS_URL/api/v1/cluster/bootstrap"

# 4. Poll until phase is succeeded; the response then carries the kubeconfig.
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/bootstrap/<bootstrap-id>"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.cluster.bootstrap.dto import (
    BootstrapCreateRequest,
    BootstrapHostKeyPin,
    BootstrapHostKeyRequest,
    BootstrapHostAddress,
    BootstrapNodeInput,
    BootstrapPreflightRequest,
)
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        keys = await lens.cluster_bootstrap.discover_host_keys(
            BootstrapHostKeyRequest(nodes=[BootstrapHostAddress(host="<ip>", port=22)])
        )
        print([(item.host, item.fingerprint) for item in keys.items])

        node = BootstrapNodeInput(
            host="<ip>",
            roles=["worker"],
            username="root",
            password="<ssh-password>",
        )
        pin = BootstrapHostKeyPin(
            host="<ip>",
            port=22,
            fingerprint="SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA",
        )
        preflight = await lens.cluster_bootstrap.preflight(
            BootstrapPreflightRequest(nodes=[node], host_keys=[pin])
        )
        if preflight.all_passed:
            job = await lens.cluster_bootstrap.start_bootstrap(
                BootstrapCreateRequest(nodes=[node], host_keys=[pin])
            )
            print(job.bootstrap_id)


asyncio.run(main())
```

  </TabItem>
</Tabs>

SSH 凭据只用于预检和引导。固定主机密钥前，请将指纹与可信来源进行比较。使用 `POST /api/v1/cluster/bootstrap/{bootstrap_id}/cancel` 取消任务。

### 检查集群健康状态

读取实时节点、加速器、容量和组件摘要，并检查 Kubernetes 版本是否达到 Lens 的最低要求。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/overview?clusterId=<cluster-id>"

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "$LENS_URL/api/v1/cluster/clusters/<cluster-id>/kubernetes-version"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        overview = await lens.clusters.overview(cluster_id="<cluster-id>")
        version = await lens.clusters.read_cluster_kubernetes_version("<cluster-id>")

        print(overview.kubernetes.hardware.accelerators)
        print(version.version, version.supported)


asyncio.run(main())
```

  </TabItem>
</Tabs>

当某项读数不可用时，容量字段可能为 `null`；`null` 表示未知，而不是零。`ready` 只是可达性探测，并不保证有空闲 GPU。

| GET | `/api/v1/cluster/clusters` | `cluster:cluster:read` | 列出可见集群。 |

| GET | `/api/v1/cluster/overview` | `cluster:cluster:read` | 读取实时集群健康和容量。 |
| GET | `/api/v1/cluster/clusters/{cluster_id}/kubernetes-version` | `cluster:cluster:read` | 检查可达性和 Kubernetes 版本。 |
| GET | `/api/v1/cluster/sessions/{session_id}/planning-discovery/{resource}` | `cluster:planning:read` | 读取一个规划发现资源。 |
| GET | `/api/v1/cluster/clusters/{cluster_id}/gateway-port-check` | `cluster:cluster:update` | 检查 Gateway NodePort 是否空闲。 |
| GET | `/api/v1/cluster/model-secrets` | `cluster:cluster:read` | 列出集群的模型相关 Secret。 |
| POST | `/api/v1/cluster/clusters/{cluster_id}/nodes/cordon` | `cluster:node:operate` | 停止新的 Pod 调度到工作节点。 |
| POST | `/api/v1/cluster/clusters/{cluster_id}/nodes/uncordon` | `cluster:node:operate` | 让工作节点重新可调度。 |

### 引导

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| POST | `/api/v1/cluster/bootstrap/host-keys` | `cluster:bootstrap:execute` | 发现目标机器的 SSH 主机密钥。 |
| POST | `/api/v1/cluster/bootstrap/preflight` | `cluster:bootstrap:execute` | 校验 SSH、sudo 和节点前提条件。 |
| POST | `/api/v1/cluster/bootstrap` | `cluster:bootstrap:execute` | 启动 Kubespray 引导任务。 |
| GET | `/api/v1/cluster/bootstrap/{bootstrap_id}` | `cluster:bootstrap:read` | 读取任务状态和 kubeconfig 交付内容。 |
| POST | `/api/v1/cluster/bootstrap/{bootstrap_id}/cancel` | `cluster:bootstrap:execute` | 取消正在运行的引导任务。 |

大多数读取返回 `200`。注册和创建 HF Secret 返回 `201`；创建软件下载和引导任务返回 `202`；删除集群和取消引导返回 `204`。

## 错误与限制

- **`401` / `403`** — 未认证或无权访问该集群。管理员可以管理所有集群；维护者只能管理分配给自己的集群。
- **`404`** — 集群不存在、引导任务不存在或会话已失效。
- **`409 cluster_has_available_deployments`** 或 **`cluster_has_storage_volumes`** — 集群仍有资源，请先删除这些资源。
- **`422 invalid_kubeconfig`** — 上传的文件不是 UTF-8 文本。
- **`422 invalid_proxy_config`** — `proxy` 不是有效的 JSON。
- **`422 invalid_gateway_port`** 或 **`gateway_port_in_use`** — 请选择 `30000`-`32767` 之间空闲的 NodePort。
- **`422 gateway_provider_immutable`** — Gateway 提供程序只能分配一次。
- **`422 invalid_secret_token`** — Hugging Face 令牌为空。
- **`409 secret_already_exists`** — Secret 已存在；请使用 `PUT` 轮换。
- **`502 cluster_gateway_cleanup_failed`** — Gateway 清理失败，注册已保留。请重试删除。
- **`503 kubectl_unavailable`** 或 **`504 kubectl_timeout`** — Lens 无法访问集群 API。请检查 kubeconfig、网络和代理。
- 组件版本由 Lens 发行版固定。请求中的版本字段不会覆盖它们。
- Cordon 只会阻止新 Pod 调度，不会驱逐或停止正在运行的 Pod。
