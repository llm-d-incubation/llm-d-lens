Lens Deploy 会将已经渲染好的部署配置运行到 Kubernetes 集群，并跟踪每个运行、用例和执行。使用本模块可以部署已保存的配置产物、启动 Standard vLLM 服务、查看发布状态、连接就绪端点并清理资源。这里也包含配置准备端点，因为它们用于生成部署所消费的产物。

## 快速开始

启动一个 Standard vLLM 服务。模型必须已存在于已注册的 Model Cache 存储卷中并处于就绪状态。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -sX POST http://127.0.0.1:3000/api/v1/deployments/standard-vllm-runs \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-8B",
    "deployment_name": "qwen3-standard",
    "cluster_session_id": "<cluster-session-id>",
    "replicas": 1,
    "tensor_parallel_size": 1,
    "storage_volume_id": "<model-cache-volume-id>"
  }'
```

```json
{
  "id": "<run-id>",
  "status": "queued",
  "cases": []
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.deploy.standard_kubernetes_service import StandardKubernetesServiceRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        run = await lens.deploy.create_standard_kubernetes_service_run(
            StandardKubernetesServiceRequest(
                model="Qwen/Qwen3-8B",
                deployment_name="qwen3-standard",
                cluster_session_id="<cluster-session-id>",
                replicas=1,
                tensor_parallel_size=1,
                storage_volume_id="<model-cache-volume-id>",
            )
        )
        print(run.id, run.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 常见任务

### 部署已保存的配置

使用一个或多个可部署配置启动运行。包含多个用例的运行通过 `failure_policy` 决定某个用例失败后是否继续执行后续用例。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/deployments/runs`**

```json
{
  "configurations": [
    {
      "schema_version": "deployable-configuration.v1",
      "type": "baseline",
      "format": "helm",
      "provider_ref": "optimized-baseline",
      "checksum": "sha256:<checksum>",
      "content": {
        "model": {"name": "Qwen/Qwen3-8B"},
        "decode": {"replicaCount": 1, "tensorParallelSize": 1, "maxModelLen": 4096}
      },
      "provenance": {"deployment_name": "qwen3-guide"}
    }
  ],
  "failure_policy": "continue",
  "provenance": {"cluster_session_id": "<cluster-session-id>"}
}
```

响应字段：`id`、`status`、`cases[].id`、`cases[].status`、`cases[].execution_id`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.deploy.contracts import DeployableConfiguration, DeploymentRunCreateRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        run = await lens.deploy.create_run(
            DeploymentRunCreateRequest(
                configurations=[
                    DeployableConfiguration(
                        type="baseline",
                        format="helm",
                        provider_ref="optimized-baseline",
                        checksum="sha256:<checksum>",
                        content={
                            "model": {"name": "Qwen/Qwen3-8B"},
                            "decode": {
                                "replicaCount": 1,
                                "tensorParallelSize": 1,
                                "maxModelLen": 4096,
                            },
                        },
                        provenance={"deployment_name": "qwen3-guide"},
                    )
                ],
                provenance={"cluster_session_id": "<cluster-session-id>"},
            )
        )
        print(run.id, run.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 查找运行和执行

运行按最新优先返回。可用 `query` 按运行 id、provider ref、部署名称或命名空间搜索。执行可按状态和集群筛选。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/deployments/runs?query=qwen3`**

**`GET /api/v1/deployments/executions?status=ready&cluster_id=<cluster-id>`**

```json
{
  "items": [
    {
      "execution_id": "<execution-id>",
      "status": "ready",
      "cluster_id": "<cluster-id>",
      "namespace": "llmd-qwen3-standard",
      "endpoint": "http://qwen3-router.llmd-qwen3-standard.svc:8000"
    }
  ]
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.deploy.contracts import DeploymentStatus
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        runs = await lens.deploy.list_runs(query="qwen3")
        for run in runs:
            print(run.id, run.status)

        executions = await lens.deploy.list_executions(
            status=DeploymentStatus.READY,
            cluster_id="<cluster-id>",
        )
        for execution in executions.items:
            print(execution.execution_id, execution.endpoint)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 连接就绪端点并读取日志

`ready` 执行具有集群内 URL。在发送模型流量前，调用端点操作创建或复用可访问的转发 URL。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/deployments/executions/<execution-id>/endpoint`**

```json
{
  "success": true,
  "execution_id": "<execution-id>",
  "endpoint": "http://127.0.0.1:38000/v1",
  "namespace": "llmd-qwen3-standard",
  "service": "qwen3-router",
  "remote_port": 8000
}
```

使用 `GET /api/v1/deployments/executions/<execution-id>/pods/<pod-name>/logs?tail=200` 读取 Pod 日志。`tail` 取值为 1-2000。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        execution = await lens.deploy.get_execution("<execution-id>")
        print(execution.status, execution.endpoint)

        resolved = await lens.deploy.connect_execution_endpoint("<execution-id>")
        print(resolved.endpoint)

        logs = await lens.deploy.get_execution_pod_logs(
            "<execution-id>", "<pod-name>", tail=200
        )
        print(logs.logs)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 停止、清理或删除部署

可以只停止或清理单个用例而不删除运行历史。仅在运行进入终态后删除运行；删除时也会清理剩余用例。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/deployments/runs/<run-id>/cases/<case-id>/stop`**

**`POST /api/v1/deployments/runs/<run-id>/cases/<case-id>/clean`**

**`DELETE /api/v1/deployments/runs/<run-id>`** 返回 `204`。

```json
{
  "case": {"id": "<case-id>", "status": "stopped", "execution_id": "<execution-id>"},
  "execution": {"execution_id": "<execution-id>", "status": "rolled_back"},
  "deployment": {"run_id": "<run-id>", "case_id": "<case-id>", "status": "stopped"}
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.deploy.models import CleanCaseRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        stopped = await lens.deploy.stop_case("<run-id>", "<case-id>")
        print(stopped.case.status, stopped.execution.status)

        cleaned = await lens.deploy.clean_case(
            "<run-id>",
            "<case-id>",
            CleanCaseRequest(preserve_rendered_overlay=False),
        )
        print(cleaned.case.status)

        await lens.deploy.delete_run("<run-id>")

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 清理孤儿命名空间

孤儿命名空间匹配部署前缀，但没有被任何 Lens 执行记录引用。前缀之外的名称或仍被引用的名称会被拒绝。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/deployments/orphans?cluster_id=<cluster-id>`**

**`POST /api/v1/deployments/orphans/clean`**

```json
{
  "clusterId": "<cluster-id>",
  "namespaces": ["llmd-optimized-baseline-1-1-20260918032423139529"]
}
```

响应：`cleaned` 和 `failed` 命名空间列表。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.deploy.models import CleanOrphansRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        orphans = await lens.deploy.list_orphan_namespaces("<cluster-id>")
        print(orphans.prefix, [item.name for item in orphans.items])

        result = await lens.deploy.clean_orphan_namespaces_route(
            CleanOrphansRequest(
                cluster_id="<cluster-id>",
                namespaces=[item.name for item in orphans.items],
            )
        )
        print(result.cleaned, result.failed)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 扩缩容部署执行

为 ready 或 failed 状态的执行调整 Prefill 和 Decode model-server 副本数。只修改 Kubernetes 副本，不改变已保存的配置。支持 Deployment 和 DisaggregatedSet；DisaggregatedSet 只改 role 副本，不修改 `spec.slices`。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/deployments/executions/{execution_id}/scale`**

```json
{"prefill_replicas": 1, "decode_replicas": 2}
```

只修改传入的 role；聚合部署使用 `decode_replicas`。返回带 `scale` 的更新后执行。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.deploy.contracts import DeploymentScaleRequest
from llm_d_lens.sdk import LensLocal


async def main() -> None:
    with LensLocal("<username>") as lens:
        context = await lens.deploy.scale_execution(
            "<execution-id>",
            DeploymentScaleRequest(decode_replicas=2),
        )
        print(context.scale)


asyncio.run(main())
```

  </TabItem>
</Tabs>

## 端点

### 部署生命周期

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/api/v1/deployments` | `deployment:run:read` | 列出运行（`/runs` 的别名） |
| `GET` | `/api/v1/deployments/runs` | `deployment:run:read` | 列出或搜索运行 |
| `POST` | `/api/v1/deployments/runs` | `deployment:run:create` | 从配置启动运行 |
| `POST` | `/api/v1/deployments/standard-vllm-runs` | `deployment:run:create` | 启动 Standard vLLM 服务 |
| `GET` | `/api/v1/deployments/runs/{run_id}` | `deployment:run:read` | 获取运行及其用例 |
| `DELETE` | `/api/v1/deployments/runs/{run_id}` | `deployment:execution:delete` | 删除终态运行并清理资源 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cancel` | `deployment:run:cancel` | 取消活动运行 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cluster-session` | `deployment:session:rebind` | 重新绑定活动集群会话 |
| `GET` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}` | `deployment:run:read` | 获取用例、执行和摘要 |
| `GET` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}/logs` | `deployment:run:read` | 读取用例编排日志 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}/refresh` | `deployment:case:execute` | 重新读取用例实时状态 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}/stop` | `deployment:case:execute` | 停止用例 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}/restart` | `deployment:case:execute` | 重启已停止或失败的用例 |
| `POST` | `/api/v1/deployments/runs/{run_id}/cases/{case_id}/clean` | `deployment:case:execute` | 清理用例运行时资源 |
| `GET` | `/api/v1/deployments/executions` | `deployment:run:read` | 列出执行 |
| `GET` | `/api/v1/deployments/executions/{execution_id}` | `deployment:run:read` | 获取执行 |
| `PATCH` | `/api/v1/deployments/executions/{execution_id}` | `deployment:execution:update` | 编辑显示名称或描述 |
| `DELETE` | `/api/v1/deployments/executions/{execution_id}` | `deployment:execution:delete` | 删除执行记录 |
| `GET` | `/api/v1/deployments/executions/{execution_id}/pods` | `deployment:run:read` | 列出实时 Pod 状态 |
| `GET` | `/api/v1/deployments/executions/{execution_id}/pods/{pod_name}/logs` | `deployment:run:read` | 读取 Pod 日志 |
| `POST` | `/api/v1/deployments/executions/{execution_id}/endpoint` | `deployment:execution:connect` | 创建或复用转发端点 |
| `GET` | `/api/v1/deployments/cluster/{cluster_id}` | `deployment:run:read` | 列出集群的用例记录 |
| `GET` | `/api/v1/deployments/node-labels?cluster_id=<cluster-id>` | `deployment:run:create` | 列出节点标签键值 |
| `GET` | `/api/v1/deployments/runtime-classes?cluster_id=<cluster-id>` | `deployment:run:read` | 发现 RuntimeClass |
| `GET` | `/api/v1/deployments/orphans?cluster_id=<cluster-id>` | `deployment:run:read` | 列出孤儿命名空间 |
| `POST` | `/api/v1/deployments/orphans/clean` | `deployment:execution:delete` | 删除孤儿命名空间 |

## 错误与限制

| 状态码 | 含义 | 处理方式 |
| --- | --- | --- |
| `401` / `403` | 未认证或缺少权限 | 检查令牌和上表的权限列 |
| `404` | 运行、用例、执行或产物不存在 | 重新列出资源并确认 id |
| `409` | 生命周期冲突 | 等待终态或检查当前状态 |
| `422` | 请求无效或 Pod 日志缺少命名空间 | 修正请求字段 |
| `502` | 端口转发或清理失败 | 检查集群后重试 |
| `503` | 集群放置或 RuntimeClass 发现失败 | 检查集群访问权限后重试 |

- 活动运行的状态为 `queued`、`running` 或 `cancelling`。删除前先取消活动运行。后台协调器只将 `cleaned` 和 `cancelled` 运行视为终态，因此失败的回滚仍可能恢复。
- 已停止的用例会保留 `rolled_back` 执行记录。已清理的用例仍保留在运行历史中。
- 执行必须为 `ready` 且包含端点，才能连接或用于基准测试。
- Standard vLLM 运行要求 Model Cache 中存在就绪模型，并提供已注册的 Model Cache 存储卷。`local-cache` 和直接 `pvc` 存储会被拒绝。
- `placement_node_label` 需要 `placement_replicas: "same-node"`，且标签必须存在于目标集群。LeaderWorkerSet 不能使用 `balanced` 或 `spread`。
- 删除运行会先清理剩余用例。活动运行返回 `409`；请先取消并等待终态。
- 用例 `clean` 会删除运行时资源但保留生命周期记录。`preserve_rendered_overlay=true` 会保留渲染文件。
- 用例日志的 `limit` 为 1-1000（默认 200）。Pod 日志的 `tail` 为 1-2000。
