使用管理（Administration）登录、创建用户、授予角色和集群访问权限、查看或撤销会话，并维护 Lens 系统设置，例如数据库连接和存储密钥主密钥。需要为某人授予或移除访问权限，或确认 Lens 安装的安全状态时使用本模块。

## 快速开始

登录以获取访问令牌并确认生成的 principal。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -s -X POST http://127.0.0.1:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -c cookies.txt \
  -d '{"username":"<username>","password":"<password>"}'

curl -H "Authorization: Bearer $LENS_ACCESS_TOKEN" \
  http://127.0.0.1:3000/api/v1/auth/session
```

登录响应返回 `accessToken`、`tokenType`、`expiresIn` 和当前 `principal`。后续请求将该令牌作为 Bearer 令牌发送。刷新 Cookie 保存在 `cookies.txt` 中。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        principal = await lens.administration.current_session()
        print(principal.user_id, principal.username, principal.permissions)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 常见任务

### 1. 创建并列出用户

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/users \
  -d '{"username":"<username>","password":"<password>","displayName":"<display-name>","email":"<email>"}'

curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/users?query=<search>&status=active"
```

创建返回 `201 Created` 和用户记录。列表为每个用户返回直接 `roles`、`groups` 和 `inheritedRoles`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.auth.models import UserCreateRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        user = await lens.administration.create_user(
            UserCreateRequest(
                username="<username>",
                password="<password>",
                displayName="<display-name>",
                email="<email>",
            )
        )
        print(user.id, user.username)

        users = await lens.administration.list_users(query="<search>", status="active")
        for item in users:
            print(item.id, item.username, item.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 2. 更新、停用或重置用户

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X PATCH -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/users/<user-id> \
  -d '{"displayName":"<display-name>","email":"<email>","status":"disabled"}'

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/users/<user-id>/password \
  -d '{"newPassword":"<new-password>"}'
```

重置密码返回 `204 No Content`。停用用户会保留记录，但阻止其后续登录。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.auth.models import ResetPasswordRequest, UserUpdateRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        user = await lens.administration.update_user(
            "<user-id>",
            UserUpdateRequest(
                displayName="<display-name>",
                email="<email>",
                status="disabled",
            ),
        )
        print(user.id, user.status)

        await lens.administration.reset_password(
            "<user-id>", ResetPasswordRequest(newPassword="<new-password>")
        )

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 3. 授予或撤销集群访问权限

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/clusters/<cluster-id>/access \
  -d '{"subjectType":"user","subjectId":"<user-id>","roleId":"<role-id>"}'

curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/clusters/<cluster-id>/access

curl -X DELETE -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/clusters/<cluster-id>/access/<binding-id>
```

授予返回 `201 Created` 和绑定记录。删除返回 `204 No Content`。使用 `subjectType: "group"` 和组 ID 可授予组。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.auth.models import AccessRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        binding = await lens.administration.grant_cluster_access(
            "<cluster-id>",
            AccessRequest(subjectType="user", subjectId="<user-id>", roleId="<role-id>"),
        )
        print(binding.id, binding.scope_cluster_id)

        items = await lens.administration.list_cluster_access("<cluster-id>")
        print(len(items))

        await lens.administration.revoke_cluster_access("<cluster-id>", binding.id)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 4. 创建角色并设置其权限

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/roles \
  -d '{"name":"<role-name>","description":"<description>","permissions":["cluster:cluster:read"]}'

curl -X PUT -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/roles/<role-id>/permissions \
  -d '{"permissions":["cluster:cluster:read","deployment:run:read"]}'
```

创建返回 `201 Created`。设置权限返回 `204 No Content`，且仅适用于自定义角色。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.auth.models import RoleCreateRequest, RolePermissionsRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        role = await lens.administration.create_role(
            RoleCreateRequest(
                name="<role-name>",
                description="<description>",
                permissions=["cluster:cluster:read"],
            )
        )
        print(role.id, role.name)

        await lens.administration.set_role_permissions(
            role.id,
            RolePermissionsRequest(
                permissions=["cluster:cluster:read", "deployment:run:read"]
            ),
        )

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 5. 列出并撤销会话

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  "http://127.0.0.1:3000/api/v1/sessions?include_revoked=true"

curl -X DELETE -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/sessions/<session-id>
```

拥有 `session:session:revoke` 的管理员可看到所有会话；其他调用方只能看到自己的会话。删除返回 `204 No Content`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        sessions = await lens.administration.list_sessions(include_revoked=True)
        for session in sessions:
            print(session.id, session.user_id, session.revoked_at)

        await lens.administration.revoke_session("<session-id>")

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 6. 轮换存储密钥主密钥

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -H "Authorization: Bearer $LENS_TOKEN" \
  http://127.0.0.1:3000/api/v1/system/secret-key

curl -X POST -H "Authorization: Bearer $LENS_TOKEN" \
  -H "Content-Type: application/json" \
  http://127.0.0.1:3000/api/v1/system/secret-key/rotate \
  -d '{"newKey":"<new-key>"}'
```

状态响应返回 `source`、`envLocked`、`fingerprint`、`oldKeyCount` 和 `providerSecretCount`，但绝不返回密钥本身。轮换会重新加密提供商密钥并报告 `rotatedSecrets`。将 `newKey` 留空可自动生成密钥。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
import asyncio

from llm_d_lens.auth.models import RotateSecretKeyRequest
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    async def main() -> None:
        status = await lens.administration.get_secret_key_status()
        print(status.source, status.env_locked, status.fingerprint)

        rotated = await lens.administration.rotate_secret_key(
            RotateSecretKeyRequest(newKey="<new-key>")
        )
        print(rotated.fingerprint, rotated.rotated_secrets)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 端点

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| POST | `/api/v1/auth/login` | 公开 | 登录；返回访问令牌并设置刷新 Cookie。 |
| POST | `/api/v1/auth/refresh` | 公开，需刷新 Cookie 和 CSRF | 使用刷新 Cookie 和 CSRF 请求头获取新的访问令牌。 |
| POST | `/api/v1/auth/logout` | 已认证 | 撤销当前会话（`204`）。 |
| GET | `/api/v1/auth/session` | 已认证 | 读取当前 principal 和权限。 |
| POST | `/api/v1/auth/password` | 已认证 | 修改自己的密码（`204`）。 |
| GET | `/api/v1/auth/sessions` | 已认证 | 列出自己的会话。 |
| GET | `/api/v1/sessions` | 已认证 | 列出会话；管理员可看到所有会话。 |
| DELETE | `/api/v1/sessions/{session_id}` | 已认证 | 撤销会话（`204`）。 |
| GET | `/api/v1/users` | `user:user:read` | 列出用户及其继承的访问权限。 |
| POST | `/api/v1/users` | `user:user:create` | 创建用户（`201`）。 |
| GET | `/api/v1/users/{user_id}` | `user:user:read` | 读取单个用户。 |
| PATCH | `/api/v1/users/{user_id}` | `user:user:update` | 更新资料字段或状态。 |
| DELETE | `/api/v1/users/{user_id}` | `user:user:delete` | 删除用户（`204`）。 |
| POST | `/api/v1/users/{user_id}/password` | `user:user:reset-password` | 重置密码（`204`）。 |
| GET, POST | `/api/v1/users/{user_id}/role-bindings` | `role:binding:manage` | 列出或添加用户角色绑定。 |
| DELETE | `/api/v1/users/{user_id}/role-bindings/{binding_id}` | `role:binding:manage` | 移除用户角色绑定（`204`）。 |
| GET, POST | `/api/v1/groups/{group_id}/role-bindings` | `role:binding:manage` | 列出或添加组角色绑定。 |
| DELETE | `/api/v1/groups/{group_id}/role-bindings/{binding_id}` | `role:binding:manage` | 移除组角色绑定（`204`）。 |
| GET | `/api/v1/roles` | `role:role:read` | 列出角色和权限。 |
| POST | `/api/v1/roles` | `role:role:create` | 创建自定义角色（`201`）。 |
| GET | `/api/v1/roles/{role_id}` | `role:role:read` | 读取单个角色。 |
| PATCH | `/api/v1/roles/{role_id}` | `role:role:update` | 更新自定义角色。 |
| DELETE | `/api/v1/roles/{role_id}` | `role:role:delete` | 删除自定义角色（`204`）。 |
| PUT | `/api/v1/roles/{role_id}/permissions` | `role:role:update` | 替换自定义角色的权限（`204`）。 |
| GET, POST | `/api/v1/clusters/{cluster_id}/access` | `cluster:cluster:grant-access` | 列出或授予集群访问权限。 |
| DELETE | `/api/v1/clusters/{cluster_id}/access/{binding_id}` | `cluster:cluster:grant-access` | 撤销集群访问权限（`204`）。 |
| GET | `/api/v1/system/database` | `system:database:read` | 读取数据库配置状态。 |
| POST | `/api/v1/system/database` | `system:database:configure` | 配置 Lens 数据库。 |
| GET | `/api/v1/system/secret-key` | `system:secret:read` | 读取主密钥状态。 |
| POST | `/api/v1/system/secret-key/rotate` | `system:secret:manage` | 轮换主密钥。 |
| DELETE | `/api/v1/system/secret-key/old` | `system:secret:manage` | 删除保留的回退密钥。 |

## 错误与限制

- **401**：凭据无效、会话过期或已撤销，或账户被锁定。**403**：缺少权限、访问其他用户的会话，或无权访问集群。
- **404**：用户、角色、组、会话或绑定不存在。**409**：用户名、组或角色重复；受保护的内置账户；移除最后一个全局管理员；或停用内置管理员。
- **422**：权限代码无效、请求格式错误，或密码少于 12 个字符、与用户名相同，或未混合至少三类字符。
- 刷新使用 HttpOnly 刷新 Cookie 和 `X-Prism-CSRF` 请求头；Bearer 请求不需要 CSRF。登出会撤销当前会话。
- 资源级角色绑定只接受 `scopeResourceType: "model_service_group"` 和内置 end-user 角色。模型和集群必须匹配，且授权对象需要具备该集群的推理权限。日常模型授权请使用[带 scope 校验的模型访问 API](/api-reference/modules/model-services)。
- 当 `LENS_SECRET_KEY` 由环境变量锁定时，主密钥轮换会被拒绝。清除旧密钥会使仍使用这些密钥加密的密钥无法读取。
- 数据库配置：外部模式要求 `databaseUrl` 的 scheme 与 `engine` 匹配；嵌入式模式始终使用 PostgreSQL。连接错误返回 `422`；配置失败返回 `409`。
