## 后端 API

模型服务路由分布在 `llm_d_lens/model_service/router.py` 的用户、管理员、公共和内部路由器中。

### 列出模型访问令牌

列出调用方当前有效的模型访问令牌。响应永远不包含明文令牌值，只包含用于识别和日后吊销所需的元数据。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/tokens`**

    请求：无请求体。调用方必须已通过 Lens 用户会话进行身份验证。

    响应：返回一个 `items` 数组，其中每个元素都是经过 `ModelAccessToken.api_payload()` 投影后的 `ModelAccessToken` 记录，因此 `tokenHash` 字段被省略。

    ```json
    {
      "items": [
        {
          "id": "mat-7f2c4a19b6d1",
          "userId": "user-123",
          "name": "laptop",
          "tokenHint": "9mQx",
          "status": "active",
          "lastUsedAt": "2026-09-23T08:15:00Z",
          "lastUsedIp": "10.0.0.25",
          "createdAt": "2026-09-21T12:00:00Z"
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    tokens = service.tokens.list_for_user("user-123", include_revoked=False)
    for token in tokens:
        print(token.api_payload())
    ```
  </TabItem>
</Tabs>

### 创建模型访问令牌

为调用方创建一个新的模型访问令牌。明文令牌仅返回一次，与持久化保存的令牌元数据一起返回。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/tokens`**

    请求体（`TokenCreateRequest`）：

    - `name`（`string`）：令牌的显示名称。

    ```json
    {
      "name": "automation"
    }
    ```

    响应：一个 `ModelAccessToken` 载荷，外加一次性的 `token` 字符串。

    ```json
    {
      "id": "mat-2c47de48a35b",
      "userId": "user-123",
      "name": "automation",
      "tokenHint": "K8xP",
      "status": "active",
      "createdAt": "2026-09-23T09:00:00Z",
      "token": "lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.create("user-123", name="automation")

    print(token.api_payload())
    print(raw_token)
    ```
  </TabItem>
</Tabs>

### 重新生成模型访问令牌

吊销调用方当前有效的一个或多个令牌，然后签发一个新令牌。你可以选择性地为替换后的新令牌指定一个名称。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/tokens/regenerate`**

    请求体：可选的 `TokenCreateRequest`。若省略，该路由使用 `"default"`。

    ```json
    {
      "name": "default"
    }
    ```

    响应：新签发的令牌元数据，外加新的明文令牌。

    ```json
    {
      "id": "mat-54b2a51d9d93",
      "userId": "user-123",
      "name": "default",
      "tokenHint": "F6rN",
      "status": "active",
      "createdAt": "2026-09-23T09:05:00Z",
      "token": "lens-mk-Gq4nP1sT8uV2xY5zA7bC9dE3fH6jK8mN0pR"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.regenerate("user-123", name="default")

    print(token.id, raw_token)
    ```
  </TabItem>
</Tabs>

### 吊销模型访问令牌

吊销调用方此前签发的一个模型访问令牌。吊销后，该令牌将无法再用于网关访问。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`DELETE /api/v1/model-service/tokens/{token_id}`**

    请求：无请求体。

    - `token_id`（`string`，路径参数）：令牌 ID，例如 `mat-7f2c4a19b6d1`。

    响应：`204 No Content`。该端点不返回 JSON 响应体。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    revoked = service.tokens.revoke("user-123", "mat-7f2c4a19b6d1")
    print(revoked)
    ```
  </TabItem>
</Tabs>

### 获取网关连接信息

返回客户端用于配置其 OpenAI 客户端的 Gateway 连接信息。每个集群都运行自己的 Gateway，因此响应会为调用方可访问的每个集群分别列出一条连接；当设置了 `LENS_MODEL_GATEWAY_PUBLIC_URL` 时，它会作为单一覆盖值应用到每个集群。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/connection`**

    请求：无请求体。

    响应：全局覆盖值（未设置时为空字符串），外加一个按集群分组的列表。

    ```json
    {
      "baseUrl": "",
      "clusters": [
        {
          "clusterId": "cluster-a",
          "clusterName": "Cluster A",
          "provider": "istio",
          "gatewayName": "lens-inference-gateway",
          "address": "10.0.0.10",
          "publicUrl": null,
          "port": null,
          "baseUrl": "http://10.0.0.10/v1",
          "ready": true
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import os

    import asyncio

    from llm_d_lens.model_service.gateway_ops import GatewayOpsService, gateway_base_url

    global_url = os.environ.get("LENS_MODEL_GATEWAY_PUBLIC_URL", "").strip()
    public_host = os.environ.get("LENS_PUBLIC_HOST", "").strip()
    status = asyncio.run(GatewayOpsService().status())
    clusters = [
        {
            "clusterId": cluster.cluster_id,
            "clusterName": cluster.cluster_name,
            "provider": cluster.gateway_provider,
            "gatewayName": cluster.gateway_name,
            "address": cluster.gateway_address,
            "publicUrl": cluster.gateway_public_url,
            "port": cluster.gateway_port,
            "baseUrl": gateway_base_url(cluster, public_host, global_url),
            "ready": bool(cluster.gateway_ready),
        }
        for cluster in status.clusters
    ]

    print({"baseUrl": global_url, "clusters": clusters})
    ```
  </TabItem>
</Tabs>

### 获取每日使用总量

将调用方最近的使用记录按天聚合为 token 总量。该处理函数复用同一份使用流水账，并通过 `_daily_totals` 对其进行分桶统计。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/usage/timeseries`**

    请求：无请求体。

    - `days`（`integer`，查询参数，默认值 `30`，取值范围 `1..365`）：要包含的最近天数。

    响应：每日使用量分桶，其中包含每个 token 类别的总量。

    ```json
    {
      "items": [
        {
          "date": "2026-09-22",
          "requests": 4,
          "inputTokens": 1200,
          "cachedInputTokens": 300,
          "cacheWriteTokens": 0,
          "outputTokens": 640
        },
        {
          "date": "2026-09-23",
          "requests": 2,
          "inputTokens": 530,
          "cachedInputTokens": 64,
          "cacheWriteTokens": 0,
          "outputTokens": 211
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from datetime import datetime, timedelta

    from llm_d_lens.model_service.router import _daily_totals
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    since = datetime.now() - timedelta(days=30)

    print(_daily_totals(records))
    ```

### 列出模型路由组

列出调用方具备集群级读取权限的模型组。每个组是路由到部署 InferencePool 的公开模型名称。
`GET /api/v1/model-service/admin/groups/{group_id}` 也要求相应 scope 内的
`model-service:group:read`。模型响应还包含可空的 `ownerUserId`、`ownerGroupId`；
所有权本身不授予消费者推理权限。

### 模型推理授权

所有访问管理端点都要求调用方在模型所属集群拥有 `model-service:group:share`。
admin 和 maintainer 具备该权限，但它不包含模型本身或 Gateway 的管理权限。
授权覆盖该模型的所有提供方，不包含管理 API。重命名保留授权，删除模型清理授权；
即使模型为空，只要还有授权，也不能迁移到其他集群。

<Tabs>
  <TabItem value="rest-api" label="REST API">

| 方法 | `/api/v1/model-service/admin/groups/{group_id}` 下的路径 | 响应 |
| --- | --- | --- |
| GET | `/access` | `{"items":[...]}`，包含授权 ID、`subjectType`、`subjectId`、`subjectName`、`permission`、`createdAt` |
| GET | `/access/options` | `{"users":[{"id":"user-123","username":"alice"}],"groups":[{"id":"group-123","name":"team"}]}` |
| POST | `/access` | HTTP 201，包含授权 ID、对象和推理权限 |
| DELETE | `/access/{binding_id}` | HTTP 204，空响应体 |

POST 请求体：

```json
{"subjectType":"user","subjectId":"user-123"}
```

响应示例：

```json
{"id":"binding-123","subjectType":"user","subjectId":"user-123","permission":"model-service:inference:use"}
```

向用户组授权时使用 `subjectType: "group"`。不接受角色、集群或所有者字段；
服务器固定授权角色，并从模型记录确定集群。对象必须已在该集群拥有推理权限。
options 只返回符合条件对象的 ID 和显示名称，不暴露完整身份记录；禁用或受保护用户不能选择。

scope 不足返回 403；资源不存在或撤权绑定不匹配返回 404；重复授权返回 409；
无效或多余字段返回 422。撤权影响使用已有 API key 的后续请求，不中断已开始的流，
也不修改 HTTPRoute 权重。
  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_lens.model_service.contracts import ModelGrantRequest
from llm_d_lens.model_service.service import default_service

def grant_model(model_id: str, user_id: str, principal):
    service = default_service()
    return service.grant_access(
        model_id,
        ModelGrantRequest(subject_type="user", subject_id=user_id),
        principal=principal,
    )

def read_model_access(model_id: str, principal):
    service = default_service()
    return (
        service.list_access(model_id, principal=principal),
        service.access_options(model_id, principal=principal),
    )

def revoke_model(model_id: str, binding_id: str, principal):
    default_service().revoke_access(model_id, binding_id, principal=principal)
```

传入已认证调用方解析后的 principal。这些方法对内部调用同样校验授权管理权限及模型集群 scope。
  </TabItem>
</Tabs>

### 创建模型路由组

创建集群内公开模型名称对应的路由组。`name`、`clusterId` 必填，名称在集群内唯一，
所有提供方必须位于该集群。提供 `executionId` 时，组与初始成员在同一事务中创建，
供 **Add model** 使用。部署必须就绪且有模型名称；服务端从部署推导 `modelRef`、
`servedName`，将 `baseModel` 设为公开名称，忽略调用方对这三个字段的覆盖。
不传 `executionId` 时仍支持单独创建组。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/admin/groups`**

    请求体（`GroupCreateRequest`）：

    - `name`（`string`）：客户端在 Chat Completions API 中使用的公开模型名称。
    - `clusterId`（`string`）：该服务所属的集群（必填）；其提供方必须都位于该集群内，且名称在该集群内唯一。
    - `displayName`（`string`，可选）：便于在 UI 中展示的标签；默认为 `name`。
    - `description`（`string`，可选）：自由格式的描述。
    - `executionId`（`string`，可选）：作为初始成员发布的就绪部署；需要该集群中的 `model-service:group:manage` 和 `model-service:member:manage` 权限。
    - `modelRef` / `servedName` / `baseModel`（`string`，可选，高级选项）：传入 `executionId` 时由服务端推导；否则 `modelRef` 默认为 `name`，`baseModel` 默认为 `modelRef`，`servedName` 为 null。
    - `selectionPolicy`（`string`，遗留字段）：为兼容性而接受此参数；llm-d 数据面会忽略它。

    ```json
    {
      "name": "qwen3-8b",
      "clusterId": "cluster-a",
      "executionId": "exec-123",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service"
    }
    ```

    响应：`201` 和创建后的 `ModelServiceGroup`。传入 `executionId` 时成员同时提交，
    并在后台安排 Gateway 调谐。权限或范围不足返回 `403`，目标不存在返回 `404`，
    名称重复、集群不匹配、部署未就绪或无模型名称返回 `409`，输入无效返回 `422`。
    事务失败不会留下任一记录。

    ```json
    {
      "id": "msg-4a8b41f3dd6c",
      "name": "qwen3-8b",
      "modelRef": "Qwen/Qwen3-8B",
      "clusterId": "cluster-a",
      "servedName": "Qwen/Qwen3-8B",
      "baseModel": "qwen3-8b",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service",
      "selectionPolicy": "random",
      "status": "active",
      "createdByUserId": "user-123",
      "createdAt": "2026-09-23T09:10:00Z",
      "updatedAt": "2026-09-23T09:10:00Z"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_lens.model_service.contracts import GroupCreateRequest
    from llm_d_lens.model_service.service import default_service

    service = default_service()
    group = service.create_group(
    ```

### 保存并应用流量分配

原子更新全部权重，并可添加部署提供方，然后调谐集群的共享 Gateway 和加权 HTTPRoute。
需要模型组所在集群中的 `model-service:member:manage` 权限。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`PUT /api/v1/model-service/admin/groups/{group_id}/traffic`**

    请求体（`TrafficUpdateRequest`）：

    - `members`：完整的 1 到 16 个成员，每项包含 `executionId` 和 **0..1000000** 范围内的整数 `weight`。不能遗漏已有成员；移除成员请使用删除接口。
    - `expectedWeights`：之前读取的执行 ID 到权重的映射，包含所有已有提供方，不含新提供方。

    ```json
    {
      "members": [
        {"executionId": "stable", "weight": 90},
        {"executionId": "canary", "weight": 10}
      ],
      "expectedWeights": {"stable": 1}
    }
    ```

    新部署及从零权重激活的提供方必须就绪、位于同一集群、使用不同的
    InferencePool/EPP，且提供方模型名称与组一致。至少一个未禁用提供方的权重为正。
    零权重成员保留但不写入 backendRefs，离线成员也不接收流量。

    响应：`200`，包含完整更新后的 `items`（包括 `weight`）和 `operation`
    （含 `status`、`message`、`detailJson` 的 `GatewayOperation`）。
    **操作失败不会回滚已保存权重。** `succeeded` 只表示已提交配置，不代表已测得流量比例。

    格式或范围错误返回 `422`，快照过期或分配无效返回 `409 model_traffic_conflict`，
    目标不存在返回 `404`，权限不足返回 `403`。保存后的传输或领域异常返回
    `502 model_traffic_apply_failed`，明确说明配置已保存；重新读取分配，修复后重试 Reconcile。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    `ModelService.update_traffic()` 校验并持久化；调用
    `GatewayOpsService.reconcile_cluster_gateway()` 提交配置。
    主体必须来自已认证请求，不能来自用户自行提交的身份。

    ```python
    from llm_d_lens.auth.access import current_principal
    from llm_d_lens.model_service.contracts import TrafficUpdateRequest
    from llm_d_lens.model_service.gateway_ops import GatewayOpsService
    from llm_d_lens.model_service.service import default_service

    async def configure_traffic(request, group_id, canary_execution_id):
        service = default_service()
        principal = current_principal(request)
        existing = service.list_members(group_id)
        weights = {member.execution_id: member.weight for member in existing}
        members = [{"executionId": member.execution_id, "weight": member.weight}
                   for member in existing]
        members[0]["weight"] = 90
        members.append({"executionId": canary_execution_id, "weight": 10})
        saved = service.update_traffic(
            group_id,
            TrafficUpdateRequest(members=members, expectedWeights=weights),
            principal=principal,
        )
        operation = await GatewayOpsService().reconcile_cluster_gateway(
            saved[0].cluster_id, actor=principal.user_id,
        )
        return {"items": [member.api_payload() for member in saved],
                "operation": operation.api_payload()}
    ```
  </TabItem>
</Tabs>

`render_model_route(..., pools=[PoolBinding(...)])` 生成精确的相对权重、一个 IPP
模型映射及跨命名空间 ReferenceGrant。保留原有 `pool=PoolBinding(...)` 单后端调用，
但不能同时传入两种形式。`PoolBinding.weight` 默认为 1。

  <TabItem value="python-api" label="Python API">

    ```python
    from llm_d_lens.cluster.registry import gateway_lock
    from llm_d_lens.model_service.gateway_ops import GatewayOpsService
    from llm_d_lens.model_service.service import default_service

    async def remove_model(group_id, principal):
        service = default_service()
    ```

    ```python
    async def stop_providers(group_id, principal):
        members = default_service().set_providers_status(
            group_id, ProvidersStatusRequest(status="disabled"), principal=principal
        )
        for cluster_id in {member.cluster_id for member in members}:

                cluster_id, actor=principal.user_id
            )
            if operation.status != "succeeded":

        return members
    ```
