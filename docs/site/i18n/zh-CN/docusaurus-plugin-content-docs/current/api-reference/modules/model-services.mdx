## 这个模块是什么

模型服务会把一个就绪的部署转换为可通过共享网关调用的、兼容 OpenAI 的模型名称。你可以用它创建和轮换 API 密钥、查找可调用的模型和网关地址、发送聊天请求、查看 token 用量，并在具备相应权限时发布部署和授予推理访问权限。

## 快速开始

先创建 API 密钥，再找到所属集群的网关，然后用任意兼容 OpenAI 的客户端调用已发布的模型。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# 1. 创建 API 密钥。立即复制 `token`：它只会返回一次。
curl -X POST "$LENS_URL/api/v1/model-service/tokens" \
  -H "Content-Type: application/json" \
  -d '{"name":"my-app"}'

# 2. 获取所属集群的网关基础 URL。
curl "$LENS_URL/api/v1/model-service/connection"

# 3. 通过该网关调用模型。
curl "$GATEWAY_URL/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"model":"<model>","messages":[{"role":"user","content":"Hello"}]}'
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.model_service.contracts import TokenCreateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        issued = await lens.model_services.create_token(TokenCreateRequest(name="my-app"))
        print(issued.token)

        connection = await lens.model_services.model_service_connection()
        for cluster in connection.clusters:
            print(cluster.cluster_name, cluster.base_url)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 常见任务

### 轮换或吊销 API 密钥

轮换会吊销当前有效的一个或多个密钥，并签发替代密钥。吊销单个密钥返回 `204`，使用该密钥的新请求将无法再通过认证。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl -X POST "$LENS_URL/api/v1/model-service/tokens/regenerate" \
  -H "Content-Type: application/json" \
  -d '{"name":"default"}'

curl -X DELETE "$LENS_URL/api/v1/model-service/tokens/<token-id>"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.model_service.contracts import TokenCreateRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        issued = await lens.model_services.regenerate_token(TokenCreateRequest(name="default"))
        print(issued.token)
        await lens.model_services.revoke_token("<token-id>")

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 查找可调用的模型和网关地址

模型服务是集群范围的，因此列表项会包含 `clusterName`，用于区分不同集群中的同名公开模型。只有处于活动状态且存在在线、正权重提供方的模型才会出现。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl "$LENS_URL/api/v1/model-service/models"
curl "$LENS_URL/api/v1/model-service/connection"
```

```json
{
  "items": [
    {
      "id": "msg-4a8b41f3dd6c",
      "name": "<model>",
      "clusterId": "cluster-a",
      "clusterName": "Cluster A",
      "status": "active"
    }
  ]
}
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        models = await lens.model_services.list_models()
        for model in models.items:
            print(model.name, model.cluster_name)

        connection = await lens.model_services.model_service_connection()
        for cluster in connection.clusters:
            print(cluster.cluster_name, cluster.base_url, cluster.ready)

    asyncio.run(main())
```

### 调用已发布的模型

将网关基础 URL 用于任意兼容 OpenAI 的客户端。请求中的 `model` 应填写公开模型名称，而不是提供方内部的模型名称。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl "$GATEWAY_URL/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"model":"<model>","messages":[{"role":"user","content":"Hello"}]}'
```

要列出某个密钥可以调用的模型，请使用同一个密钥请求 `GET /v1/models`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from openai import OpenAI

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        connection = await lens.model_services.model_service_connection()
        models = await lens.model_services.list_models()

        client = OpenAI(base_url=connection.clusters[0].base_url, api_key="<token>")
        reply = client.chat.completions.create(
            model=models.items[0].name,
            messages=[{"role": "user", "content": "Hello"}],
        )
        print(reply.choices[0].message.content)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 将就绪部署发布为模型

就绪部署可以成为其所在集群中的一个新公开模型名称。如果该集群中已存在这个公开名称，请将该部署添加为提供方，而不是重复发布。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
# 查找就绪部署及其 executionId。
curl "$LENS_URL/api/v1/model-service/admin/deployments"

curl -X POST "$LENS_URL/api/v1/model-service/admin/groups/publish" \
  -H "Content-Type: application/json" \
  -d '{"name":"<model>","clusterId":"<cluster-id>","executionId":"<execution-id>"}'
```

响应（`201`）是创建的模型服务。要向现有模型添加另一个部署，请使用 `POST /api/v1/model-service/admin/members`，并传入 `groupId` 和 `executionId`。

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal
from llm_d_lens.model_service.contracts import GroupPublishRequest

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        group = await lens.model_services.admin_publish_group(
            GroupPublishRequest(
                name="<model>",
                clusterId="<cluster-id>",
                executionId="<execution-id>",
            )
        )
        print(group.id, group.name, group.status)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

### 查看用量

用量按请求记录。使用按日时间序列查看趋势，使用记录列表查看单个请求。

<Tabs>
  <TabItem value="rest-api" label="REST API">

```bash
curl "$LENS_URL/api/v1/model-service/usage/records?limit=50&offset=0"
curl "$LENS_URL/api/v1/model-service/usage/timeseries?days=30"
```

  </TabItem>
  <TabItem value="python-api" label="In-process Python SDK">

```python
from llm_d_lens.sdk import LensLocal

with LensLocal("<username>") as lens:
    import asyncio

    async def main() -> None:
        records = await lens.model_services.usage_records(limit=50, offset=0)
        for record in records.items:
            print(record.group_name, record.input_tokens, record.output_tokens)

        totals = await lens.model_services.usage_timeseries(days=30)
        for item in totals.items:
            print(item.date, item.requests, item.output_tokens)

    asyncio.run(main())
```

  </TabItem>
</Tabs>

## 端点

面向使用者和 API 密钥的端点：

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/v1/model-service/tokens` | `model-service:token:manage` | 列出你的有效 API 密钥。 |
| POST | `/api/v1/model-service/tokens` | `model-service:token:manage` | 创建密钥；明文只返回一次。 |
| POST | `/api/v1/model-service/tokens/regenerate` | `model-service:token:manage` | 吊销有效密钥并签发替代密钥。 |
| DELETE | `/api/v1/model-service/tokens/{token_id}` | `model-service:token:manage` | 吊销一个密钥。 |
| GET | `/api/v1/model-service/models` | `model-service:inference:use` | 列出你可以调用的模型。 |
| GET | `/api/v1/model-service/connection` | `model-service:inference:use` | 获取各集群的网关基础 URL。 |
| GET | `/api/v1/model-service/usage/records` | `model-service:usage:read` | 列出你的近期用量。 |
| GET | `/api/v1/model-service/usage/timeseries` | `model-service:usage:read` | 获取每日 token 总量。 |
| GET | `/v1/models` | 模型 token | 兼容 OpenAI 的模型列表。 |
| POST | `/v1/chat/completions` | 模型 token | 兼容 OpenAI 的聊天补全。 |

### 管理

这些操作需要集群范围的模型服务权限。

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/v1/model-service/admin/groups[/{group_id}]` | `model-service:group:read` | 列出或获取模型服务。 |
| POST | `/api/v1/model-service/admin/groups` | `model-service:group:manage` | 创建模型服务，可选择同时加入一个部署。 |
| POST | `/api/v1/model-service/admin/groups/publish` | `model-service:member:manage` | 将就绪部署发布为新模型。 |
| PATCH | `/api/v1/model-service/admin/groups/{group_id}` | `model-service:group:manage` | 更新元数据或状态。 |
| POST | `/api/v1/model-service/admin/groups/{group_id}/status` | `model-service:group:toggle` | 启用或停用模型。 |
| DELETE | `/api/v1/model-service/admin/groups/{group_id}` | `model-service:group:remove` | 删除空模型。 |
| GET/POST/DELETE | `/api/v1/model-service/admin/groups/{group_id}/access[/{binding_id}]` | `model-service:group:share` | 列出、授予或撤销推理访问权限。 |
| PUT | `/api/v1/model-service/admin/groups/{group_id}/traffic` | `model-service:member:manage` | 替换提供方权重。 |
| PUT | `/api/v1/model-service/admin/groups/{group_id}/providers/status` | `model-service:member:manage` | 启动或停止所有提供方。 |
| GET | `/api/v1/model-service/admin/members` | `model-service:group:read` | 列出已发布的提供方。 |
| POST | `/api/v1/model-service/admin/members` | `model-service:member:manage` | 向现有模型添加提供方。 |
| PATCH/DELETE | `/api/v1/model-service/admin/members/{member_id}` | `model-service:member:manage` | 更改或移除提供方。 |
| GET | `/api/v1/model-service/admin/deployments` | `model-service:group:read` | 列出可发布的部署。 |
| GET | `/api/v1/model-service/admin/usage[/analytics]` | `usage:report:read` | 查看跨用户、模型和集群的用量。 |

## 错误 / 限制

- **模型 token 只返回一次。** 只有 `POST /api/v1/model-service/tokens` 和 `POST /api/v1/model-service/tokens/regenerate` 的响应包含 `token`。其他响应只显示 `tokenHint`。请立即保存 token。
- **访问同时需要集群权限和模型授权。** 使用者需要在模型所属集群拥有推理权限，并在该模型上拥有直接或用户组授权。部署所有权不会授予推理访问权限。
- **模型名称是集群范围的。** 不同集群可以存在相同的公开名称。使用 `clusterName` 选择正确的网关。
- **模型需要至少一个活动、在线且权重为正的提供方。** 已停用的模型、离线的提供方和零权重提供方不会收到流量。
- **发布需要同一集群中的就绪部署。** 公开名称重复会返回 `409`；请将该部署添加为成员，或选择其他名称。
- **只有空模型可以删除。** 只要还关联任何提供方（包括离线或零权重提供方），就会返回 `409 model_group_conflict`。
- **已保存状态可能在路由失败后仍保留。** 返回 `502` 且带有 `model_publication_apply_failed` 或 `model_traffic_apply_failed` 时，表示更改已保存但路由未应用；修复原因后重试 **Reconcile**。`model_removal_failed` 会保留记录，以便重试移除。
- **常见状态码。** 模型 token 缺失、过期或已吊销时返回 `401 token_invalid`；缺少权限或集群范围不足返回 `403`；资源不存在返回 `404`；冲突返回 `409`；输入无效返回 `422`。
- **分页限制。** 用量记录接受最大为 `500` 的 `limit`；时间序列接受 `1` 到 `365` 的 `days`。
- **缓存 token 计数取决于引擎。** 用量账本支持缓存输入 token 和缓存写入 token，但某些引擎只报告输入和输出 token，因此这些字段可能为 `0`。
