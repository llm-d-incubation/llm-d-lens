title: 欢迎页
description: 发起 Lens Assistant 对话、查看当前集群问题并打开常用运维操作。
---

欢迎页是运维人员的落地页。它直接展示 Lens Assistant 输入框、当前集群问题和一组快捷操作，不再显示欢迎语。
它不再重复展示集群容量、模型服务列表、部署历史或 Token 使用量；这些内容仍由各自页面负责。

## 谁可以看到欢迎页

管理员、维护者以及拥有 `cluster:cluster:read` 的自定义角色会看到侧边栏第一项“欢迎”。
仅面向模型消费者的角色保留原有落地页。页面中的问题和操作始终按当前账号可访问的集群和权限过滤。
如果当前账号没有可访问集群且拥有创建集群权限，欢迎页会提示打开创建集群向导。

## 工作区布局

侧边栏与顶栏无缝衔接，不保留外侧空隙。各页面的标题和简短说明显示在顶栏左侧。
**Create**、**Refresh**、筛选器和返回按钮等页面操作仍位于顶栏下方的内容区，
左右留白保持均衡。内容滚动时，全局顶栏始终可见，并固定显示 **Documentation**、
**Join Slack**、**Star on GitHub** 和主题切换按钮。内容区上方不再重复显示页面标题。
小屏幕上，入口以带有可访问名称的图标按钮显示。
使用右上角的太阳或月亮按钮切换主题；滚动条（包括 Model Services 画布）跟随所选主题。
侧边栏展开/收起按钮和账号菜单仍位于侧边栏。展开时，**Account** 位于底部左侧，
**Lens Assistant** 以紧凑图标显示在右侧。悬停 Account 可查看用户名；悬停或用键盘聚焦助手图标可查看入口名称，
选中 Lens Assistant 时图标按钮显示蓝色背景。
收起时，两个图标上下排列，Account 在前。
即使正在查看其他管理分组的页面，也可以展开或收起 Administration 下的分组；进入管理页面时会展开其所属分组。

点击右侧抽屉外的遮罩可关闭抽屉；表单正在提交或明确要求在面板内操作时除外。

Benchmark 详情将任务信息、运行状态和分区标签合并在同一背景内，以分割线区分。
Observability 同样将服务控件和 Namespace/GUIs 行合并显示。
**Platform → Model Usage** 将 **Time range**、**Group by**、**User**、**Model**、
**Cluster** 和 **Clear filters** 放在同一行；空间不足时控件会自动换行。

页面操作统一使用紧凑按钮和仅图标的刷新按钮：

| 页面 | 控件位置 |
| --- | --- |
| Deployments | Create 和刷新位于 Deployments 列表标题右侧 |
| Evaluation | Evaluation evidence、New Task 和刷新位于搜索筛选行上方，筛选行不再额外加外框；点击状态卡片可筛选 |
| Trace Replayer | Matching Tasks、后方小字匹配数量、New Task 和唯一的刷新按钮位于无额外外框的搜索筛选行上方 |
| Storage | New storage volume 和刷新位于 Storage volumes 右侧，下方为统一的筛选器和列表/详情区域 |
| Model cache | Download model 和刷新位于 Cached models 右侧；分页摘要和控件保留在面板底部，位于可滚动的模型列表下方 |
| Clusters | Target cluster 和导航位于 Clusters 列表上方；状态和编辑保留在列表中，通过集群选择旁的帮助图标查看描述 |
| Observability | 桌面端将服务标签、上下文、目标集群和刷新合并为一行 |

小屏幕上控件会换行，避免被截断。

Model cache 的 **Showing 1–1 of 1 cached models** 表示当前页显示的条目范围和筛选后的总数。
桌面端列表占满面板剩余高度，模型卡片滚动时底部分页栏仍然可见。
同步与返回操作保留在统计卡片旁。

Storage 使用统一面板，以分隔线区分存储卷列表和详情，不再使用独立侧栏。
**Storage volumes** 旁的按钮可以收起或展开列表；收起时详情占满面板宽度，当前选择和筛选条件保持不变。
只有超过一页时才显示分页控件。Clusters 中的 **Target cluster** 使用弱化标签，
作为下方选择框的说明。

Evaluation Tasks 卡片内还显示 **multi-configuration comparisons**：
即一次比较两个或更多配置的已记录评估任务数。零表示没有此类任务，并非错误；
此计数覆盖全部已记录任务，不随列表筛选变化。

**My services** 的 Gateway connections 外层面板保持全宽，内部连接卡片较窄。
**Users** 和 **Roles** 的搜索与筛选直接放在主面板中，不再额外嵌套带边框的工具栏。

点击全局顶栏的 **Documentation** 在新标签页中打开 Lens 文档。

## 使用 Lens Assistant

欢迎页使用紧凑的集群状态卡片，方便同时查看问题和助手。助手的 **Message** 输入框
带有清晰边框，并可垂直调整大小。

1. 在 **Ask Lens Assistant** 下的 **Message** 输入框中输入消息。
2. 在输入框左下角选择 AI provider。
3. 点击 **Send**，或按 `Enter`；使用 `Shift+Enter` 换行。

点击发送后会打开 Lens Assistant，自动选择你选择的 provider，并在 provider 就绪后
自动提交消息。工具调用仍遵循 Assistant 原有的确认规则。消息只通过浏览器临时
session storage 传递，不会写入 URL。

下拉框只列出 Lens Assistant 可使用的 provider。没有可用 provider 时，发送按钮会禁用，
输入框内会提供 **External providers** 链接。如果当前角色不能添加 provider，请联系管理员。
如果 provider 列表加载失败，请重试，不要直接认为没有 provider。

如果当前角色不能使用 Lens Assistant，页面会显示权限提示，而不是不可用的输入框；
问题列表和有权限的快捷操作仍然可用。

## 查看集群问题

**Needs attention** 显示当前集群范围内的异常：

- 没有任何可访问集群、集群没有 model-cache 存储卷，或记录的 HF_TOKEN Secret 已不存在。缺少存储卷的问题会链接到 **New storage volume**，并自动选好集群和 **Model cache** 用途。
- 某个 model-cache 存储卷中没有任何模型，或集群的 model-cache 存储卷中没有任何可用模型。
- 组件或节点未就绪。核心监控正常但缺少 Grafana dashboard 时以 info 级别提示。
- 模型服务没有可用的服务路径，或 Gateway/IPP 不可用。
- 后端部署持续出现服务压力或错误率升高。
- 最近的部署失败，或已就绪但未发布为模型服务的部署。
- 存储创建失败，或模型缓存下载/同步失败。
- 活跃用户既没有直接角色、所在组也没有角色，或组没有任何角色绑定（info 级别）。用户相关问题会显示用户名，并链接到该用户的角色编辑位置。
- 没有兼容的 External AI provider（info 级别）。

每条问题包含严重程度、资源标识、证据、首次发现时间和诊断链接，例如
标有 **To check**、**To fix** 或 **To resolve** 的按钮。遥测不足时会显示未知或过期，
不会当成健康状态。

使用区块标题旁的严重程度和集群选择器缩小范围。**View all issues** 打开完整的可筛选问题页面，并带上相同筛选条件。
Lens 每 60 秒在后台检查当前问题并保存最新快照；页面每 15 秒读取该快照，静默刷新期间保留已有内容。
切换页面不会重复触发检查。结果还会再次按你的集群访问范围和权限过滤。

## 快捷操作

右侧栏显示当前角色可以执行的操作：

| 操作 | 打开内容 |
| --- | --- |
| Token usage analytics | 使用报告，查看已记录的 Token 消耗。 |
| Add a model deployment | 模型市场，准备部署模型。 |
| Publish a model service | 模型服务页面，并请求打开添加表单。 |
| Launch benchmark | 评测页面，并打开新建任务向导。 |
| Replay traces | 仿真页面，并打开新建任务表单。 |
| Manage storages | 存储页面，查看或创建集群存储卷。 |
| Cache a new model | 模型缓存页面，并请求打开下载表单。 |
| Create a new cluster | 集群页面，并请求打开创建向导。 |

快捷操作只负责跳转。表单、校验、确认和写操作仍在目标页面执行，并继续受权限控制。
没有权限的操作不会显示。

## 空状态与部分状态

| 页面显示 | 含义 |
| --- | --- |
| All systems operational | 所有受监控集群的健康检查和遥测数据均正常，无需执行操作。 |
| Cluster access needed | 当前账号没有可访问的集群，请联系管理员分配集群范围角色。 |
| Some checks unavailable | 部分遥测或 Kubernetes 数据源没有返回结果。 |
| No compatible provider | 请到 External providers 添加兼容的 OpenAI 类型 provider。 |
| Assistant not available | 当前角色缺少 `playground:chat:use` 权限。 |
