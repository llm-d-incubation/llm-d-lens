下载模型前，先在 **Storage（存储）**中创建存储卷。
管理已下载的模型请使用**模型缓存**页面。

## 创建一个存储卷

1. 打开**存储**，点击**新建存储卷**。
2. 在**新建存储卷**中，选择目标**集群**。
3. 按下表选择**类型**并填写对应的连接信息。
4. 要存放下载的模型，将 **Purpose（用途）**设为 **Model cache（模型缓存）**，类型选择 **hostPath** 或 **NFS**。
5. 填写**名称（可选）**和**容量**。名称只需在所选集群内唯一，因此每个集群都可以有自己的 `a100-model-cache`；在同一集群内重复使用某个名称会被拒绝，且不区分大小写。留空则由 Lens 自动生成名称。
6. 如有需要，开启或关闭**挂载时只读**。
7. 点击**创建存储卷**，在列表中确认新卷已出现。

| 类型 | 适用场景 | 需要填写 |
| --- | --- | --- |
| **hostPath** | 使用集群节点上的目录 | **Host path（主机路径）** |
| **NFS** | 使用共享网络目录 | **Server（服务器）**、**Export path（导出路径）** |
| **Dynamic PVC** | 由 Kubernetes StorageClass 分配存储，不用于模型缓存下载 | **StorageClass**、**Namespace（命名空间）**、**Access mode（访问模式）** |

模型缓存卷必须可写；选择此用途会关闭**挂载时只读**。

## 筛选存储卷列表并查看实时状态

1. 打开**存储**。
2. 使用**所有集群**、**按名称搜索**、**所有类型**和**所有用途**
   来缩小列表范围。
3. 查看摘要卡片：**总数**、**就绪**、**等待中**、**需关注**和**失败**。
4. 在列表中点击一个存储卷。
5. 在**状态**中，查看**ID**、**类型**、**集群**、**容量**和**位置**。
6. 查看**Persistent Volume Claim** 和 **Persistent Volume** 面板，
   了解实时的 Kubernetes 资源状态。

## 确认 hostPath 存储卷的节点变更

1. 选择显示橙色漂移警告的存储卷。
2. 阅读**状态**中的警告信息。
3. 在确认节点变更无误后，点击**确认**来清除该警告。

## 删除一个存储卷

被一个或多个部署引用的存储卷会显示**使用中**徽标，并且其删除
控件会被禁用；请先从这些部署中释放它。

1. 在存储卷列表中，点击标题为**删除存储卷**的删除控件。
2. 在**删除存储卷**中，查看关于 Kubernetes PVC 和 PV 对象的警告。
3. 如果该存储卷包含模型缓存条目，点击**继续**。
4. 在后续的**删除存储卷**步骤中，如果想保留 NFS 或 hostPath 上的
   文件，选择**保留模型文件**；如果想让 Lens 先删除这些文件，
   选择**删除模型文件**。
5. 如果该存储卷没有模型缓存条目，直接点击**删除存储卷**。

## 模型缓存

当你需要管理已下载的模型权重本身时，使用
[模型缓存](/user-guide/model-cache)。该页面涵盖缓存条目和下载日志，
而**存储**管理的是底层可复用的存储卷。

## 权限

存储操作和 Lens 的其他部分一样按集群划分范围：维护者只能管理
自己被绑定的集群上的存储卷，而管理员可以管理所有集群上的存储卷。
