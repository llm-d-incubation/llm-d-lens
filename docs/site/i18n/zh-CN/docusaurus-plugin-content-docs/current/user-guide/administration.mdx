在管理页面为用户分配权限、管理账户并查看操作记录。
看不到页面或按钮时，请使用有权执行该操作的账户登录。

登录后，Lens 自动打开侧边栏中位置最高且当前权限允许访问的页面，
同样适用于多个角色的合并权限和自定义角色。默认页由侧边栏顺序决定，不按角色名称固定指定。
没有任何可访问页面时，会显示无权限提示。已登录会话刷新时保留有效页面 URL 及其过滤条件；
重新登录则进入默认页。

## 创建用户

1. 打开**用户**页面。
2. 点击**新增用户**。
3. 在**新增用户**抽屉中，填写**用户名**、**显示名称**、**邮箱**、**密码**和**确认密码**。
4. 可选：在**角色**中预先选择一个或多个角色。
5. 如果你分配了角色并希望限定集群范围，请将**范围**从**所有集群（全局）**改为**指定集群**，然后选择**集群**。
6. 点击**新增用户**。

## 为用户分配或移除角色

1. 打开**用户**页面。
2. 在该用户所在行，点击标题为**角色**的操作。
3. 在**角色**抽屉中，选择一个**角色**。
4. 将**范围**设置为**所有集群（全局）**或**指定集群**。
5. 如果你选择了**指定集群**，请选择一个**集群**。
6. 点击**新增角色**。
7. 要稍后移除某个绑定，点击该条目旁的**移除角色**。

## 重置用户密码

1. 打开**用户**页面。
2. 在该用户所在行，点击标题为**重置密码**的操作。
3. 在**重置密码**对话框中，输入**新密码**和**确认新密码**，两次输入必须一致。
4. 点击**重置密码**。

## 创建组并管理成员

1. 打开**组**页面。
2. 点击**新增组**。
3. 在**新增组**抽屉中，填写**名称**和**描述**。
4. 可选：分配初始**角色**，如有需要可将**范围**切换为**指定集群**并选择**集群**。
5. 点击**新增组**。
6. 回到**组**表格，点击你要更新的组旁边的**成员**。
7. 在**组成员**中，使用**搜索成员…**查找用户，通过复选框选择用户，或使用**全选**和**清除**。
8. 点击**保存成员**。

## 创建或编辑角色

1. 打开**角色**页面。
2. 要创建角色，点击**新增角色**。要修改现有的自定义角色，点击标注为**编辑**后跟该角色名称的操作。
3. 在**新增角色**中，如果你是在创建新角色，请输入**名称**和**描述**。
4. 在权限列表中，勾选你希望该角色授予的权限复选框。
5. 新建角色时点击**新增角色**，编辑现有角色时点击**保存权限**。

## 配置身份提供方

1. 打开**身份提供方**页面。
2. 点击**新增提供方**。
3. 在**新增身份提供方**中，按需填写**名称**、**服务器 URL**、**用户基础 DN**、**组基础 DN**（可选）、**用户过滤器**、**用户名属性**、**显示名称属性**、**邮箱属性**、**绑定 DN** 和**绑定密码**。
4. 打开或关闭**已启用**。
5. 可选：勾选**默认提供方**。
6. 点击**新增提供方**。
7. 要稍后验证连通性，点击该提供方行中的**测试**。
8. 要修改现有条目，点击标注为**编辑**后跟该提供方名称的操作，更新相应字段，然后点击**保存更改**。

## 导入目录用户和组

先配置身份提供方并测试连接，再导入目录中的用户和组。

1. 在提供方上设置**组基础 DN**（例如 `ou=groups,dc=example,dc=org`）。
2. 在**身份提供方**页面，点击该提供方行中的**同步**，导入该基础 DN 下的所有组及其成员。
3. 登录操作同样会导入用户及其所属组，因此目录用户在首次登录后会出现在**用户**页面中。
4. 打开**用户**或**组**页面分配角色。目录组的成员关系请在目录服务中修改，不能在 Lens 中修改。
5. 在 **Model services** 中打开模型的 **Manage access** 抽屉，向导入的用户或组授予推理权限。授权对象还必须在该模型所属集群拥有推理权限；不再支持部署分享。

**删除身份提供方会同时删除它导入的账户和组，以及相应的角色分配和共享记录。**
删除前先确认受影响的用户。

## 管理主密钥

主密钥用于保护保存的提供方凭据，例如 LDAP 绑定密码。

1. 打开**主密钥**页面。
2. 查看**来源**、**密钥指纹**、**密钥长度**、**已加密的提供方密钥数**和**保留的旧密钥数**。
3. 点击 **Rotate key（轮换密钥）**。新密钥留空可自动生成，也可填写至少 16 个字符，再点击 **Rotate key** 确认。
4. 轮换后测试已配置的身份提供方；确认不再需要之前，保留旧密钥。
5. 需要删除旧密钥时，点击 **Clear previous keys（清除旧密钥）**并确认。

当 `LENS_SECRET_KEY` 是通过环境变量提供的，该页面为只读状态：请更新该变量并重启 Lens 以完成轮换。

## 撤销活跃会话

1. 打开**活跃会话**页面。
2. 查看**你的会话**表格的列：**用户**、**IP**、**来源**、**创建时间**、**最后活跃时间**和**过期时间**。
3. 在你想结束的会话所在行，点击**撤销会话**。
4. 等待确认横幅**会话已撤销**出现。

## 筛选审计日志

1. 打开**审计日志**页面。
2. 使用**所有事件**来缩小**事件筛选**范围。
3. 使用**所有结果**和**所有操作**来缩小结果和操作范围。
4. 使用**所有来源**区分浏览器、API、助手、后台和系统事件。
5. 在**按用户筛选…**中，选择一个用户名。
6. 可选：使用**开始时间**和**结束时间**设置**开始**和**结束**。
7. 点击**清除筛选**以重置当前的筛选条件。
8. 使用**每页行数**和分页器在**事件**表格中翻页。每行显示事件、操作、用户、来源、结果和目标。
