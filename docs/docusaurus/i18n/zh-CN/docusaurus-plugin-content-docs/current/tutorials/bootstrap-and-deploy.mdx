这份演练将带你从零开始，一路走到一个正在运行的推理部署。

## 1. 注册或引导集群

打开[集群](/user-guide/clusters)，然后选择以下其中一种方式：

- **注册已有集群**：提供其 kubeconfig，或者
- **引导一个新集群**：使用引导式的"创建集群"向导（关于该向导自动
  完成了哪些步骤，参见[集群](/user-guide/clusters)）。

## 2. 选择模型

打开[模型市场](/user-guide/model-market)，浏览目录，并打开某个
模型的详情视图，确认其参数规模和许可证是否适合你的集群资源。

## 3. 部署它

从模型详情视图中使用**一键部署**，它会带着预先填好的模型信息
跳转到[部署](/user-guide/deployments)。然后你可以：

- 手动选择集群和资源形态，或者
- 描述目标工作负载，让智能体规划为你提出方案
  （参见[架构概览](/architecture)）。

审阅并批准该方案。

## 4. 观察它启动

在部署页面上，从滑出面板跟踪状态、查看 Pod、流式查看日志，
直到部署报告就绪为止。

## 接下来

- [评估](/tutorials/evaluate-a-deployment)它，以衡量真实的延迟和吞吐量。
- [将它发布为模型服务](/tutorials/publish-a-model-service)，
  这样客户端就可以通过一个稳定的、兼容 OpenAI 的端点调用它。
