## 后端 API

模型市场**没有**专门的后端模块。它的目录是 `src/data/modelCatalog.js` 中的静态前端数据，因此没有需要文档化的后端目录 API。该页面只调用共享的集群和部署 API。

### 列出 Lens 管理的集群

列出 Lens 管理的集群，可选择包含尚未完成的草稿记录。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/cluster/clusters`**

请求：

- 查询参数：
  - `includeDrafts`（`boolean`，可选）：是否包含尚未完成的草稿集群记录。

该端点没有请求体。

响应：

返回一个 `ClustersResponse` 对象，其中包含一个 `ClusterRecord` 对象数组 `items`。

```json
{
  "items": [
    {
      "id": "cluster-123",
      "name": "lab-cluster",
      "description": "Shared Intel GPU cluster",
      "createdAt": "2026-09-20T10:15:00+00:00",
      "ready": true,
      "proxy": {
        "mode": "auto",
        "httpProxy": null,
        "httpsProxy": null,
        "noProxy": null
      },
      "llmDRef": "v0.9.0",
      "llmDBenchmarkRef": "main",
      "llmDRepoPath": "/opt/prism/checkouts/llm-d",
      "llmDBenchmarkRepoPath": "/opt/prism/checkouts/llm-d-benchmark",
      "deploymentSource": {
        "resolved_from": "cluster-registry",
        "ref": "v0.9.0"
      },
      "benchmarkSource": {
        "resolved_from": "cluster-registry",
        "ref": "main"
      },
      "draft": false
    }
  ]
}
```

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
import asyncio

from llm_d_bench.cluster import service


async def main() -> None:
    clusters = service.list_clusters(include_drafts=True)
    readiness = await asyncio.gather(*(service.cluster_is_ready(cluster) for cluster in clusters))

    for cluster, is_ready in zip(clusters, readiness):
        print(cluster.id, cluster.name, is_ready)


asyncio.run(main())
```

请求：

- 查询参数：

该端点没有请求体。

### 启动一次 Standard Kubernetes Service 部署运行

使用 Lens 的白名单 vLLM 契约启动一次 Standard Kubernetes Service 部署运行。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/deployments/standard-vllm-runs`**

请求：

- JSON 请求体字段：
  - `model`（`string`，必需）
  - `deployment_name`（`string`，必需）
  - `description`（`string`，可选）
  - `cluster_session_id`（`string`，必需，36 个字符）
  - `replicas`（`integer`，必需）
  - `tensor_parallel_size`（`integer`，必需）
  - `storage_type`（`"local-cache" | "pvc" | "model-cache"`，可选）
  - `storage_volume_id`（`string`，可选）
  - `model_cache_path`（`string`，可选）
  - `pvc_name`（`string`，可选）
  - `max_model_len`（`integer`，可选）
  - `gpu_memory_utilization`（`number`，可选）
  - `max_num_seqs`（`integer`，可选）
  - `max_num_batched_tokens`（`integer`，可选）
  - `enable_prefix_caching`（`boolean`，可选）
  - `enforce_eager`（`boolean`，可选）
  - `vllm_arguments`（`array<object>`，可选；每项使用 `name` 和 `value` 两个字符串键）
  - `use_cluster_proxy`（`boolean`，可选）
  - `http_proxy`（`string`，可选）
  - `https_proxy`（`string`，可选）
  - `no_proxy`（`string`，可选）

```python
import asyncio

from llm_d_bench.deploy.application import deployment_run_manager
from llm_d_bench.deploy.contracts import DeploymentRunCreateRequest
from llm_d_bench.deploy.standard_kubernetes_service import (
    StandardKubernetesServiceRequest,
    build_standard_kubernetes_service_configuration,
)


async def main() -> None:
    request = StandardKubernetesServiceRequest(
        model="Qwen/Qwen3-8B",
        deployment_name="qwen3-8b-standard",
        description="Model Market launch",
        cluster_session_id="123e4567-e89b-12d3-a456-426614174000",
        replicas=2,
        tensor_parallel_size=2,
        storage_type="local-cache",
        model_cache_path="/home/prism/.cache",
        max_model_len=8192,
        gpu_memory_utilization=0.85,
        max_num_seqs=128,
        max_num_batched_tokens=4096,
        enable_prefix_caching=True,
        vllm_arguments=[{"name": "enable-auto-tool-choice", "value": "true"}],
        use_cluster_proxy=True,
        http_proxy="http://proxy.example:911",
        https_proxy="http://proxy.example:911",
        no_proxy="localhost,.svc",
    )
    configuration = build_standard_kubernetes_service_configuration(request)
    run = await deployment_run_manager.start_run(
        DeploymentRunCreateRequest(
            configurations=[configuration],
            provenance={
                "deployment_source": {"kind": "standard-kubernetes-service"},
                "cluster_session_id": request.cluster_session_id,
                "deployment_name": request.deployment_name,
                "description": request.description.strip(),
                "model_market": {
                    "deployment_name": request.deployment_name,
                    "description": request.description.strip(),
                },
            },
        )
    )
    print(run.id, run.status)


asyncio.run(main())
```
