## 后端 API

模型服务路由分布在 `llm_d_bench/model_service/router.py` 的用户、管理员、公共和内部路由器中。

### 列出模型访问令牌

列出调用方当前有效的模型访问令牌。响应永远不包含明文令牌值，只包含用于识别和日后吊销所需的元数据。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/tokens`**

    请求：无请求体。调用方必须已通过 Lens 用户会话进行身份验证。

    响应：返回一个 `items` 数组，其中每个元素都是经过 `ModelAccessToken.api_payload()` 投影后的 `ModelAccessToken` 记录，因此 `tokenHash` 字段被省略。

    ```json
    {
      "items": [
        {
          "id": "mat-7f2c4a19b6d1",
          "userId": "user-123",
          "name": "laptop",
          "tokenHint": "9mQx",
          "status": "active",
          "lastUsedAt": "2026-09-23T08:15:00Z",
          "lastUsedIp": "10.0.0.25",
          "createdAt": "2026-09-21T12:00:00Z"
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    tokens = service.tokens.list_for_user("user-123", include_revoked=False)
    for token in tokens:
        print(token.api_payload())
    ```
  </TabItem>
</Tabs>

### 创建模型访问令牌

为调用方创建一个新的模型访问令牌。明文令牌仅返回一次，与持久化保存的令牌元数据一起返回。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/tokens`**

    请求体（`TokenCreateRequest`）：

    - `name`（`string`）：令牌的显示名称。

    ```json
    {
      "name": "automation"
    }
    ```

    响应：一个 `ModelAccessToken` 载荷，外加一次性的 `token` 字符串。

    ```json
    {
      "id": "mat-2c47de48a35b",
      "userId": "user-123",
      "name": "automation",
      "tokenHint": "K8xP",
      "status": "active",
      "createdAt": "2026-09-23T09:00:00Z",
      "token": "lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.create("user-123", name="automation")

    print(token.api_payload())
    print(raw_token)
    ```
  </TabItem>
</Tabs>

### 重新生成模型访问令牌

吊销调用方当前有效的一个或多个令牌，然后签发一个新令牌。你可以选择性地为替换后的新令牌指定一个名称。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/tokens/regenerate`**

    请求体：可选的 `TokenCreateRequest`。若省略，该路由使用 `"default"`。

    ```json
    {
      "name": "default"
    }
    ```

    响应：新签发的令牌元数据，外加新的明文令牌。

    ```json
    {
      "id": "mat-54b2a51d9d93",
      "userId": "user-123",
      "name": "default",
      "tokenHint": "F6rN",
      "status": "active",
      "createdAt": "2026-09-23T09:05:00Z",
      "token": "lens-mk-Gq4nP1sT8uV2xY5zA7bC9dE3fH6jK8mN0pR"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.regenerate("user-123", name="default")

    print(token.id, raw_token)
    ```
  </TabItem>
</Tabs>

### 吊销模型访问令牌

吊销调用方此前签发的一个模型访问令牌。吊销后，该令牌将无法再用于网关访问。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`DELETE /api/v1/model-service/tokens/{token_id}`**

    请求：无请求体。

    - `token_id`（`string`，路径参数）：令牌 ID，例如 `mat-7f2c4a19b6d1`。

    响应：`204 No Content`。该端点不返回 JSON 响应体。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    revoked = service.tokens.revoke("user-123", "mat-7f2c4a19b6d1")
    print(revoked)
    ```
  </TabItem>
</Tabs>

### 获取网关连接信息

返回客户端用于配置其 OpenAI 客户端的 Gateway 连接信息。每个集群都运行自己的 Gateway，因此响应会为调用方可访问的每个集群分别列出一条连接；当设置了 `LENS_MODEL_GATEWAY_PUBLIC_URL` 时，它会作为单一覆盖值应用到每个集群。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/connection`**

    请求：无请求体。

    响应：全局覆盖值（未设置时为空字符串），外加一个按集群分组的列表。

    ```json
    {
      "baseUrl": "",
      "clusters": [
        {
          "clusterId": "cluster-a",
          "clusterName": "Cluster A",
          "provider": "istio",
          "gatewayName": "lens-inference-gateway",
          "address": "10.0.0.10",
          "publicUrl": null,
          "port": null,
          "baseUrl": "http://10.0.0.10/v1",
          "ready": true
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import os

    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService, gateway_base_url

    global_url = os.environ.get("LENS_MODEL_GATEWAY_PUBLIC_URL", "").strip()
    public_host = os.environ.get("LENS_PUBLIC_HOST", "").strip()
    status = asyncio.run(GatewayOpsService().status())
    clusters = [
        {
            "clusterId": cluster.cluster_id,
            "clusterName": cluster.cluster_name,
            "provider": cluster.gateway_provider,
            "gatewayName": cluster.gateway_name,
            "address": cluster.gateway_address,
            "publicUrl": cluster.gateway_public_url,
            "port": cluster.gateway_port,
            "baseUrl": gateway_base_url(cluster, public_host, global_url),
            "ready": bool(cluster.gateway_ready),
        }
        for cluster in status.clusters
    ]

    print({"baseUrl": global_url, "clusters": clusters})
    ```
  </TabItem>
</Tabs>

### 列出兼容 OpenAI 的模型

针对一个有效的模型令牌返回 OpenAI 风格的 `GET /v1/models` 响应。模型列表会被过滤为该令牌所属用户可见的那些组。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /v1/models`**

    请求：无请求体。使用 `Authorization: ******` 或 `x-api-key: <token>` 传递模型令牌。

    响应：标准的兼容 OpenAI 的模型列表载荷。

    ```json
    {
      "object": "list",
      "data": [
        {
          "id": "qwen3-8b",
          "object": "model",
          "created": 1727107200,
          "owned_by": "lens"
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    record = service.tokens.validate("lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ", ip="10.0.0.25")
    if record is None:
        raise RuntimeError("token is missing, expired, or revoked")

    payload = {
        "object": "list",
        "data": [
            {
                "id": group.name,
                "object": "model",
                "created": int(group.created_at.timestamp()),
                "owned_by": "lens",

            for group in service.list_models_for_user(record.user_id)

    }

    ```

### 列出使用记录

列出调用方最近的使用记录，通过 `limit` 和 `offset` 进行简单的分页。每个条目都是存储的 `UsageRecord`，并经过驼峰命名的 API 别名投影。llm-d EPP 仅上报输入/输出 token，因此 `cachedInputTokens` 目前始终为 `0`（保留该字段是为了兼容会暴露该数据的引擎）。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/usage/records`**

    请求：无请求体。

    - `limit`（`integer`，查询参数，默认值 `100`，最大值 `500`）：要返回的记录数量。
    - `offset`（`integer`，查询参数，默认值 `0`）：调用方流水账中从 0 开始计数的偏移量。

    响应：一个 `items` 数组，包含若干条使用记录。

    ```json
    {
      "items": [
        {
          "id": "usg-8c2d9e1fa410",
          "requestId": "req-20260923-0001",
          "userId": "user-123",
          "tokenId": "mat-2c47de48a35b",
          "groupId": "msg-4a8b41f3dd6c",
          "groupName": "qwen3-8b",
          "clusterId": "cluster-a",
          "executionId": "exec-qwen3-8b",
          "modelRef": "Qwen/Qwen3-8B",
          "provider": "vllm",
          "inputTokens": 512,
          "cachedInputTokens": 128,
          "cacheWriteTokens": 0,
          "outputTokens": 196,
          "usageSource": "engine",
          "status": "success",
          "streaming": false,
          "ttftMs": 240,
          "durationMs": 1310,
          "createdAt": "2026-09-23T08:40:00Z"
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    records = service.usage.list_for_user("user-123", limit=100, offset=0)
    for record in records:
        print(record.api_payload())
    ```
  </TabItem>
</Tabs>

### 获取每日使用总量

将调用方最近的使用记录按天聚合为 token 总量。该处理函数复用同一份使用流水账，并通过 `_daily_totals` 对其进行分桶统计。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/model-service/usage/timeseries`**

    请求：无请求体。

    - `days`（`integer`，查询参数，默认值 `30`，取值范围 `1..365`）：要包含的最近天数。

    响应：每日使用量分桶，其中包含每个 token 类别的总量。

    ```json
    {
      "items": [
        {
          "date": "2026-09-22",
          "requests": 4,
          "inputTokens": 1200,
          "cachedInputTokens": 300,
          "cacheWriteTokens": 0,
          "outputTokens": 640
        },
        {
          "date": "2026-09-23",
          "requests": 2,
          "inputTokens": 530,
          "cachedInputTokens": 64,
          "cacheWriteTokens": 0,
          "outputTokens": 211
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from datetime import datetime, timedelta

    from llm_d_bench.model_service.router import _daily_totals
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    since = datetime.now() - timedelta(days=30)
    records = service.usage.list_for_user("user-123", since=since, limit=10000)
    print(_daily_totals(records))
    ```
  </TabItem>
</Tabs>

### 创建模型路由组

创建一个在单个集群内公开一个面向用户模型名称的路由组。`name` 和 `clusterId` 为必填项；公开名称在每个集群（`clusterId`）内唯一，并且每个提供方都必须是同一集群内的某个部署。Lens 会根据 `name` 推导出 `modelRef`/`baseModel`，`displayName` 默认为 `name`。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/admin/groups`**

    请求体（`GroupCreateRequest`）：

    - `name`（`string`）：客户端使用的模型名称（同时也是路由/模型引用）。
    - `clusterId`（`string`）：该服务所属的集群（必填）；其提供方必须都位于该集群内，且名称在该集群内唯一。
    - `displayName`（`string`，可选）：便于在 UI 中展示的标签；默认为 `name`。
    - `description`（`string`，可选）：自由格式的描述。
    - `modelRef` / `servedName` / `baseModel`（`string`，可选，高级选项）：省略时根据 `name` 推导得出。
    - `selectionPolicy`（`string`，遗留字段）：为兼容性而接受此参数；llm-d 数据面会忽略它。

    ```json
    {
      "name": "qwen3-8b",
      "modelRef": "Qwen/Qwen3-8B",
      "clusterId": "cluster-a",
      "servedName": "Qwen/Qwen3-8B",
      "baseModel": "Qwen/Qwen3-8B",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service"
    }
    ```

    响应：创建成功后的 `ModelServiceGroup`。

    ```json
    {
      "id": "msg-4a8b41f3dd6c",
      "name": "qwen3-8b",
      "modelRef": "Qwen/Qwen3-8B",
      "clusterId": "cluster-a",
      "servedName": "Qwen/Qwen3-8B",
      "baseModel": "Qwen/Qwen3-8B",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service",
      "selectionPolicy": "random",
      "status": "active",
      "createdByUserId": "user-123",
      "createdAt": "2026-09-23T09:10:00Z",
      "updatedAt": "2026-09-23T09:10:00Z"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.contracts import GroupCreateRequest
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    group = service.create_group(
        GroupCreateRequest(
            name="qwen3-8b",
            modelRef="Qwen/Qwen3-8B",
            clusterId="cluster-a",
            servedName="Qwen/Qwen3-8B",
            baseModel="Qwen/Qwen3-8B",
            displayName="Qwen3 8B",
            description="Shared Qwen 3 8B service",
        ),
        created_by="user-123",
    )
    print(group.api_payload())
    ```
  </TabItem>
</Tabs>

### 将一个部署发布为成员

将一个就绪的部署执行发布到某个路由组中。该路由会根据执行 ID 推导出实际的命名空间、服务、端口和端点类型。该执行所在的集群必须与该组所在的集群一致，否则调用会被以 `409`（`model_member_conflict`）拒绝。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/admin/members`**

    请求体（`MemberCreateRequest`）：

    - `groupId`（`string`）：目标路由组 ID。
    - `executionId`（`string`）：就绪的部署执行 ID。
    - `poolName`（`string`，可选，高级选项）：由部署所拥有的 InferencePool 名称；默认为部署保存的池名称，形式为 `namespace/pool`（跨命名空间唯一）。

    ```json
    {
      "groupId": "msg-4a8b41f3dd6c",
      "executionId": "exec-qwen3-8b",
      "poolName": "ns/qwen"
    }
    ```

    响应：创建成功后的 `ModelServiceMember`。

    ```json
    {
      "id": "msm-32d55cb7f9a1",
      "groupId": "msg-4a8b41f3dd6c",
      "executionId": "exec-qwen3-8b",
      "clusterId": "cluster-a",
      "targetNamespace": "ns",
      "targetService": "qwen-epp",
      "targetPort": 8000,
      "endpointKind": "llm-d-epp",
      "poolName": "qwen",
      "eppRef": "qwen-epp",
      "status": "active",
      "ownerUserId": "user-123",
      "publishedByUserId": "user-123",
      "createdAt": "2026-09-23T09:12:00Z",
      "updatedAt": "2026-09-23T09:12:00Z"
    }
    ```
  </TabItem>

  <TabItem value="python-api" label="Python API">
    该流式接口是一种 HTTP 传输方式；与之等价的 Python 调用会直接运行该操作。

    ```python
    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService

    async def main() -> None:
        ops = GatewayOpsService()
        await ops.reconcile_cluster_gateway("cluster-a")          # op=reconcile
        await ops.install_cluster_gateway("cluster-a")            # op=install-gateway
        await ops.uninstall_inference_gateway("cluster-a")        # op=uninstall-gateway
        await ops.install_ipp("cluster-a")                        # op=install-ipp
        await ops.uninstall_ipp("cluster-a")                      # op=uninstall-ipp

    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### 流式输出某个组件的日志

流式输出（`kubectl logs -f`）某个数据面组件的实时日志。管理员数据面拓扑图使用该端点，以便实时查看 Gateway / IPP / EPP 的输出。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/model-service/admin/gateway/logs`**

    请求体（`ComponentLogsRequest`）：
    - `clusterId`（`string`）：目标集群。
    - `component`（`string`，可选）：`gateway` 或 `ipp` —— 后端会据此解析出命名空间/名称。
    - `namespace` / `name`（`string`，可选）：当未提供 `component` 时，显式指定坐标。
    - `kind`（`string`，默认值 `deployment`）、`container`（`string`，可选）、`tail`（`integer`，默认值 `200`）。

    ```json
    { "clusterId": "cluster-a", "component": "gateway" }
    ```

    响应：`text/event-stream`；每个 `log` 事件携带一行日志，最后是一个作为终态的 `complete`。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService

    async def main() -> None:
        namespace, name = await GatewayOpsService().resolve_log_target(
            "cluster-a", component="gateway", namespace=None, name=None
        )
        async for line in GatewayOpsService().stream_component_logs("cluster-a", namespace, name, tail=50):
            print(line)

    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

## 内部端点（Edge ext_authz）

这些 `/api/v1/internal/model-gateway/*` 路由只会被 Edge Envoy 的 `ext_authz` 过滤器和 llm-d EPP 调用，永远不会被 Lens 客户端直接调用；它们不携带任何 Lens 用户会话。

### 对网关请求进行鉴权

校验调用方的模型令牌，将请求的公开模型名称解析为该令牌可使用的一个活跃路由组，选择一个后端成员，并返回供 Edge Envoy 附加到上游请求的路由请求头。`GET /v1/models`（不带模型）只会做令牌校验；其他所有 HTTP 方法都会被接受，因为 Envoy 会转发客户端原始的请求方法。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/internal/model-gateway/authorize`**（同时支持 `GET`/`PUT`/`PATCH`/`DELETE`，以及用于适配 Envoy 按集群划分路径形式的 `/authorize/{rest:path}`，例如 `.../authorize/cluster/<id>/...`）

    请求：一个 JSON 请求体 `{"token": "...", "model": "..."}`，或者原始的 OpenAI 请求体，外加 `Authorization`/`x-api-key` 以及 `x-lens-model`/`x-gateway-base-model-name` 请求头。

    响应：成功时为 `200`，并附带 `AuthorizeResult` 载荷，以及供 Edge 转发到上游的 `x-lens-*` / `x-ai-eg-model` / `x-llm-d-inference-fairness-id` 路由请求头；失败时为 `401`（`token_invalid`）或 `404`（`model_not_found`）。
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.model_service.contracts import AuthorizeRequest
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    result = service.authorize_request(
        AuthorizeRequest(token="lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ", model="qwen3-8b"),
        cluster_id="cluster-a",
    )
    print(result.model_dump(mode="json", by_alias=True))
    ```
  </TabItem>
</Tabs>
