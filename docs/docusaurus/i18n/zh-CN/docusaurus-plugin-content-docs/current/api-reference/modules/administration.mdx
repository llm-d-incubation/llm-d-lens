## 后端 API

管理模块涵盖 `llm_d_bench/auth/router.py` 中的身份验证路由，以及 `llm_d_bench/db/system_router.py` 中的系统设置路由。

身份验证与管理相关路由位于 `llm_d_bench/auth/router.py` 中的 `/api/v1` 前缀下。

### 列出用户

列出用户，包括直接角色、群组成员关系以及继承的角色。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/users`**

请求：

- 查询参数：
  - `query`（`string`，可选）：按用户名或其他用户搜索文本进行过滤。
  - `status`（`string`，可选）：按用户状态过滤，例如 `active` 或 `disabled`。

该端点没有请求体。

响应：

返回用户记录数组，并附带直接 `roles`（角色）、`groups`（群组）和 `inheritedRoles`（继承角色）信息。

```json
[
  {
    "username": "alice",
    "display_name": "Alice Admin",
    "id": "user-1",
    "email": "alice@example.com",
    "provider_id": null,
    "auth_source": "local",
    "external_id": null,
    "status": "active",
    "failed_login_count": 0,
    "locked_until": null,
    "must_change_password": false,
    "password_changed_at": "2026-09-21T08:00:00+00:00",
    "last_login_at": "2026-09-23T08:45:00+00:00",
    "principal_version": 3,
    "created_at": "2026-09-20T10:00:00+00:00",
    "updated_at": "2026-09-23T08:45:00+00:00",
    "has_password": true,
    "protected": false,
    "roles": [
      {
        "name": "maintainer",
        "scopeType": "cluster",
        "scopeClusterId": "cluster-123"
      }
    ],
    "groups": [
      {
        "id": "group-ops",
        "name": "ops",
        "source": "manual"
      }
    ],
    "inheritedRoles": [
      {
        "name": "end-user",
        "scopeType": "global",
        "scopeClusterId": null,
        "scopeResourceType": null,
        "scopeResourceId": null,
        "groupId": "group-ops",
        "groupName": "ops"
      }
    ]
  }
]
```

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.auth.service import default_service

service = default_service()
role_names = {role.id: role.name for role in service.role_dao.list()}
group_names = {group.id: group.name for group in service.group_dao.list()}
user_bindings = service.user_binding_dao.list_all()
group_bindings = service.group_binding_dao.list_all()
memberships = service.user_group_dao.list_all()
users = service.user_dao.list(query="alice", status="active")

print(len(users), len(user_bindings), len(group_bindings), len(memberships))
print(role_names)
print(group_names)
```

### 创建角色

```json
  "permissions": [
    "cluster:cluster:read",
    "deployment:run:read"
  ]
```

### 列出会话

列出会话；管理员可以包含已吊销的会话，而其他调用者只能看到自己的会话。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/sessions`**

请求：

- 查询参数：
  - `include_revoked`（`boolean`，可选）：管理员可以在结果集中包含已吊销的会话。

响应：

返回会话记录列表。管理员调用者会收到每个会话以及 `username` 字段；非管理员调用者只能收到自己的会话。

```json

  {
    "user_id": "user-1",
    "token_hash": "$argon2id$v=19$m=65536,t=3,p=4$sessionhash",
    "id": "session-1",
    "created_at": "2026-09-23T08:45:00+00:00",
    "expires_at": "2026-09-23T16:45:00+00:00",
    "idle_expires_at": "2026-09-23T10:45:00+00:00",
    "last_seen_at": "2026-09-23T09:15:00+00:00",
    "revoked_at": null,
    "auth_source": "local",
    "ip": "127.0.0.1",
    "user_agent": "Mozilla/5.0",
    "username": "alice"
  }
]
```

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.auth.service import default_service
```

- 路径参数：
  - `cluster_id`（`string`，必填）：要移除其绑定的集群。

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.auth.service import default_service

service = default_service()
for binding in service.user_binding_dao.list_all():
    if binding.id == "binding-user-1":
        service.remove_user_binding(binding.user_id, binding.id)
        break
else:
    for binding in service.group_binding_dao.list_all():
        if binding.id == "binding-group-1":
            service.remove_group_binding(binding.group_id, binding.id)
            break

print("binding revoked")
```

### 配置后端数据库

配置 Lens 自身的数据库连接（外部或内嵌），并创建初始数据表。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/system/database`**

请求：

- JSON 请求体字段：
  - `mode`（`"external" | "embedded"`，必填）
  - `engine`（`"postgresql" | "mysql" | "oracle" | "mssql"`，可选）
  - `databaseUrl`（`string`，`external` 模式下必填）
  - `embeddedPassword`（`string`，可选；仅在 `embedded` 模式下有意义）

外部数据库示例：

```json
{
  "mode": "external",
  "engine": "mysql",
  "databaseUrl": "mysql://prism:secret@db.example.com:3306/prism"
}
```

响应：

连接探测、引擎配置和初始数据表创建成功后，返回最终的 `DatabaseStatus`。

```json
{
  "configured": true,
  "mode": "external",
  "engine": "mysql",
  "displayTarget": "db.example.com:3306/prism"
}
```

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.db.system_router import DatabaseSetupRequest, apply_database_setup

status = apply_database_setup(
    DatabaseSetupRequest(

        engine="mysql",
        databaseUrl="mysql://prism:secret@db.example.com:3306/prism",

print(status.configured, status.mode, status.engine)
```

### 读取存储密钥主密钥状态

读取当前生效的主密钥（`LENS_SECRET_KEY`）来源、不可逆指纹，以及现有的服务提供方密钥数量和旧的备用密钥数量。密钥本身的值永远不会被返回。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`GET /api/v1/system/secret-key`**

请求：

该端点没有请求体。

响应：

```json
{
  "source": "file",
  "envLocked": false,
  "configured": true,
  "fingerprint": "3f9a1c7b52e0d4a6",
  "keyLength": 64,
  "oldKeyCount": 1,
  "path": "/home/user/.local/share/lens/credentials/master_key.json",
  "providerSecretCount": 2
}
```

`source` 的取值为 `environment`、`file` 或 `unconfigured`；当 `LENS_SECRET_KEY` 通过环境变量提供时，`envLocked` 为 `true`（此时存储的密钥会被忽略，并且通过 API 进行密钥轮换的请求会被拒绝）。

  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.auth.master_key import status
from llm_d_bench.auth.settings import get_settings

print(status(get_settings())["source"], status(get_settings())["fingerprint"])
```

  </TabItem>
</Tabs>

### 轮换存储密钥主密钥

生成一个新的主密钥（或使用指定的密钥），用它重新加密每一个已存储的服务提供方密钥，并保留此前的密钥作为解密回退。当 `LENS_SECRET_KEY` 被环境变量锁定时，该操作会被拒绝。

<Tabs>
  <TabItem value="rest-api" label="REST API">

**`POST /api/v1/system/secret-key/rotate`**

请求：

- JSON 请求体字段：
  - `newKey`（`string`，可选；留空则自动生成一个强密钥）

```json
{
  "newKey": "a-manually-chosen-strong-key"
}
```

响应：

返回新的状态，以及 `rotatedSecrets`（已重新加密的服务提供方密钥数量）。

```json
{
  "source": "file",
  "envLocked": false,
  "configured": true,
  "fingerprint": "b71e0c9d3a4f8215",
  "keyLength": 28,
  "oldKeyCount": 1,
  "path": "/home/user/.local/share/lens/credentials/master_key.json",
  "providerSecretCount": 2,
  "rotatedSecrets": 2
}
```
