## 后端 API

评估相关的路由位于 `llm_d_bench/evaluate/router.py` 中，前缀为 `/api/v1/evaluate`。请求模型定义在 `llm_d_bench.evaluate.models` 中；命名的 HTTP 响应模型定义在 `llm_d_bench.evaluate.api_models` 中。

运行、工作流、用例和详情响应会保留额外的已存储字段。记录中不存在的可选字段会保持省略状态；显式存储的 `null` 值会保持为 `null`。列表响应会保留其 `{ "items": [...] }` 信封结构。Python 路由函数返回字典；FastAPI 会在 HTTP 边界处应用对应的命名响应模型。

错误使用应用的 `application/problem+json` 响应格式，包含 `type`、`status`、`title`、`detail`、`code` 以及可选的 `requestId`。`detail` 字段可以包含结构化的校验错误。认证和资源权限仍然适用；声明一个响应模型并不会授予访问权限。

### 获取基准测试默认值

获取 Lens Evaluate 将使用的 llm-d-benchmark 默认仓库和运行时设置。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/evaluate/benchmark-defaults`**

    请求：无请求体。

    响应：HTTP `200`，`BenchmarkDefaultsResponse`。

    ```json
    {
      "mode": "managed-source",
      "repository": "https://github.com/llm-d/llm-d-benchmark.git",
      "revision": "main",
      "localRuntimeConfigured": false
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
import asyncio

from llm_d_bench.evaluate.router import benchmark_defaults


async def main() -> None:
    defaults = await benchmark_defaults()
    print(defaults["mode"], defaults["repository"], defaults["revision"])


asyncio.run(main())
```

### 启动一次基准测试运行

针对一个就绪的部署执行记录，或一个已发布的模型服务，启动一次基准测试运行。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/evaluate/runs`**

    请求体：`EvaluateRunRequest`
    - `deployment_execution_id`（`string`，可选）——直接对某个特定的部署执行记录进行基准测试。
    - `model_service_group_id`（`string`，可选）——改为对一个已发布、持续健康探测的
      模型服务进行基准测试；测试工具会将其解析为该组的活跃成员及已发布名称，并且
      要求提供 `api_key`。`deployment_execution_id` 与 `model_service_group_id` 二者必须恰好设置其中一个。
    - `api_key`（`string`，可选）——模型访问令牌；当设置了 `model_service_group_id` 时为必填项。
    - `cluster_session_id`（`string`，可选；提供时必须与执行记录所属的会话一致）
    - `harness`、`workload`、`workload_yaml`、`parallelism`、`wait_timeout_seconds`、`harness_memory_gib`
    - `accelerator_profile`、`storage_class_name`、`matrix`、`concurrency_stages`、`warmup_requests`、`shared_prefix`
    - `sla_targets`（`BenchmarkSlaTargets`）
    - `specification_file`、`http_proxy`、`https_proxy`、`no_proxy`、`benchmark_source`、`use_baseline_endpoint`

    ```json
    {
      "deployment_execution_id": "00000000-0000-4000-8000-000000000001",
      "cluster_session_id": "123e4567-e89b-12d3-a456-426614174000",
      "harness": "inference-perf",
      "workload": "sanity_random.yaml",
      "parallelism": 2,
      "wait_timeout_seconds": 1800,
      "harness_memory_gib": 8,
      "matrix": [
        {"isl": 1024, "osl": 128}
      ],
      "concurrency_stages": [
        {"concurrency": 8, "num_requests": 96}
      ],
      "warmup_requests": 2,
      "sla_targets": {
        "ttft_ms": 500,
        "ttft_percentile": "p99",
        "tpot_ms": 50,
        "tpot_percentile": "p99",
        "throughput_min_tps": 1000,
        "success_rate_min_percent": 99
      },
      "specification_file": "guides/optimized-baseline",
      "http_proxy": "",
      "https_proxy": "",
      "no_proxy": "",
      "benchmark_source": {
        "repository": "https://github.com/llm-d/llm-d-benchmark.git",
        "revision": "main"
      },
      "use_baseline_endpoint": false
    }
    ```

    要改为针对一个已发布的模型服务，请将 `deployment_execution_id` 替换为
    `model_service_group_id` 并提供 `api_key`：

    ```json
    {
      "model_service_group_id": "01998e6b-4b2e-7c7e-8c6d-8e2a3f0c9b11",
      "api_key": "lens-mk-…",
      "harness": "inference-perf",
      "workload": "sanity_random.yaml"
    }
    ```

    响应：HTTP `202`，`BenchmarkRunResponse`。已排队的基准测试运行记录。

    ```json
    {
      "kind": "benchmark",
      "id": "7d698fda-8e2e-44b2-86aa-14d24098350d",
      "status": "queued",
      "created_at": "2026-09-23T09:18:24.287000Z",
      "deployment_execution_id": "00000000-0000-4000-8000-000000000001",
      "cluster_session_id": "123e4567-e89b-12d3-a456-426614174000",

      "harness": "inference-perf",
      "workload": "sanity_random.yaml",
      "parallelism": 2,
      "wait_timeout_seconds": 1800,
      "harness_memory_gib": 8,
      "matrix": [{"isl": 1024, "osl": 128}],
      "concurrency_stages": [{"concurrency": 8, "num_requests": 96}],
      "warmup_requests": 2,
      "sla_targets": {
        "ttft_ms": 500,
        "ttft_percentile": "p99",
        "tpot_ms": 50,
        "tpot_percentile": "p99",
        "throughput_min_tps": 1000,

      },
      "benchmark_source": {
    ```

### 删除一次基准测试运行

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`DELETE /api/v1/evaluate/runs/{run_id}`**

    请求：无请求体。
    - 路径参数：`run_id`（`string`，必填）

    响应：HTTP `204 No Content`。不返回任何 JSON 响应体。
  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
from llm_d_bench.evaluate.router import _delete_benchmark_history, _get

run_id = "7d698fda-8e2e-44b2-86aa-14d24098350d"
run = _get("benchmark", run_id)
if run is not None and run.get("status") in {"succeeded", "failed", "cancelled"}:
    _delete_benchmark_history(run_id)
```

### 启动一次“部署+基准测试”工作流

启动一个简单的“部署+基准测试”工作流：先创建一个经过优化的基线部署，然后对其进行基准测试。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/evaluate/workflow-runs`**

    请求体：`EvaluateWorkflowRequest`
    - `model`（`string`，必填）
    - `cluster_session_id`（`string`，必填）
    - `replicas`、`tensor_parallel_size`、`image`、`harness`、`workload`、`parallelism`

    ```json
    {
      "model": "Qwen/Qwen3-8B",
      "cluster_session_id": "123e4567-e89b-12d3-a456-426614174000",
      "replicas": 1,
      "tensor_parallel_size": 1,
      "image": "ghcr.io/llm-d/llm-d-xpu:v0.9.0",
      "harness": "inference-perf",
      "workload": "sanity_random.yaml",
      "parallelism": 1
    }
    ```

    响应：HTTP `202`，`EvaluationWorkflowResponse`。

    ```json
    {
      "kind": "workflow",
      "deployment_ownership": "evaluation",
      "id": "0e8dd5de-8a1c-4f96-9756-fd91c1da4faa",
      "status": "deploying",
      "created_at": "2026-09-23T09:18:24.287000Z",
      "deployment_run_id": "deployment-1",
      "cluster_id": "cluster-1",
      "owner_user_id": "user-1",
      "model": "Qwen/Qwen3-8B",
      "harness": "inference-perf",
      "workload": "sanity_random.yaml",
      "parallelism": 1,
      "benchmark_runtime": {}
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">

```python
import asyncio

from llm_d_bench.evaluate.models import EvaluateWorkflowRequest
from llm_d_bench.evaluate.router import create_workflow_run


async def main() -> None:
    workflow = await create_workflow_run(
        EvaluateWorkflowRequest(
            model="Qwen/Qwen3-8B",
            cluster_session_id="123e4567-e89b-12d3-a456-426614174000",
            replicas=1,
            tensor_parallel_size=1,
            workload="sanity_random.yaml",
        )
    )
    print(workflow["id"], workflow["status"])


asyncio.run(main())
```

### 获取详细的评估工作流结果

获取展开后的评估工作流结果以及部署关联信息。

对于包含用例的工作流，报告使用 `comparison_version: 2`。在读取详情时，较旧的缓存报告会根据保留下来的证据数据重新生成。矩阵行会匹配唯一的、成功的 `(isl, osl)` 数据点以及显式的 `concurrency`；速率阶段会匹配显式的 `rate`。缺失、非有限、负数或重复的负载键不构成匹配，数组位置也永远不会作为回退依据。没有匹配行时，对应的统计信息为 `null`。

比值等于 guide 值除以 baseline 值。有效的零分子会被保留，包括在几何平均值的计算中；零分母则不产生比值。按套件归一化的吞吐量仅使用那些两侧输出 token 数均非负、且实测时长均为正数的匹配配对。均值、P90 和 P99 聚合值保持相互独立。
