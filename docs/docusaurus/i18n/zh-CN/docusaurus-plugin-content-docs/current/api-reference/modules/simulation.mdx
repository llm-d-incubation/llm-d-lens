## 后端 API

本地执行与 Pod 执行通过 `llm_d_bench.simulation.progress.report_request_progress` 共享请求进度报告。Pod 报告仍会等待就绪；本地报告则保留其原始开始时间。后端适配器通过 `backends.analytics.artifact_error_message` 共享产物错误格式化逻辑，同时各自保留自身的错误/超时字段优先级、状态映射和指标单位。任务 API 与后端环境准备逻辑保持不变。

模拟相关路由位于 `llm_d_bench/simulation/router.py`，前缀为 `/api/simulation`。

    ```json
      "endpoint": "http://127.0.0.1:38000/v1",
    ```

```python
import asyncio

from llm_d_bench.simulation.endpoints import discover_models

asyncio.run(main())
```

### 创建模拟任务

创建一个模拟（Simulation）任务，对目标模型端点回放某个跟踪数据集。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/simulation/tasks`**

    请求体：`SimulationTaskCreateRequest`
    - `name`, `description`, `scenario`, `backend`, `endpoint_mode`
    - `cluster_session_id`, `endpoint_namespace`, `endpoint_service`, `endpoint_deployment_execution_id`, `endpoint_cluster_id`, `endpoint_cluster_name`, `endpoint_deployment_name`
    - `model_service_group_id` (`string`，可选) — 用于指定一个已发布、持续进行健康探测的
      模型服务（Model Service），而非原始的部署执行实例。设置该字段后，后端会将其解析为该
      分组当前活跃成员及其已发布名称，并强制将 `endpoint_mode` 设为 `"deployment"`，
      覆盖任何传入的 `endpoint_deployment_execution_id`/`model_name`。需要同时提供 `api_key`。
    - `api_key` (`string`，可选) — 模型访问令牌；当设置了 `model_service_group_id` 时为必填。
    - `endpoint_url`, `model_name`, `trace_dataset`, `trace_path`
    - `duration_seconds`, `scale_factor`, `trace_start_seconds`, `trace_end_seconds`, `trace_timeout_seconds`, `fixed_schedule`, `stream`, `backend_options`

    ```json
    {
      "name": "Trace simulation",
      "description": "Replay a chat trace against a ready deployment",
      "scenario": "chat",
      "backend": "trace-replayer",
      "endpoint_mode": "deployment",

      "endpoint_namespace": "prism-sim",
      "endpoint_service": "qwen-router",

      "endpoint_cluster_id": "cluster-1",
      "endpoint_cluster_name": "dev-cluster",
      "endpoint_deployment_name": "qwen3-guide",
      "endpoint_url": "http://127.0.0.1:38000/v1",
      "model_name": "Qwen/Qwen3-8B",
      "trace_dataset": "mooncake-arxiv",
      "trace_path": "/home/prism/.local/share/prism/data/datasets/mooncake_trace.jsonl",
    ```
