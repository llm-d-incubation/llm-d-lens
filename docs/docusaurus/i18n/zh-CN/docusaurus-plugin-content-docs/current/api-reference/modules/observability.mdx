## 后端 API

可观测性功能拆分在 `llm_d_bench/monitoring/` 下的五个 FastAPI 路由器中：`accelerator/router.py`、`cluster_stack/router.py`、`deployment/router.py`、`gpu_driver/router.py` 和 `profiling/router.py`。

### 列出加速器可观测性能力

列出 Lens 支持的加速器可观测性能力，包括访问模式和默认命名空间。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/monitoring/accelerators`**

    请求：无请求体。

    响应：返回一个 `AcceleratorCapabilitiesResponse`，其中包含支持的加速器系列。

    ```json
    {
      "accelerators": [
        {
          "type": "intel_gpu",
          "display_name": "Intel GPU",
          "access_modes": ["dra", "plugin"],
          "release_name": "xpumd",
          "default_namespace": "intel-xpumd"
        },
        {
          "type": "nvidia_gpu",
          "display_name": "NVIDIA GPU",
          "access_modes": ["plugin", "dra"],
          "release_name": "dcgm-exporter",
          "default_namespace": "dcgm-exporter"
        }
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    from llm_d_bench.monitoring.accelerator.service import capabilities

    response = capabilities()
    print(response.model_dump())
    ```
  </TabItem>
</Tabs>

### 获取加速器可观测性状态

获取某个加速器系列的可观测性状态，包括 release、组件以及访问模式的健康状况。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`GET /api/v1/monitoring/accelerators/{accelerator}/status`**

    请求：无请求体。路径参数：`accelerator`（`str`，取值为已注册系列之一：`intel_gpu` 或 `nvidia_gpu`）。查询参数：`namespace`（`str`，默认值为 `intel-xpumd`，无论所选加速器是哪个——查询 `nvidia_gpu` 时，请显式传入 `dcgm-exporter` 或 NVIDIA release 实际安装到的命名空间）、`access_mode`（`"dra" | "plugin"`，可选）以及 `cluster_id`（`str`，可选）。

    响应：返回一个 `AcceleratorStatusResponse`。

    ```json
    {
      "accelerator": "intel_gpu",
      "access_mode": "dra",
      "access_modes": [
        {
          "mode": "dra",
          "available": true,
          "detected": true,
          "message": null
        },
        {
          "mode": "plugin",
          "available": false,
          "detected": false,
          "message": "device plugin not installed"
        }
      ],
      "cluster_reachable": true,
      "context": "kind-test",
      "namespace": "intel-xpumd",
      "release": {
        "name": "xpumd",
        "status": "deployed",
        "chart": "xpumd-0.1.0",
        "revision": 1
      },
      "status": "ready",
      "message": "ready",
      "components": [
        {
          "name": "xpumd-controller",
          "status": "ready",
          "kind": "workload",
          "ready": 1,
          "desired": 1,
          "source": "xpumd",
          "diagnostics": []
        }
      ],
      "active_operation_id": null,
      "observed_at": "2026-09-23T08:00:00Z",
      "stale": false
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_bench.monitoring.accelerator.service import get_status, validate_namespace


    async def main() -> None:
        status = await get_status(
            "intel_gpu",
            validate_namespace("intel-xpumd"),
            "dra",
            cluster_id="cluster-123",
        )
        print(status.model_dump())


    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### 安装加速器可观测性

为受支持的加速器系列安装可观测性组件。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/monitoring/accelerators/{accelerator}/installations`**

    请求：路径参数 `accelerator`（`str`）。可选请求头：`Idempotency-Key`（`str`）。可选查询参数：`cluster_id`（`str`）。请求体字段为 `accelerator`、`access_mode` 和 `namespace`。

    ```json
    {
      "accelerator": "intel_gpu",
      "access_mode": "dra",
      "namespace": "intel-xpumd"
    }
    ```

    响应：返回已排队安装操作对应的 `AcceleratorOperationResponse`。

    ```json
    {
      "operation_id": "accel-op-123",
      "kind": "install",
      "status": "queued",
      "phase": "queued",
      "accelerator": "intel_gpu",
      "access_mode": "dra",
      "namespace": "intel-xpumd",
      "started_at": "2026-09-23T08:01:00Z",
      "finished_at": null,
      "exit_code": null,
      "logs": [],
      "error": null
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_bench.monitoring.accelerator.models import AcceleratorInstallRequest
    from llm_d_bench.monitoring.accelerator.service import install


    async def main() -> None:
        operation = await install(
            AcceleratorInstallRequest(
                accelerator="intel_gpu",
                access_mode="dra",
                namespace="intel-xpumd",
            ),
            idempotency_key="request-123",
            cluster_id="cluster-123",
        )
        print(operation.model_dump())


    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### 运行集群监控技术栈预检

在不安装任何内容的情况下运行集群监控技术栈的预检检查。在开始安装 Prometheus/Grafana 技术栈之前使用它。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/monitoring/cluster-stack/installations/preflight`**

    请求：可选查询参数 `cluster_id`（`str`）。请求体字段为 `namespace`、`mode`、`enable_tls` 和 `reinstall`。

    ```json
    {
      "namespace": "llm-d-monitoring",
      "mode": "central",
      "enable_tls": false,
      "reinstall": false
    }
    ```

    响应：返回一个 `ClusterStackPreflightResponse`，包含阻断性和非阻断性检查项。

    ```json
    {
      "allowed": true,
      "status": "ready",
      "checks": [
        {
          "name": "cluster-reachable",
          "passed": true,
          "message": "cluster is reachable",
          "blocking": true
        }
      ],
      "warnings": [],
      "command_preview": [
        "/path/to/llm-d/guides/recipes/observability/install-prometheus-grafana.sh",
        "--namespace",
        "llm-d-monitoring"
      ]
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_bench.monitoring.cluster_stack.models import ClusterStackInstallRequest
    from llm_d_bench.monitoring.cluster_stack.service import preflight


    async def main() -> None:
        result = await preflight(
            ClusterStackInstallRequest(
                namespace="llm-d-monitoring",
                mode="central",
                enable_tls=False,
                reinstall=False,
            ),
            cluster_id="cluster-123",
        )
        print(result.model_dump())


    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

### 管理部署监控资源

安装、启用、禁用或卸载某个部署执行的监控资源。

<Tabs>
  <TabItem value="rest-api" label="REST API">
    **`POST /api/v1/monitoring/deployments/{execution_id}/{action}`**

    请求：无请求体。路径参数：`execution_id`（`str`）和 `action`（`str`，取值为 `install`、`enable`、`disable` 或 `uninstall` 之一）。可选查询参数：`cluster_id`（`str`）。

    响应：在所请求的操作完成后，返回与前述相同形状的部署监控状态。

    ```json
    {
      "execution_id": "deploy-exec-001",
      "namespace": "llm-d-run-001",
      "cluster_reachable": true,
      "stack_ready": true,
      "status": "disabled",
      "enabled": false,
      "epp_service": {
        "name": "demo-epp",
        "labels": {
          "app.kubernetes.io/name": "demo-epp"
        },
        "service_account": "demo-epp"
      },
      "servicemonitors": [],
      "podmonitors": [],
      "message": "monitoring disabled"
    }
    ```
  </TabItem>
  <TabItem value="python-api" label="Python API">
    ```python
    import asyncio

    from llm_d_bench.monitoring.deployment.service import disable, enable, install, uninstall


    async def main() -> None:
        actions = {
            "install": install,
            "enable": enable,
            "disable": disable,
            "uninstall": uninstall,
        }
        result = await actions["disable"]("deploy-exec-001", "cluster-123")
        print(result)


    asyncio.run(main())
    ```
  </TabItem>
</Tabs>

## 共享的监控行为

监控服务共享命令 JSON 解析、Service 链接查找、Prometheus 查询传输以及操作运行时机制。下方的现有 Python 入口点和 REST 请求/响应契约保持不变；领域错误、安装阶段、DAO 记录和验证回调仍归属于各自的加速器或 cluster-stack 服务。
