---
title: 外部服务提供方
description: 配置 Lens 可选 AI 功能所使用的、兼容 OpenAI 或 Anthropic 的 AI 提供方。
---

使用外部服务提供方页面来管理 Lens 可选 AI 功能所使用的、
兼容 OpenAI 或 Anthropic 的端点。以下步骤基于当前页面和弹窗中
实际存在的控件。

提供方连接要求使用公开的 HTTPS 基础 URL。支持诸如 `/openai/v1.0`
这样的路径；在测试或调用提供方时，凭据、查询字符串、片段标识符
以及私有网络目标都会被拒绝。即使连接测试没有成功，提供方仍然
可以被保存。

刷新提供方列表时会在加载期间保留已有的行。被取代的请求无法
用更新的结果来替换；刷新失败时会保留之前的列表。删除确认框
在删除操作进行期间会禁止重复提交和关闭，并会显示失败信息以便重试。

## 添加提供方

1. 在**外部服务提供方**页面，点击**添加提供方**。
2. 在**添加 AI 提供方**中，填写**名称**、**API 类型**、
   **基础 URL**、**模型**、**API 密钥**和**超时时间（秒）**。
3. 如果想在保存前验证草稿，点击**测试连接**。页面会提示
   **可选——即使测试失败，你也可以保存。**
4. 当表单内容看起来正确时，点击**添加提供方**。

## 搜索和筛选提供方

1. 使用**搜索名称、基础 URL 或模型……**来筛选表格。
2. 打开**类型**来按提供方类型筛选。
3. 点击**清除筛选条件**来移除当前生效的筛选。
4. 在**外部服务提供方**表格中查看筛选后的结果。

## 测试一个已保存的提供方

1. 在**外部服务提供方**表格中找到该提供方。
2. 在**测试**列中，点击**测试**。
3. 等待同一行中的状态图标更新，如果需要完整的结果消息，
   将鼠标悬停在上面即可。

## 编辑提供方

1. 在该提供方所在的行中，点击 aria-label 为**编辑 _提供方名称_**的操作。
2. 在**编辑 AI 提供方**中，更新你需要的字段。
3. 如果**API 密钥**那一行提示密钥已经保存，当你想保留现有密钥时，
   将该字段留空。
4. 可选地点击**测试连接**来检查修改后的设置。
5. 点击**保存更改**。

## 删除提供方

1. 在该提供方所在的行中，点击 aria-label 为**删除 _提供方名称_**的操作。
2. 在**删除 AI 提供方**中，查看警告文本。
3. 点击**删除提供方**。
