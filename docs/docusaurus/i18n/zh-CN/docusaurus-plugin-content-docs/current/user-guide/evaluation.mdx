使用**评估**区域可以创建基准测试任务、比较各种部署配置，并查看为每次运行
收集到的证据。下面的操作只涉及当前任务列表、创建弹窗、向导和结果页面中
实际存在的控件。

基准测试结果的场景和结果选择器在使用共享选择控件的同时，保留了原有的选项
和选择行为。

## 查找评估任务

1. 从左侧导航栏打开**评估**。
2. 使用汇总卡片**评估任务**、**成功**、**运行中**、**排队中**、**失败**和
   **已取消**来缩小任务列表范围。
3. 在**搜索评估、工作负载或测试工具…**中输入内容，可按名称、模型、ID、
   模式、工作负载或测试工具匹配任务。
4. 打开**模式**，在**部署 + 基准测试**和**现有端点**两类任务之间切换。
5. 打开**工作负载**，按工作负载名称过滤。
6. 点击**清除过滤器**重置当前过滤条件。
7. 如有需要，更改**每页任务数**，并使用**上一页**或**下一页**。

## 从评估仪表盘创建新任务

1. 点击**新建任务**。
2. 在**创建新任务**中，选择目标类型：
   - **部署配置**，对已保存的部署产物进行基准测试。
   - **使用现有端点**，对一个实时服务进行基准测试，而不创建部署。
3. 如果选择了**部署配置**，停留在**选择**标签上挑选部署产物，使用
   **查看 YAML** 查看某一项，或者如果需要先创建一个新产物，点击
   **创建配置**。
4. 如果选择了**使用现有端点**，从**模型服务**中选择一个已发布的服务，然后
   填写**模型访问令牌**。
5. 继续进入**基准测试与对比**。
6. 选择一个基准测试套件，例如**自定义工作负载**或某个内置套件。
7. 当页脚显示目标已就绪时，点击**启动评估**。

**模型服务**只会列出已发布、持续进行健康探测的模型服务；没有健康成员的
模型服务会显示"尚未发布任何健康的模型服务。"原始的部署 URL 无法通过该
流程提交。仪表盘和完整向导应用相同的目标校验规则，令牌仅用于本次运行，
且从不被存储。

## 完成完整的"新建基准测试任务"向导

1. 当 Lens 将你路由到**新建基准测试任务**时，打开完整向导。
2. 在**评估设置**中，输入**任务名称**。
3. 在**这次评估应该如何运行？**下，选择**使用现有端点**或**设计配置**。
4. 如果是对现有服务进行基准测试，从**模型服务**中选择一个已发布的服务，
   然后填写**模型访问令牌**。
5. 如果是设计一个基于部署的运行，请填写共享设置字段，例如**集群**、
   **模型 ID**、**模型缓存存储**、**部署名称**和**部署描述**。
6. 在**配置**中，查看已选的部署产物。只有在需要更改候选集时，才使用
   **编辑设置**、**从已保存配置添加**、**编辑**、**编辑 YAML**或
   **删除已部署配置**。
7. 在**基准测试**中，配置基准测试计划并解决任何校验提示信息。
8. 在**执行计划**中，查看**执行计划**、**目标与执行顺序**和**性能目标**
   各个部分。
9. 点击**开始评估**。

**模型服务**只会列出已发布、持续进行健康探测的模型服务；该令牌用于通过
集群的共享 Gateway 对测试工具进行身份验证，且仅用于本次运行。

编辑已保存配置的 YAML 会创建一个带有更新后校验和与编辑溯源信息的新产物；
原始产物会被保留。这一点在两个创建入口中都适用。

## 打开任务结果并导出证据

1. 在任务列表中，点击任务卡片上的**结果**。
2. 在详情页面上，使用各分区标签**基准测试结果**、**对比**、**实时监控**
   或**已记录监控**、**资源**、**基准测试日志**和**部署**。
3. 点击**下载报告**导出基准测试报告。
4. 如果想把基准测试数据传递到模拟工作流中，点击**发送到模拟与 TCO**。
5. 需要获取最新状态快照时，使用提示为**刷新部署状态与详情**的刷新操作。

活动中的结果页面每五秒刷新一次已持久化的进度，且不会再次显示初始加载
状态。当浏览器标签页处于隐藏状态时，刷新会暂停，恢复可见后再继续；当任务
到达终止状态时，刷新会停止。部署就绪状态的刷新仍需显式操作。处于
**Stopping**（正在停止）状态的任务，在清理完成之前仍视为活动任务。

### 阅读指南与基线对比

矩阵对比会将具有相同输入长度、输出长度和并发度的结果配对。速率对比会将
具有相同目标速率的阶段配对。缺失或存在歧义的负载值会被排除，而不是按行
位置进行匹配。一个有效的零值测量仍会保持为零；缺失的测量值或为零的基线
不会产生比率。套件吞吐量对比只包含双方都具有 token 计数和正持续时间的
匹配对。

比率计算方式为指南值除以基线值：更高的吞吐量比率对指南更有利，而更低的
延迟比率对指南更有利。打开结果时，较早缓存的对比报告会根据已保存的证据
刷新；不会凭空臆造不可用的历史测量值。

## 查看基准测试日志与部署用例

1. 打开某个任务的**结果**页面。
2. 点击**基准测试日志**，查看**测试工具 Pod 日志**、**基准测试输出**和
   **基准测试诊断信息**。
3. 点击**部署**，查看**部署用例**。
4. 使用部署过滤条件**全部**、**失败**、**活动中**、**就绪**以及
   **重试历史**或**隐藏历史**。
5. 在某个部署用例中，点击**部署日志**打开部署诊断信息。
6. 查看**部署与 Kubernetes 日志**、**Kubernetes Pod**、**Kubernetes 事件**、
   **模型服务器日志**和**最近一次就绪检查**。

## 重试、取消、恢复或删除由评估创建的部署

1. 打开任务的**结果**页面，进入**部署**。
2. 如果某个部署用例失败，点击**重试**。
3. 如果某个部署用例已暂停，点击**恢复**。
4. 要停止执行，对由评估创建的服务点击**取消基准测试与部署**，对针对现有
   端点的任务点击**取消基准测试**。
5. 如果不再需要某个失败或已清理的部署，点击**删除**。
6. 如果本次重试需要使用私有模型令牌，请在点击**重试**之前填写
   **本次重试使用的 Hugging Face 令牌**。

## 从任务列表移除或重试任务

1. 在任务列表中，使用任务卡片右侧的操作。
2. 点击**结果**打开已完成的证据。
3. 对失败或已取消的任务，使用 aria-label 为**重试任务**、提示为**重试**
   的操作。
4. 对正在运行的任务，使用 aria-label 为**取消任务**的操作。
5. 对处于终止状态的任务，使用 aria-label 为**删除任务**的操作，并确认
   删除。
