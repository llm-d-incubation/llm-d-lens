使用模型缓存页面可以将模型下载到已注册的缓存存储中、查看下载进度，并清理
已缓存的文件。下面的步骤与当前 UI 中实际存在的控件一一对应。

更改集群或搜索过滤条件会取消被替代的列表请求。**开始下载**会阻止重复提交，
并在弹窗中显示失败信息以便重试。下载会继续使用所选集群保存的令牌。
**每页行数**会将列表返回到第一页；汇总信息反映的是经过过滤后的已缓存模型。

## 部署如何使用已缓存的模型

当某个部署使用**共享 Hugging Face 缓存优先**模型来源且缓存已就绪，或者使用
**精确模型文件夹**模型来源时，其模型服务器会将缓存挂载到 `/model-cache`，
并以 Hugging Face 离线模式启动（`HF_HUB_OFFLINE=1`、
`TRANSFORMERS_OFFLINE=1`，对于共享缓存还会加上 `HF_HOME=/model-cache`）。
它会从挂载点加载模型，启动时不会联系 `huggingface.co`，因此即便 Hub 连接
缓慢、被阻断或不稳定，也不会阻止部署成功。这适用于所有依赖缓存的指南场景，
包括 P/D 分离、精确前缀缓存路由和分层前缀缓存。请在部署前确保缓存条目已
就绪且完整，包括精确的模型版本（revision）；离线模型服务器无法回退到联网
下载。

Hugging Face 相关的环境变量（`HF_*`、`HUGGING*`、`TRANSFORMERS_*`）由平台
管理员统一管理。它们无法在部署编辑器的自定义运行时覆盖项中设置，规划与
配置 API 也会拒绝它们；平台会根据集群已保存的代理、模型缓存和令牌设置自动
推导这些值。

## 从 Hugging Face 下载模型

1. 在**模型缓存**页面上，点击**下载模型**。
2. 在**下载模型**中，选择一个**集群**和**存储卷**。
3. 将**模型来源**保留为 **Hugging Face**。
4. 可以手动输入 **HuggingFace 仓库 ID** 和**版本（Revision）**，也可以点击
   **浏览 Hugging Face Hub**。
5. 如果打开了**浏览 HuggingFace Hub**，使用**搜索模型…**，从左侧列表中选择
   一个结果，然后点击**使用此模型**。
6. 下载会使用**集群保存的 HuggingFace 令牌**（在集群向导中设置）；此处没有
   令牌选择项。对于没有保存令牌的公开模型，下载会以未认证方式进行。
7. 点击**开始下载**。

## 从模型市场下载模型

1. 点击**下载模型**。
2. 在**下载模型**中，将**模型来源**设置为**模型市场**。
3. 点击**浏览模型市场**。
4. 在**浏览模型市场**中，使用**按模型名称、系列或仓库搜索…**以及
   **模型分类**下的分类标签来查找模型，然后点击对应的模型卡片。
5. 回到**下载模型**后，查看所选模型的详情。如需更换，点击**更换模型**选择
   另一个模型。
6. 选择**集群**和**存储卷**。
7. 对于私有模型，下载会使用**集群保存的 HuggingFace 令牌**（在集群向导中
   设置）。
8. 点击**开始下载**。

## 过滤已缓存的模型

1. 使用**目标集群**将页面限定到单个集群，或保留为**所有集群**。
2. 在**模型缓存存储**中，点击某个存储卡片，将列表过滤到该存储卷。
3. 使用**按模型搜索**缩小**已缓存模型**列表的范围。
4. 使用**全部**等类型标签，以及页面显示的任何模型类型标签。
5. 使用**每页行数**和分页控件浏览更长的结果集。

## 查看下载日志

1. 在某个模型卡片上，点击提示为**查看日志**的操作。
2. 在**下载日志**中，如果列出了多个节点，从下拉列表中选择一个节点。
3. 如果想立即刷新，点击标题为**刷新日志**的按钮。弹窗在打开期间也会自动
   刷新。
4. 阅读日志输出以及上方显示的各节点状态标签。

## 重试失败的下载

1. 找到显示为失败状态的模型卡片。
2. 点击提示为**重试下载**的操作。
3. 留意页面上出现的**已开始重试**提示，并通过**进度**或**查看日志**继续监控
   该卡片。

## 将已缓存的模型同步到新节点

1. 如果页面显示页头操作**同步新节点 (...)**，点击它以开始将每个仍需复制到
   新节点的已缓存模型进行同步。留意提示**已开始为 N 个模型同步**（表示已
   排队的模型数量），如果没有需要同步的模型，则会显示**无需同步——所有模型
   均已是最新**。
2. 如果只想同步一个模型，找到提示新节点需要该模型的卡片，点击提示为
   **同步新节点**的操作。留意**已开始同步新节点**的提示。

## 删除已缓存的模型

1. 在要移除的模型卡片上，点击提示为**删除已缓存模型**的操作。
2. 在**删除已缓存模型**中，查看关于即将删除的确切缓存路径的警告信息。
3. 点击**删除已缓存模型**开始移除操作。

## 相关页面

如果你没有看到可用的缓存卷，请先在[存储](/user-guide/storage)页面注册一个。
