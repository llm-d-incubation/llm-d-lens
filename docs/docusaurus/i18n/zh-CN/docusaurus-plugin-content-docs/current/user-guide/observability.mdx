---
title: 可观测性
description: 安装并监控 Prometheus/Grafana 集群监控栈，并查看用量报告。
---

使用可观测性页面可以在一个地方查看集群监控、加速器监控和逐部署监控。下面
的步骤只描述当前 UI 中**集群**、**加速器**和**部署**三个标签下实际存在的
控件。

## 查看集群可观测性状态

1. 打开**集群**标签。
2. 使用**目标集群**选择你想查看的集群。
3. 在**命名空间**中输入你要检查的命名空间，然后点击**检查**。
4. 查看**实时状态**、**安装操作**和**技术栈组件**。
5. 当这些按钮针对当前状态出现时，使用**刷新**、**重试**或**重新检查**。

## 安装集群可观测性技术栈

1. 在**集群**标签中，选择目标集群。
2. 如果页面显示**安装技术栈**或**安装可观测性技术栈**，点击它。
3. 在**安装可观测性技术栈**中，确认**命名空间**，并查看**安装模式**。
   可选的方式是**中心化（推荐）**；**单独安装**会显示出来但处于禁用状态。
4. 点击**运行预检**。
5. 查看**预检通过**或**预检未通过**的结果，以及相应的检查项、警告和
   **命令预览**。
6. 预检通过后，点击**安装技术栈**。
7. 跟踪**安装操作**的进度，直到页面报告**集群可观测性技术栈安装成功**。

## 重新安装集群可观测性技术栈

1. 在**集群**标签中，点击**重新安装**（如果该操作可用）。
2. 在**重新安装可观测性技术栈**中，查看关于重新安装会删除已存储指标的
   警告。
3. 勾选**我了解现有的指标数据将被永久删除**。
4. 点击**运行预检**。
5. 预检通过后，点击**重新安装技术栈**。

## 打开集群仪表盘

1. 停留在**集群**标签。
2. 在 **GUIs** 中，点击 **Prometheus** 或 **Grafana**。
3. 如果无法打开仪表盘，请阅读按钮旁显示的内联错误信息。

## 查看加速器可观测性

1. 打开**加速器**标签。
2. 在**加速器类型**下选择一种加速器。这些标签是根据注册到 Lens 的硬件
   配置文件构建的，因此每一个已连接的设备插件/DRA 驱动都会出现在这里，
   页面文案和图表名称也会跟随所选厂商变化。
3. 查看 **GPU 访问模式**，如有需要，可在该加速器支持的模式之间切换
   （例如 **DRA** 和**设备插件**）。
4. 查看所选加速器的**可观测性界面**和**技术栈组件**。
5. 当这些操作可用时，使用 **Prometheus**、**Grafana**、**刷新**或**重试**。

## 安装或修复加速器可观测性

1. 打开**加速器**标签并选择目标集群。
2. 如果页面显示**安装加速器可观测性**、**修复/重新安装**或**重新安装**，
   点击与你当前状态匹配的操作。
3. 在**安装加速器可观测性**中，设置**命名空间**和 **GPU 访问模式**。
4. 点击**运行预检**。
5. 查看预检的检查项、警告和**命令预览**。
6. 预检通过后，点击**安装**。
7. 关注**安装操作**，直到页面报告所选加速器安装成功（例如
   **NVIDIA GPU 可观测性安装成功**）。

## 管理某个部署的部署监控

1. 打开**部署**标签。
2. 在**目标集群**中选择集群。
3. 在**部署监控**中，为要管理的部署打开**监控**菜单。
4. 当没有监控时选择**安装**；当监控已禁用时选择**启用**；当监控已启用时
   选择**禁用**；选择**卸载**以将其移除。
5. 等待**监控**列中的状态标签更新。页面会提示**状态每 10 秒自动刷新一次。**

## 打开部署仪表盘

1. 在**部署**标签中，为已启用监控的某个部署打开**监控**菜单。
2. 点击**打开 Grafana**或**打开 Prometheus**。

## 查看部署性能剖析

1. 在**部署**标签中，打开某个部署的**监控**菜单，点击**性能剖析**。
2. 在**部署性能剖析**中，按需在**流量指标**的**请求**和 **Token** 之间
   切换。
3. 保持 **Flow Map**（流程图）处于选中状态，以查看当前的流水线拓扑图。
4. 使用**查看实时流程节点**下的节点按钮，在侧边抽屉中打开各节点的指标。
5. 在流程图工具栏中，使用**放大**、**缩小**、**重置视图**和**适应视图**。
6. 点击 aria-label 为 **Back to deployments**（返回部署列表）的按钮，
   返回部署列表。

## 共享的监控行为

安装弹窗共用预检逻辑和请求处理；当页面处于隐藏状态时，操作轮询会暂停，
并在到达终止状态时停止。加速器与集群技术栈的选项及安装验证相互独立。
