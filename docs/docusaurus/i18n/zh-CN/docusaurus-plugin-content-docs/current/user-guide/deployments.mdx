使用**部署**页面查找活跃的服务、查看它们的运行时详情，并管理你已创建的部署记录。以下每一项操作都基于当前前端中确实存在的控件。

部署列表会取消已被取代的过滤请求，确保旧的结果不会替换当前的选择。集群名称在可用时会显示，否则回退显示 ID。删除操作仍需要输入页面显示的确认短语，并会保留命名空间的选择；在删除操作处于待处理状态时，提交按钮和对话框的关闭操作均被禁用。

在为部署规划指定运维偏好时，请使用英文，例如
`prefer prefix cache`、`more GPU for performance` 或 `use fewer GPU resources`。
确定性规划器匹配的是英文偏好关键词；不再支持中文关键词别名。

## 打开部署创建流程

1. 在左侧导航中，打开**部署**。
2. 在页面标题栏，点击**创建**。
3. Lens 会将你路由到模型市场中的部署创建流程。当你返回时，新的部署记录会自动出现在**部署**列表中。

## 在列表中查找部署

1. 查看页面顶部的汇总卡片：**总计**、**就绪**、**进行中**、**失败**和**已清理**。
2. 在列表工具栏中，在**搜索部署**中输入内容，可按名称、描述、模型、命名空间、指南或 ID 匹配部署。
3. 打开**状态**以按部署状态进行筛选。
4. 打开集群选择器，选择**所有集群**或某一个集群。
5. 如有需要，更改**每页行数**，并使用分页器在列表中翻页。
6. 如果没有匹配的行，点击**清除筛选**。

## 查看部署详情

1. 在部署行中，点击提示为**查看详情**的操作。
2. 在抽屉中，查看**基本信息**、**模型与服务引擎**、**集群与环境**、**网络与端点**以及**审计与时间线**各个部分。
3. 当你需要在别处复用诸如**命名空间**、**集群会话 ID**、**容器镜像**、**内部端点**、**转发端点**或**执行 ID**等值时，使用这些值旁边的复制按钮。
4. 如果部署失败，请先阅读失败提示横幅，再做任何改动。

## 查看 Pod 并查看实时日志

1. 要在行内查看 Pod 状态，点击提示为**显示 Pod** 的行展开开关。
2. 在展开的行中，查看 Pod 表格的列：**Pod**、**状态**、**重启次数**、**节点**和 **Pod IP**。
3. 要使用完整的日志查看器，点击提示为**查看 Pod 与日志**的操作。
4. 在抽屉中，当 Pod 分布在多个节点上时，使用**所有节点 (...)** 按节点筛选。当节点数超过 3 个或 Pod 数超过 2 个时，使用**搜索节点...**或**搜索 Pod...**进一步缩小列表范围。
5. 点击某个 Pod 卡片，打开该 Pod 的**Pod 日志：**。
6. 如果某个 Pod 包含多个容器，请选择所需的**容器：...**条目。
7. 选择**100 行**、**200 行**、**500 行**或**1000 行**以更改日志尾部的长度。
8. 如果需要查看上一个容器的日志，请打开**上一个**开关。
9. 保持**自动刷新 (5 秒)**开启，以让 Pod 列表和日志保持实时更新。
10. 使用**筛选日志行...**来缩小日志输出范围，或点击**复制**来复制当前的日志文本。

## 为就绪的部署创建本地端口转发

1. 找到一个已经处于**就绪**状态的部署。
2. 在该行中，点击提示为**创建本地端口转发**的操作。
3. 等待成功提示**本地端点已连接**出现。
4. 如果你想从工作站调用该服务，可从表格中复制更新后的本地端点。

## 打开部署监控与性能分析

1. 在部署行中，点击提示为**部署监控**的操作。
2. 如果监控尚未安装，点击**安装**。
3. 如果监控已存在但处于暂停状态，点击**启用**。
4. 当监控已启用时，使用**打开 Grafana** 或**打开 Prometheus** 在新标签页中打开相应的仪表盘。
5. 点击**性能分析**，跳转到该部署的性能分析视图。
6. 使用**禁用**可以在不卸载的情况下停止监控。
7. 使用**卸载**可以从该服务中移除部署监控。

## 编辑部署名称与描述

1. 在部署行中，点击提示为**编辑名称与描述**的操作。
2. 在**编辑部署**中，更新**显示名称**和**描述**。
3. 点击**保存更改**。
4. 如果你决定不保留这次编辑，点击**取消**。
5. 不要期望在这里更改运行时字段：抽屉中说明模型、命名空间、镜像、拓扑结构、端点和集群都是不可变的。

## 将部署共享给其他用户或组

1. 在部署行中，点击提示为**共享部署**的操作。
2. 在**共享部署**中，选择**共享对象**：**用户**或**组**。
3. 从**用户**或**组**中选择目标对象。
4. 选择**对该部署的权限**。
5. 点击**共享**。
6. 要稍后移除一项共享，点击该用户或组旁的**撤销访问权限**操作。
7. 完成后点击**关闭**。

## 删除部署

1. 在部署行中，点击提示为**删除部署**的操作。
2. 在**删除部署**中，查看**执行 ID**、**集群**和**命名空间**。
3. 如果你希望 Lens 移除该命名空间及其中的所有内容，请保持**同时删除 Kubernetes 命名空间**选中；如果只想移除部署记录，请取消勾选。
4. 在**输入 `<短语>` 以确认**中，输入对话框中显示的确切确认短语。
5. 点击**删除部署**。
6. 如果你不想继续，点击**取消**。

## 权限

维护者可以管理其被绑定的集群上的部署；管理员可以管理每一个集群上的部署。完整的权限模型参见 [认证与 RBAC](/architecture)。

## 相关参考

在部署创建流程中，当某个已验证的替代方案存在精确拓扑估算结果时，展开其下方的**为什么选择此项**可查看其 AIC TTFT、TPOT 和吞吐量估算值。即使 AIC 候选搜索找不到满足原始 SLO 的配置，该估算值也可能出现；在这种情况下，该替代方案仍会显示**未满足 SLO**。没有匹配估算值的替代方案会显示没有可用的精确 AIC 预测结果。

智能体候选项旁显示的**AI 评分**是一个满分 100 的相对排名分数；得分最高的候选项会被归一化为 100。它不是基准测试结果、置信水平，也不是满足 SLO 的概率。确定性回退方案会改为显示**确定性评分**。

如果你在部署创建流程中使用智能体规划器，请参阅[架构概览](/architecture)了解基于负载引导的规划是如何工作的。
