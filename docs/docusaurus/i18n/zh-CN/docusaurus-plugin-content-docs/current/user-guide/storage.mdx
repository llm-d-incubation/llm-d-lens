title: 存储
description: 管理部署所使用的模型缓存和共享存储卷。

使用存储页面来注册可复用的存储卷，查看它们实时的 PVC 和 PV 状态，
并在不再需要时清理它们。

筛选操作会取消被取代的列表请求。创建和删除操作会防止重复提交，
并在弹窗中显示失败信息以便重试。当一个存储卷包含模型缓存条目时，
删除操作会保留其两步确认流程：先查看受影响的条目，再选择
**保留模型文件**或**删除模型文件**。

## 创建一个存储卷

1. 打开**存储**，点击**新建存储卷**。
2. 在**新建存储卷**中，选择目标**集群**。
3. 选择**类型**。
4. 如果**类型**是 **hostPath**，填写**主机路径**。如果**类型**是
   **NFS**，填写**服务器**和**导出路径**。如果**类型**是
   **动态 PVC**，填写**StorageClass**、**命名空间**和**访问模式**。
5. 填写**名称（可选）**和**容量**。
6. 如有需要，开启或关闭**挂载时只读**。
7. 在**用途（可选）**下，保持**通用**或选择**模型缓存**。
   模型缓存仅适用于 **hostPath** 和 **NFS** 卷（当选择了模型缓存时，
   动态 PVC 会被禁用，反之亦然）；选择它还会强制关闭
   **挂载时只读**，因为模型下载必须能够写入该存储卷。
8. 点击**创建存储卷**。

## 筛选存储卷列表并查看实时状态

1. 打开**存储**。
2. 使用**所有集群**、**按名称搜索**、**所有类型**和**所有用途**
   来缩小列表范围。
3. 查看摘要卡片：**总数**、**就绪**、**等待中**、**需关注**和**失败**。
4. 在列表中点击一个存储卷。
5. 在**状态**中，查看**ID**、**类型**、**集群**、**容量**和**位置**。
6. 查看**Persistent Volume Claim** 和 **Persistent Volume** 面板，
   了解实时的 Kubernetes 资源状态。

## 确认 hostPath 存储卷的节点变更

1. 选择显示橙色漂移警告的存储卷。
2. 阅读**状态**中的警告信息。
3. 在确认节点变更无误后，点击**确认**来清除该警告。

## 删除一个存储卷

被一个或多个部署引用的存储卷会显示**使用中**徽标，并且其删除
控件会被禁用；请先从这些部署中释放它。

1. 在存储卷列表中，点击标题为**删除存储卷**的删除控件。
2. 在**删除存储卷**中，查看关于 Kubernetes PVC 和 PV 对象的警告。
3. 如果该存储卷包含模型缓存条目，点击**继续**。
4. 在后续的**删除存储卷**步骤中，如果想保留 NFS 或 hostPath 上的
   文件，选择**保留模型文件**；如果想让 Lens 先删除这些文件，
   选择**删除模型文件**。
5. 如果该存储卷没有模型缓存条目，直接点击**删除存储卷**。

## 模型缓存

当你需要管理已下载的模型权重本身时，使用
[模型缓存](/user-guide/model-cache)。该页面涵盖缓存条目和下载日志，
而**存储**管理的是底层可复用的存储卷。

## 权限

存储操作和 Lens 的其他部分一样按集群划分范围：维护者只能管理
自己被绑定的集群上的存储卷，而管理员可以管理所有集群上的存储卷。
