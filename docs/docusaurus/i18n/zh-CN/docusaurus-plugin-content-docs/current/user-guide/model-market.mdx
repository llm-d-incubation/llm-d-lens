---
title: 模型市场
description: 浏览模型目录并开始一键部署。
---

模型市场页面帮助你选择目录中的模型，并将它交给部署流程处理。
它是一个由 UI 内置模型列表支撑的前端目录，之后会进入一个
引导式部署表单。

## 按类别浏览模型

1. 打开**模型市场**。
2. 在**模型分类**行中，点击一个分类（例如**全部**、**文本**、
   **视觉**、**语音**、**编码器**或**重排序**）来过滤网格。
3. 查看每张模型卡片的内置字段：**发布时间**、**精度**、**权重**、
   **上下文**和**模型类型**。
4. 点击你想使用的模型卡片，打开**一键部署**。

## 创建一个标准部署

1. 在**一键部署**中，确认所选模型，然后填写**部署名称**。
2. 可选：输入**描述**。
3. 在**集群**中，选择一个就绪的集群。如果需要先切回目录，
   点击页眉中的**模型市场**。
4. 在**模型缓存存储**中，选择一个存储卷。如果你还没有，点击
   **管理存储**。
5. 等待页面显示**该模型已在所选缓存中就绪。**。如果它显示
   **该模型未在所选存储中下载。请先清理或在此下载模型。**，
   请先修复缓存问题。
6. 将**模式**保持为**标准**。Lens 会根据推荐方案预先填写
   **副本数**和**张量并行度**；如果需要不同的拓扑结构，
   可以调整这两个字段中的任意一个（如果组合超出了集群的
   可用 GPU 数量，会出现错误提示）。
7. 可选：展开**vLLM 参数**，调整**GPU 内存利用率**、
   **最大模型长度**、**最大序列数**、**最大批处理 token 数**、
   **前缀缓存**、**强制 eager 执行**、**启用自动工具选择**
   （会显示**工具调用解析器**）或**自定义 vLLM 参数**等字段。
8. 可选：展开**部署环境**，修改**使用集群代理**、**HTTP 代理**、
   **HTTPS 代理**或**NO_PROXY**。
9. 查看**标准 vLLM 方案**。
10. 点击**创建部署**，打开资源预算选择器，选择
    **当前可用**或**全部物理显卡**，然后通过
    **确认并部署**来确认。
11. 请求成功后，Lens 会打开[部署](/user-guide/deployments)页面。

## 交接给高级部署工作流

1. 从**模型市场**打开一个模型，使**一键部署**表单出现。
2. 填写**部署名称**，选择一个**集群**，如果想复用已缓存的权重，
   设置**模型缓存存储**。
3. 在**模式**中，点击**高级**。
4. 点击**配置部署**。
5. 在随后打开的部署配置流程中继续操作。

## 启动智能体部署规划器

1. 从**模型市场**打开一个模型。
2. 填写你已经知道的基本表单字段，例如**部署名称**、**集群**和
   **模型缓存存储**。
3. 在**模式**中，点击**智能体**（标记为**实验性**）。
4. 在表单下方打开的嵌入式规划器中继续操作。

## 权限

如果页面显示**你的角色无法创建部署。**，你仍然可以点击
**打开部署**来查看现有部署，但无法从此页面提交**一键部署**。
