最快搭建起一个运行中的 Lens 实例的方式是使用内置安装脚本——
无需手动配置 Node/Python/Postgres。

```bash
git clone https://github.com/llm-d-incubation/llm-d-lens.git
cd llm-d-lens
./scripts/LensInstaller-Ubuntu-x86_64.sh
```

按回车接受默认值（安装目录 `$HOME/llm-d-lens`，应用端口
`3000`，后端端口 `8081`）。安装脚本会自动安装 Node、Python、
内置的 PostgreSQL 数据库，构建应用，配置 TLS 并启动它。

安装完成后，打开脚本打印出的 URL（默认是 `https://localhost:3000`），
并使用脚本打印出的管理员凭据登录。

## 走完整条路径：集群 → 部署 → 模型服务 → 令牌调用

本页接下来的内容会带你完整走一遍最小示例：注册一个
集群，使用 llm-d 的 **optimized-baseline** 指南部署一个
**单 GPU 的 `Qwen/Qwen3-0.6B`**，将其发布为一个**模型服务**，
然后使用**个人令牌**调用网关。每一步都链接到对应模块页面，
以获取完整选项说明。

### 1. 创建集群

1. 打开[集群](/user-guide/clusters)页面并点击**新增**。
2. 在**基本信息**中，输入**集群名称**（可选填写**描述**）。
3. 在**Kubeconfig 文件**下，保持选中**我已有 kubeconfig**，
   然后点击**浏览**选择文件，或者选择**通过 Kubespray 引导新集群**。
4. 依次点击**下一步**，完成**网络代理**、**加速器**、**llm-d 技术栈**
   和**模型缓存**这几步。
5. 在最后一步点击**审核**，然后点击**完成**，再点击**结束**。
6. 等待集群就绪，并显示非零的**可部署 GPU** 数量。

### 2. 使用 optimized-baseline 指南部署 Qwen3-0.6B（单 GPU）

1. 打开[模型市场](/user-guide/model-market)，点击
   **`Qwen/Qwen3-0.6B`** 卡片，打开**一键部署**。
2. 填写**部署名称**（例如
   `qwen3-0-6b-optimized-baseline`）和可选的**描述**。
3. 在**集群**下，选择第 1 步中创建的集群。
4. 在**模式**中，点击**高级**（评估配置），然后点击
   **配置部署**。
5. 在**配置部署**页面：
   - **基本设置**：保持**模型**为 `Qwen/Qwen3-0.6B`，**运行时**为
     `vllm`，默认的**运行时镜像**，**副本数**为 `1`，**TP** 为 `1`
     （1 个副本 × TP 1 = 单个加速器）。
   - **模型来源**：保持**优先使用共享 Hugging Face 缓存；缺失时下载**。
   - **指南模板**：将**指南**设置为 **optimized-baseline**，
     **加速器**设置为你集群的加速器类型。
6. 点击**生成 YAML**，确认资源预算，然后点击
   **确认并生成**。
7. 检查生成的可部署配置，然后点击**下一步**进行部署。
8. Lens 会打开[部署](/user-guide/deployments)页面；等待部署
   状态显示为**就绪**。

### 3. 将部署发布为模型服务

1. 打开**模型服务**。
2. 在**模型服务**下，点击**新增**。
3. 在**新建服务**中，设置**模型名称（面向用户）**（例如
   `qwen3-0.6b`）、**模型引用** `Qwen/Qwen3-0.6B`，以及可选的
   **显示名称**/**描述**。将**服务提供方选择策略**保持为
   `random`，然后点击**创建**。
4. 点击**新增提供方**，然后选择新建的**模型服务**、
   **集群**以及第 2 步中创建的**部署**。
5. 确认推导出的目标信息（`namespace`、`service`、`port`、`kind`），
   然后点击**新增提供方**。
6. 等待共享的**网关**及其 **HTTPRoute** 显示为健康状态；如果需要
   重新执行网关协调，可使用**同步**。

### 4. 使用令牌调用服务

1. 打开**API 密钥**并点击**新建密钥**。
2. 在**创建 API 密钥**中，输入**密钥名称**，点击**创建**，然后点击
   **复制**并保存令牌（该令牌仅显示一次），最后点击
   **我已保存**。
3. 打开**我的服务**，点击**复制端点**以复制共享网关的基础
   URL，并点击 `qwen3-0.6b` 旁的 **cURL** 以复制一个现成的请求。
4. 将 `lens-mk-...` 替换为你的密钥，然后发送请求：

```bash
curl <gateway-base-url>/v1/chat/completions \
  -H "Authorization: ******" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-0.6b","messages":[{"role":"user","content":"Hello!"}]}'
```

响应内容就是模型通过共享网关返回的回复。使用相同的令牌
执行 `GET <gateway-base-url>/v1/models`，即可列出你可以调用的模型名称。

如需了解安装脚本的每一个选项、升级现有安装，或改为从源码运行，
请参阅[安装指南](/installation)。
