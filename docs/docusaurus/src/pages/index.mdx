## Architecture

<img src={useBaseUrl('/img/home-3-7d83bcc33b.png')} alt="Lens system architecture" width="100%" />

A single Lens server manages any number of Kubernetes clusters, on-premises or
in the cloud, from one pane of glass: the console talks to an application layer
over same-origin API routes, and that layer forwards requests to a control plane
that owns the domain services, persists state to the database, and drives
clusters, storage and the model-service data plane directly. Access control and
audit logging are enforced in the control plane, so every page — deployments,
evaluation, simulation and model services alike — respects the same per-cluster
permissions.
